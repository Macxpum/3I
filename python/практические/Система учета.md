## Общая задача

Необходимо разработать консольную программу для учёта товаров в небольшом магазине компьютерной техники. Программа должна хранить информацию о товарах, позволять просматривать ассортимент, выполнять поиск, изменять количество товаров и рассчитывать стоимость продукции.

Для выполнения работы необходимо использовать списки, словари, циклы, условия и функции.

## Исходные данные

В начале программы создай список товаров. Каждый товар должен храниться в виде словаря со следующими характеристиками:

- `id` — уникальный номер товара;
    
- `name` — название товара;
    
- `category` — категория товара;
    
- `price` — цена за одну единицу;
    
- `quantity` — количество единиц на складе.
    

Добавь в список не менее 8 товаров разных категорий. Например: мышь, клавиатура, монитор, наушники, веб-камера, микрофон, колонки и USB-флешка.

У товаров должны быть разные цены и остатки на складе. Необходимо предусмотреть несколько товаров одной категории.

## Задание 1. Вывод ассортимента

Реализуй вывод полного списка товаров.

Для каждого товара необходимо отображать его номер, название, категорию, цену и количество на складе.

Дополнительно рассчитай и выведи общую стоимость всех товаров на складе. Для этого необходимо умножить цену каждого товара на его количество и сложить полученные значения.

## Задание 2. Поиск товаров

Реализуй поиск товара по названию.

Пользователь вводит название или часть названия, после чего программа выводит все подходящие товары.

Поиск должен учитывать регистр букв: например, запросы «мышь» и «Мышь» должны работать одинаково.

Если подходящих товаров нет, программа должна сообщить об этом пользователю.

## Задание 3. Фильтрация по категории

Реализуй вывод товаров выбранной категории.

Пользователь вводит название категории, а программа выводит только товары, которые к ней относятся.

Если в выбранной категории нет товаров, необходимо вывести соответствующее сообщение.

Дополнительно выведи список всех уникальных категорий, которые присутствуют в ассортименте. Для этого используй множество (`set`).

## Задание 4. Работа с остатками на складе

Реализуй проверку наличия товаров.

Программа должна выводить три группы товаров:

1. Товары, которых на складе нет.
    
2. Товары, количество которых меньше 5 единиц.
    
3. Товары, количество которых составляет 5 единиц или больше.
    

Для каждой группы необходимо вывести названия товаров и их количество.

## Задание 5. Изменение количества товара

Реализуй пополнение склада.

Пользователь вводит идентификатор товара и количество единиц, которое необходимо добавить.

Программа должна найти товар и увеличить его остаток на указанное количество.

Предусмотри проверки:

- товар с таким идентификатором существует;
    
- введённое количество является положительным числом;
    
- при ошибке программа выводит понятное сообщение.
    

После успешного изменения необходимо вывести обновлённую информацию о товаре.

## Задание 6. Продажа товара

Реализуй продажу товара со склада.

Пользователь вводит идентификатор товара и количество единиц для продажи.

Программа должна проверить наличие товара и достаточность остатка. Если товара недостаточно, продажа не выполняется, а пользователю выводится сообщение об ошибке.

При успешной продаже количество товара на складе уменьшается, а программа выводит итоговую стоимость покупки.

Например, если покупатель приобретает 2 мыши стоимостью 1500 рублей каждая, стоимость покупки составит 3000 рублей.

## Задание 7. Статистика магазина

Реализуй формирование отчёта по ассортименту.

Программа должна выводить:

- общее количество различных товаров в ассортименте;
    
- общее количество единиц продукции на складе;
    
- общую стоимость товаров на складе;
    
- самый дорогой товар;
    
- самый дешёвый товар;
    
- категорию, в которой находится больше всего товаров по количеству единиц;
    
- среднюю цену одного товара в ассортименте.
    

При расчёте средней цены учитывай количество различных позиций, а не количество единиц на складе.

## Задание 8. Сортировка товаров

Добавь возможность сортировки ассортимента:

1. По цене от меньшей к большей.
    
2. По цене от большей к меньшей.
    
3. По названию в алфавитном порядке.
    
4. По количеству на складе от меньшего к большему.
    

Для сортировки используй `sorted()` или метод `sort()` с параметром `key`.

При сортировке необходимо сохранить возможность дальнейшей работы с исходным ассортиментом.

## Задание 9. Меню программы

Объедини все реализованные возможности в единое меню.

При запуске программа должна предлагать пользователю следующие действия:

1. Показать все товары.
    
2. Найти товар по названию.
    
3. Показать товары выбранной категории.
    
4. Проверить остатки на складе.
    
5. Пополнить склад.
    
6. Продать товар.
    
7. Показать статистику.
    
8. Отсортировать товары.
    
9. Завершить работу программы.
    

После выполнения любого действия программа должна возвращаться к главному меню, пока пользователь не выберет завершение работы.

Если пользователь вводит неизвестный пункт меню, программа должна сообщить об ошибке и предложить повторить ввод.

## Дополнительные требования

1. Для повторяющихся операций используй функции, например `show_products()`, `find_product()`, `sell_product()` и `show_statistics()`.
    
2. Для перебора товаров используй циклы.
    
3. Для принятия решений используй условные конструкции.
    
4. Не создавай отдельную переменную для каждого товара — храни товары в списке словарей.
    
5. Используй множество для получения уникальных категорий.
    
6. Следи за тем, чтобы изменения количества товара сохранялись в исходном списке.
    
7. Добавь комментарии к наиболее важным участкам программы.
    

## Дополнительное задание повышенной сложности

Реализуй корзину покупателя.

Пользователь может добавить несколько товаров в корзину, указав их идентификаторы и количество. После завершения выбора программа должна вывести состав корзины, стоимость каждой позиции и общую сумму заказа.

Пользователь должен иметь возможность удалить товар из корзины до оформления заказа.

При оформлении заказа необходимо повторно проверить наличие нужного количества товаров на складе и списать проданное количество только после успешной проверки всех позиций.

## Результат работы

В результате должна получиться консольная программа учёта товаров, в которой можно просматривать ассортимент, искать и фильтровать товары, изменять остатки, оформлять продажи, получать статистику и сортировать данные.

Работа должна выполняться с помощью изученных структур данных и конструкций Python без использования сторонних библиотек.
