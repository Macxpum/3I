
**Тема:** Модули, пакеты и импорты в Python.

**Цель работы:** научиться создавать собственные библиотеки Python, организовывать код по модулям, использовать стандартные библиотеки языка и реализовывать функции, которые могут применяться при разработке серверных приложений.

### 1. Постановка задачи

Вам необходимо разработать собственную мини-библиотеку на Python, которая будет содержать набор полезных инструментов для решения определённых задач.

В качестве основы можно использовать стандартные модули Python (`math`, `random`, `datetime`, `json`, `re`, `uuid` и другие), дополняя их собственными функциями.

Ваша библиотека должна решать конкретную задачу или объединять несколько близких по смыслу задач.

**Важно:** библиотека должна содержать самостоятельно разработанные функции, а не просто импортировать и переименовывать стандартные функции Python.

### 2. Выбор направления библиотеки

Вы можете самостоятельно придумать назначение библиотеки или выбрать одно из предложенных направлений.

**Вариант 5. Собственная идея**

Вы можете предложить собственную библиотеку, если её назначение понятно и она содержит функции, которые могут быть полезны при разработке программ или серверных приложений.

### 3. Технические требования

Разрабатываемая библиотека должна соответствовать следующим требованиям:

1. Библиотека должна содержать файл инициализирующий библиотеку, и файлы относящиеся к коду функций.
    
2. В библиотеке должно быть реализовано не менее **5 собственных функций**.
    
3. Функции должны принимать аргументы и возвращать результаты там, где это необходимо.
    
4. Необходимо предусмотреть обработку некорректных входных данных.
    
5. Названия функций и переменных должны отражать их назначение.
    
6. Должна быть предусмотрена возможность импортировать функции библиотеки в другой Python-файл.
    
7. Необходимо продемонстрировать работу библиотеки на нескольких примерах.
    

### 4. Пример структуры проекта

Один из возможных вариантов организации библиотеки:

```
MyLibrary/
│
├── __init__.py
│
├── user_tools.py
│
├── math_tools.py
│
└── date_tools.py

main.py
```

Файл `__init__.py` может использоваться для организации импорта функций из отдельных модулей.

Например:

```python
from .user_tools import check_login, generate_password
from .math_tools import solve_quadratic
```

После этого в другом файле можно использовать:

```python
from MyLibrary import check_login, generate_password

print(check_login("student_123"))
print(generate_password(12))
```

### 5. Представление и защита библиотеки

После завершения разработки необходимо подготовить небольшую презентацию своей библиотеки.

При защите необходимо раскрыть следующие вопросы:

**1. Назначение библиотеки**

- Как называется ваша библиотека?
    
- Для решения каких задач она предназначена?
    
- Для кого она может быть полезна?
    

**2. Возможности библиотеки**

- Какие функции реализованы?
    
- Какие стандартные модули Python используются?
    
- За что отвечает каждый модуль вашей библиотеки?
    

**3. Демонстрация работы**

- Показать минимум две реализованные функции.
    
- Продемонстрировать их работу на примерах.
    
- Показать, как библиотека импортируется и используется в другом Python-файле.
    

**4. Практическая ценность**

- Почему ваша библиотека может быть полезна другим разработчикам?
    
- В каких программах или серверных приложениях её можно использовать?
    
- Какую проблему она помогает решить?
    
- Что можно было бы добавить в библиотеку в будущем?
    

### 6. Результат работы

По итогам практической работы необходимо предоставить:

- папку с исходным кодом библиотеки;
    
- файл `main.py`, демонстрирующий её использование;
    
- краткую презентацию или устное представление проекта.
    

**Главное условие:** библиотека должна быть самостоятельной разработкой студента. Допускается использование стандартных возможностей Python, но основная логика функций должна быть написана самостоятельно.
