## Задание 1. Создание класса Student

Создайте файл `student.py`.

В нем необходимо реализовать класс `Student`, который будет описывать студента.

Класс должен содержать следующие атрибуты:

|Атрибут|Тип данных|Описание|
|---|---|---|

2. Используйте `self` для обращения к атрибутам объекта.
    
3. Реализуйте метод `show_info()`, который выводит информацию о студенте.

7. Реализуйте метод `__str__()`, который возвращает строковое представление студента.


```python

        if average >= 4.5:
```

## Задание 7. Защита программы от ошибок

Добавьте обработку исключений в программу.

### Необходимо обработать следующие ситуации

|Ситуация|Что необходимо сделать|
|---|---|
|Пользователь вводит вместо возраста текст|Вывести сообщение об ошибке|
|Пользователь вводит некорректный ID|Обработать ошибку|
|Пользователь вводит оценку меньше 2 или больше 5|Запретить добавление|

|Пользователь вводит неправильный пункт меню|Вывести предупреждение|
|Файл не существует|Обработать отсутствие файла|
|Файл содержит некорректные данные|Вывести сообщение об ошибке|

Используйте:

```python
try:
    # Код, который может вызвать ошибку
    pass
except ValueError:
    print("Ошибка ввода данных")
except FileNotFoundError:
    print("Файл не найден")
except Exception as error:
    print("Произошла ошибка:", error)
```

Важно: не используйте `except` без указания типа исключения для всех операций подряд. Обрабатывайте конкретные ошибки там, где это возможно.
