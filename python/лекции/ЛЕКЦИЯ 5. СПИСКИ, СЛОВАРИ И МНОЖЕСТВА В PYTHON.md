
## 5.1. Что такое структура данных

Структуры данных предназначены для хранения и организации нескольких значений.

Например, если необходимо сохранить имена пяти студентов, можно создать пять отдельных переменных. Но при большом количестве записей такой способ становится неудобным.

Для этого используют коллекции.

Основные структуры данных, которые рассматриваются в этой лекции:

- `list` — список;
    
- `dict` — словарь;
    
- `set` — множество.
    

Каждая структура предназначена для своих задач.

## 5.2. Списки `list`

Список — упорядоченная изменяемая коллекция элементов.

```python
numbers = [10, 20, 30, 40]
names = ["Иван", "Мария", "Алексей"]
mixed = [10, "Python", True]
```

Список может содержать значения разных типов, хотя на практике часто удобнее хранить в одном списке элементы одного назначения.

Список сохраняет порядок элементов и допускает повторения.

```python
numbers = [10, 20, 10, 30]
```

Здесь число 10 встречается два раза.

### Индексы

Каждый элемент списка имеет индекс. Индексация начинается с нуля.

```python
fruits = ["яблоко", "банан", "груша"]

print(fruits[0])
print(fruits[1])
print(fruits[2])
```

Результат:

```python
'яблоко'
'банан'
'груша'
```

Последний элемент можно получить с помощью отрицательного индекса:

```python
print(fruits[-1])
```

Результат:

```python
'груша'
```

`-1` обозначает последний элемент, `-2` — предпоследний.

Обращение к несуществующему индексу вызывает `IndexError`.

### Изменение элементов

Список изменяемый, поэтому его элементы можно заменять:

```python
fruits = ["яблоко", "банан", "груша"]

fruits[1] = "апельсин"

print(fruits)
```

Результат:

```python
['яблоко', 'апельсин', 'груша']
```

### Добавление элементов

Метод `append()` добавляет один элемент в конец списка:

```python
numbers = [10, 20, 30]

numbers.append(40)

print(numbers)
```

Метод `extend()` добавляет элементы другой последовательности:

```python
numbers = [10, 20]
numbers.extend([30, 40])

print(numbers)
```

Метод `insert()` вставляет элемент по указанному индексу:

```python
numbers = [10, 30]
numbers.insert(1, 20)

print(numbers)
```

### Удаление элементов

`remove()` удаляет первое найденное совпадение значения:

```python
numbers = [10, 20, 30]
numbers.remove(20)
```

`pop()` удаляет и возвращает элемент по индексу. Если индекс не указан, удаляется последний элемент.

```python
numbers = [10, 20, 30]

last = numbers.pop()

print(last)
print(numbers)
```

`del` удаляет элемент или срез по индексу:

```python
numbers = [10, 20, 30, 40]

del numbers[1]
```

Метод `clear()` удаляет все элементы списка:

```python
numbers.clear()
```

### Длина списка

Функция `len()` возвращает количество элементов.

```python
numbers = [10, 20, 30]

print(len(numbers))
```

Результат:

```python
3
```

### Проверка наличия элемента

```python
fruits = ["яблоко", "банан", "груша"]

print("банан" in fruits)
```

Результат — `True`.

### Срезы

Срез позволяет получить часть списка.
v
```python
numbers = [10, 20, 30, 40, 50]

print(numbers[1:4])
```

Результат:

```python
[20, 30, 40]
```

Верхняя граница среза не включается.

Также можно задавать шаг:

```python
print(numbers[::2])
```

Результат:

```python
[10, 30, 50]
```

Срез `numbers[::-1]` возвращает элементы в обратном порядке.

### Сортировка списка

Метод `sort()` сортирует список на месте:

```python
numbers = [5, 2, 10, 1]

numbers.sort()

print(numbers)
```

Результат:

```python
[1, 2, 5, 10]
```

Для сортировки по убыванию применяется `reverse=True`:

```python
numbers.sort(reverse=True)
```

Функция `sorted()` возвращает новый отсортированный список, не изменяя исходную последовательность:

```python
numbers = [5, 2, 10, 1]

result = sorted(numbers)
```

По умолчанию элементы сортируются по возрастанию. Для смешанных значений разных типов, например чисел и строк, прямое сравнение обычно невозможно, поэтому сортировка может вызвать `TypeError`.

## 5.3. Перебор списков

Для обработки всех элементов используется цикл `for`.

```python
names = ["Иван", "Мария", "Алексей"]

for name in names:
    print(name)
```

Списки часто применяются для хранения товаров, студентов, оценок, заказов и результатов вычислений.

### Списковые включения

Списковое включение (_list comprehension_) позволяет компактно создавать новый список на основе последовательности.

```python
numbers = [1, 2, 3, 4, 5]

squares = [number ** 2 for number in numbers]

print(squares)
```

Результат:

```python
[1, 4, 9, 16, 25]
```

Можно включать условие фильтрации:

```python
numbers = [1, 2, 3, 4, 5, 6]

even_numbers = [number for number in numbers if number % 2 == 0]
```

Результат:

```python
[2, 4, 6]
```

Списковые включения полезны для простого преобразования и фильтрации. Для сложной логики обычный цикл может быть понятнее.

## 5.4. Словари `dict`

Словарь хранит данные в виде пар «ключ — значение».

```python
student = {
    "name": "Иван",
    "age": 18,
    "group": "ИС-21"
}
```

Здесь:

- `name` — ключ;
    
- `"Иван"` — значение;
    
- `age` — ключ;
    
- `18` — значение.
    

Словарь удобен, когда необходимо связать данные с именованными характеристиками.

Например, для студента проще обращаться к `student["age"]`, чем запоминать, что возраст хранится в определённой позиции списка.

### Получение значений

```python
print(student["name"])
print(student["age"])
```

Если ключ отсутствует, обращение через квадратные скобки вызывает `KeyError`.

Метод `get()` позволяет безопасно получить значение:

```python
print(student.get("age"))
print(student.get("email"))
```

Если ключ отсутствует, `get()` возвращает `None`, если не указано другое значение по умолчанию.

```python
print(student.get("email", "Не указан"))
```

### Добавление и изменение

```python
student["age"] = 19
student["email"] = "student@example.com"
```

Если ключ уже существует, значение изменяется. Если ключа нет, он добавляется.

Метод `update()` позволяет добавить или изменить несколько пар:

```python
student.update({
    "age": 20,
    "group": "ИС-22"
})
```

### Удаление данных

```python
del student["email"]
```

Метод `pop()` удаляет элемент и возвращает его значение:

```python
age = student.pop("age")
```

Метод `clear()` очищает словарь.

### Перебор словаря

Перебор ключей:

```python
for key in student:
    print(key)
```

Перебор значений:

```python
for value in student.values():
    print(value)
```

Перебор пар «ключ — значение»:

```python
for key, value in student.items():
    print(key, value)
```

Метод `items()` особенно удобен для вывода и обработки всех характеристик объекта.

### Уникальность ключей

Ключи словаря должны быть уникальными. Если один и тот же ключ указан несколько раз при создании словаря, последнее значение заменяет предыдущие.

```python
data = {
    "age": 18,
    "age": 20
}

print(data)
```

В результате останется значение `20`.

В качестве ключей обычно используют строки, числа и другие хешируемые объекты. Списки и обычные словари нельзя использовать как ключи, поскольку они изменяемы и не являются хешируемыми.

### Вложенные словари

Словарь может содержать другие словари:

```python
students = {
    "ivan": {
        "name": "Иван",
        "age": 18
    },
    "maria": {
        "name": "Мария",
        "age": 19
    }
}
```

Получить возраст Ивана можно так:

```python
print(students["ivan"]["age"])
```

Такая структура удобна для представления сложных объектов и связанных данных.

## 5.5. Множества `set`

Множество — коллекция уникальных элементов без фиксированного порядка.

```python
numbers = {1, 2, 3, 3, 2}

print(numbers)
```

В результате останутся только уникальные значения.

Множества полезны для удаления дубликатов, проверки принадлежности и выполнения операций над группами элементов.

### Создание множества

```python
numbers = {1, 2, 3}
```

Для создания пустого множества необходимо использовать:

```python
numbers = set()
```

Запись `{}` создаёт пустой словарь, а не множество.

### Добавление и удаление

```python
numbers = {1, 2, 3}

numbers.add(4)
numbers.discard(2)
```

`add()` добавляет элемент. `discard()` удаляет элемент, если он существует, и не вызывает ошибку при его отсутствии.

Метод `remove()` тоже удаляет элемент, но вызывает `KeyError`, если элемент не найден.

### Удаление дубликатов из списка

```python
numbers = [1, 2, 2, 3, 3, 3]

unique_numbers = set(numbers)

print(unique_numbers)
```

Порядок элементов множества не гарантируется. Если нужен список уникальных значений с сохранением исходного порядка, можно использовать другой подход:

```python
numbers = [1, 2, 2, 3, 1]

unique_numbers = list(dict.fromkeys(numbers))

print(unique_numbers)
```

### Операции над множествами

Пусть имеются два множества:

```python
a = {1, 2, 3, 4}
b = {3, 4, 5, 6}
```

Объединение:

```python
print(a | b)
```

Результат — все уникальные элементы обоих множеств.

Пересечение:

```python
print(a & b)
```

Результат — элементы, присутствующие в обоих множествах.

Разность:

```python
print(a - b)
```

Результат — элементы, которые присутствуют в `a`, но отсутствуют в `b`.

Симметрическая разность:

```python
print(a ^ b)
```

Результат — элементы, присутствующие только в одном из двух множеств.

### Ограничения множеств

Элементы множества должны быть хешируемыми. Поэтому числа и строки можно добавлять напрямую, а списки и словари — нельзя.

## 5.6. Вложенные структуры данных

В Python коллекции можно комбинировать.

Например, список словарей:

```python
products = [
    {"name": "Мышь", "price": 1500},
    {"name": "Клавиатура", "price": 3000},
    {"name": "Монитор", "price": 12000}
]
```

Каждый элемент списка — словарь, описывающий отдельный товар.

Перебор:

```python
for product in products:
    print(product["name"], product["price"])
```

Фильтрация:

```python
for product in products:
    if product["price"] > 2000:
        print(product["name"])
```

Вложенные структуры позволяют представлять информацию, похожую на записи базы данных, JSON-объекты и ответы веб-сервисов.

## 5.7. Изменяемость и копирование

Списки, словари и множества являются изменяемыми объектами.

Рассмотрим:

```python
a = [1, 2, 3]
b = a

b.append(4)

print(a)
```

Результат:

```python
[1, 2, 3, 4]
```

Переменные `a` и `b` ссылаются на один список. Присваивание `b = a` не создаёт независимую копию.

Чтобы получить поверхностную копию списка:

```python
a = [1, 2, 3]
b = a.copy()
```

Теперь изменение внешнего списка `b` не изменит структуру списка `a`.

Однако для вложенных изменяемых объектов поверхностной копии может быть недостаточно.

```python
a = [[1, 2], [3, 4]]
b = a.copy()

b[0].append(5)
```

Внутренний список общий для обоих внешних списков, поэтому изменения будут видны через обе переменные.

Для глубокой копии используется модуль `copy`:

```python
import copy

a = [[1, 2], [3, 4]]
b = copy.deepcopy(a)
```

Глубокая копия рекурсивно копирует вложенные объекты в пределах возможностей механизма копирования.

## 5.8. Какую структуру выбирать

|Структура|Особенности|Когда использовать|
|---|---|---|
|`list`|Упорядоченная, изменяемая, допускает повторения|Набор товаров, оценки, последовательность действий|
|`dict`|Хранит пары ключ — значение|Данные пользователя, товар, настройки|
|`set`|Хранит уникальные элементы|Удаление дубликатов, поиск общих элементов|

Выбор структуры данных влияет на удобство хранения, изменения и поиска информации.

## 5.9. Итоги лекции

Списки, словари и множества — базовые структуры данных Python.

- Список хранит последовательность элементов.
    
- Словарь связывает ключи со значениями.
    
- Множество хранит уникальные элементы.
    
- Коллекции можно вкладывать друг в друга.
    
- Списки и словари изменяемы.
    
- Присваивание переменной другой переменной не обязательно создаёт копию объекта.
    
- Для обработки коллекций применяются циклы, условия и списковые включения.
