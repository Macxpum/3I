
## 1. Что такое объектно-ориентированное программирование

До этого момента мы изучали Python преимущественно с точки зрения процедурного программирования.

Процедурное программирование — это подход, при котором программа состоит из последовательности действий, функций и данных, обрабатываемых этими функциями.

Например, представим систему управления пользователями:

```python
user_name = "Алексей"
user_age = 20
user_email = "alex@example.com"

def print_user(name, age, email):
    print(f"Имя: {name}")
    print(f"Возраст: {age}")
    print(f"Email: {email}")

print_user(user_name, user_age, user_email)
```

Такой код работает, но при увеличении количества пользователей становится неудобным.

Предположим, нам необходимо хранить информацию о 100 пользователях. Для каждого из них потребуются имя, возраст, электронная почта и другие данные.

Мы можем использовать словари:

```
user = {    "name": "Алексей",    "age": 20,    "email": "alex@example.com"}
```

Однако словарь хранит только данные. Чтобы выполнять действия над пользователем, нам всё равно приходится создавать отдельные функции.

Объектно-ориентированное программирование предлагает объединить данные и действия над ними в одну логическую структуру.

Объектно-ориентированное программирование (ООП) — это подход к разработке программ, основанный на использовании объектов, которые объединяют данные и поведение.

Основными понятиями ООП являются:

- Класс — описание структуры и поведения объектов.
    
- Объект — конкретный экземпляр класса.
    
- Атрибут — данные, принадлежащие объекту или классу.
    
- Метод — функция, определённая внутри класса.
    

Рассмотрим схему.

Класс User

Атрибуты: name, age, email

Методы: show_info(), change_email()

Объект user1

Алексей, 20 лет

alex@example.com

Объект user2

Мария, 22 года

maria@example.com

Один класс описывает общую структуру, но каждый объект хранит собственные данные.

Класс можно сравнить с чертежом автомобиля. Чертёж описывает устройство автомобиля, но сам по себе автомобилем не является. На основе одного чертежа можно создать множество автомобилей.

Аналогично один класс Python может использоваться для создания множества объектов.

## 2. Классы и объекты

Для создания класса в Python используется ключевое слово `class`.

Общий синтаксис:

```python
class ClassName:    
	# Содержимое класса 
    pass
```

Название класса по соглашению записывается в стиле `PascalCase`, то есть каждое слово начинается с заглавной буквы.

Например:

```python
class User:
    pass
```

Мы создали класс `User`, но пока он не содержит никаких данных или методов.

Чтобы создать объект класса, необходимо вызвать его по имени:

```python
class User:
    pass

user1 = User()
user2 = User()
```

Здесь `user1` и `user2` — два разных объекта одного класса.

Проверим их тип:

```python
print(type(user1))
print(type(user2))
```

Результат:

```python
<class '__main__.User'>
<class '__main__.User'>
```

Оба объекта принадлежат классу `User`.

Но это разные экземпляры:

```python
print(user1 is user2)
```

Результат:

```python
False
```

Оператор `is` проверяет, являются ли две переменные ссылками на один и тот же объект.

### Для чего создавать несколько объектов?

Представим серверное приложение, в котором зарегистрировано несколько пользователей.

Каждый пользователь имеет собственные данные, но все пользователи обладают одинаковой структурой.

Вместо создания отдельных переменных для каждого пользователя мы можем создать один класс `User`, а затем создавать объекты по мере необходимости.

## 3. Атрибуты объектов

Атрибут — это переменная, связанная с объектом или классом.

Атрибуты используются для хранения информации.

Например, создадим класс `User` и добавим объекту имя и возраст:

```python
class User:
    pass
user1 = User()
user1.name = "Алексей"
user1.age = 20
print(user1.name)
print(user1.age)
```

Результат:

```
Алексей
20
```

Мы создали объект `user1` и добавили ему два атрибута.

Обращение к атрибутам выполняется через точку:

```python
user1.name
user1.age
```

Теперь создадим второй объект:

```python
user2 = User()
user2.name = "Мария"
user2.age = 22
```

Каждый объект хранит собственные значения атрибутов.

Однако у такого подхода есть недостаток.

Мы можем случайно забыть добавить один из атрибутов:

```python
user3 = User()
user3.name = "Иван"
print(user3.age)
```

В результате возникнет ошибка:

```bash
AttributeError: 'User' object has no attribute 'age'
```

Python сообщает, что у объекта отсутствует атрибут `age`.

Чтобы избежать подобных проблем и организовать создание объектов, используется специальный метод `__init__()`.

## 4. Конструктор `__init__()` и параметр `self`

В Python метод `__init__()` используется для инициализации объекта.

Он автоматически вызывается после создания экземпляра класса и позволяет задать начальные значения его атрибутов.

В учебной практике его часто называют конструктором, хотя технически создание экземпляра выполняет метод `__new__()`, а `__init__()` инициализирует уже созданный объект.

Рассмотрим пример:

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age
```

Теперь при создании объекта необходимо передать имя и возраст:

```python
user1 = User("Алексей", 20)
user2 = User("Мария", 22)
print(user1.name)
print(user2.age)
```

Результат:

```
Алексей
22
```

### Как работает `__init__()`?

Когда выполняется:

```python
user1 = User("Алексей", 20)
```

Python создаёт объект класса `User`, после чего вызывает его метод `__init__()`, передавая новый объект в качестве первого аргумента.

Затем выполняются инструкции:

```python
self.name = name
self.age = age
```

Таким образом, переданные значения сохраняются внутри объекта.

### Что такое `self`?

`self` — это общепринятое имя первого параметра методов экземпляра класса, через который метод получает доступ к конкретному объекту.

Например:

```python
self.name = name
```

означает: сохранить значение переменной `name` в атрибуте `name` текущего объекта.

Рассмотрим:

```python
class User:
    def __init__(self, name):
        self.name = name

user1 = User("Алексей")
user2 = User("Мария")
```

Когда создаётся `user1`, параметр `self` внутри `__init__()` ссылается на `user1`.

Когда создаётся `user2`, он ссылается на `user2`.

Именно поэтому разные объекты могут хранить собственные значения.

Важно: `self` не является ключевым словом Python. Однако использование именно этого имени — общепринятое соглашение, которого следует придерживаться.

### Значения параметров по умолчанию

Как и обычные функции, методы могут иметь параметры со значениями по умолчанию.

```python
class User:
    def __init__(self, name, age=18):
        self.name = name 
        self.age = age

user1 = User("Алексей", 20)
user2 = User("Мария")
print(user1.age)
print(user2.age)
```

Результат:

```
20
18
```

Если возраст не передан, используется значение по умолчанию.

## 5. Методы классов

До этого момента наши объекты только хранили информацию.

Однако ООП позволяет не только хранить данные, но и определять действия, которые объект может выполнять.

Метод — это функция, объявленная внутри класса.

Создадим метод, который выводит информацию о пользователе:

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        
    def show_info(self):
        print(f"Имя: {self.name}")
        print(f"Возраст: {self.age}")
```

Теперь создадим объект:

```python
user1 = User("Алексей", 20)
user1.show_info()
```

Результат:

```
Имя: Алексей
Возраст: 20
```

Обратите внимание: при вызове `show_info()` мы не передаём параметр `self` вручную.

Python автоматически связывает вызов метода с объектом, через который он был вызван.

### Методы, изменяющие состояние объекта

Методы могут не только получать данные, но и изменять их.

Например, добавим возможность изменить имя пользователя:

```python
class User:
    def __init__(self, name, age):
        self.name = name
        self.age = age
        
    def change_name(self, new_name):
        self.name = new_name
        
    def show_info(self):
        print(f"{self.name}, {self.age} лет")
```

Использование:

```python
user1 = User("Алексей", 20)
user1.show_info()
user1.change_name("Александр")
user1.show_info()
```

Результат:

```
Алексей, 20 лет
Александр, 20 лет
```

Метод `change_name()` изменил состояние объекта.

### Методы с возвращаемыми значениями

Методы могут возвращать значения с помощью `return`, как и обычные функции.

Например:

```python
class Rectangle:
    def __init__(self, width, height):
        self.width = width
        self.height = height
        
    def get_area(self):
        return self.width * self.height
        
    def get_perimeter(self):
        return 2 * (self.width + self.height)
```

Использование:

```python
rectangle = Rectangle(10, 5)
print(rectangle.get_area())
print(rectangle.get_perimeter())
```

Результат:

```
50
30
```

Этот пример показывает, что ООП подходит не только для пользователей или серверных приложений, но и для математических задач.

## 6. Атрибуты класса и атрибуты экземпляра

В Python существуют атрибуты, принадлежащие конкретному объекту, и атрибуты, определённые непосредственно в классе.

Рассмотрим пример:

```python
class User:
    platform = "MyWebsite"
    
    def __init__(self, name):
        self.name = name
```

Здесь:

- `platform` — атрибут класса;
    
- `name` — атрибут экземпляра.
    

Создадим два объекта:

```python
user1 = User("Алексей")
user2 = User("Мария")
print(user1.name)
print(user2.name)
print(user1.platform)
print(user2.platform)
```

Результат:

```
Алексей
Мария
MyWebsite
MyWebsite
```

Атрибут `platform` определён в классе и доступен обоим объектам.

При этом `name` хранится отдельно в каждом экземпляре.

Атрибут класса также можно получить через имя класса:

```python
print(User.platform)
```

### Изменение атрибута класса

```python
User.platform = "NewWebsite"
print(user1.platform)
print(user2.platform)
```

Оба объекта теперь будут получать новое значение `platform`, если у них нет собственного атрибута с таким именем.

Следует помнить, что присваивание через объект может создать отдельный атрибут экземпляра:

```python
user1.platform = "LocalWebsite"
```

Теперь `user1.platform` будет отличаться от `User.platform`.

### Когда использовать атрибуты класса?

Обычно они применяются для хранения общих настроек, констант и данных, относящихся ко всем экземплярам класса.

Однако изменяемые объекты, такие как списки и словари, в атрибутах класса требуют осторожности: один общий список может случайно использоваться всеми экземплярами.

## 7. Инкапсуляция

Инкапсуляция — один из основных принципов объектно-ориентированного программирования.

Она предполагает объединение данных и методов работы с ними, а также управление доступом к внутреннему состоянию объекта.

Представим, что мы разрабатываем банковскую систему.

У каждого банковского счёта есть баланс.

Если разрешить произвольно изменять баланс, это может привести к ошибкам:

```python
account.balance = -100000
```

Поэтому лучше предоставлять специальные методы для изменения состояния объекта.

### Пример инкапсуляции

```python
class BankAccount:
    def __init__(self, balance=0):
        if balance < 0:
            raise ValueError("Начальный баланс не может быть отрицательным") 
        self._balance = balance
        
    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Сумма должна быть положительной")
        self._balance += amount
        
    def get_balance(self):
        return self._balance
```

Использование:

```python
account = BankAccount(1000)
account.deposit(500)
print(account.get_balance())
```

Результат:

```
1500
```

Здесь изменение баланса происходит через метод `deposit()`.

### Что означает `_balance`?

В Python существуют соглашения по именованию атрибутов:

|Обозначение|Значение|
|---|---|
|`balance`|Обычный публичный атрибут|
|`_balance`|Атрибут для внутреннего использования|
|`__balance`|Атрибут с преобразованием имени (name mangling)|

Одинарное подчёркивание `_` не запрещает доступ к атрибуту, а сообщает другим разработчикам, что он предназначен для внутреннего использования.

Двойное подчёркивание `__` запускает механизм преобразования имени, но тоже не создаёт абсолютную защиту данных.

Python не использует строгую модель приватности, характерную для некоторых других языков программирования.

### Свойства `@property`

Python позволяет организовать контролируемый доступ к атрибутам через свойства.

```python
class User:
    def __init__(self, age):
        self.age = age

    @property    
    def age(self):
        return self._age
        
    @age.setter
    def age(self, value):
        if value < 0:
            raise ValueError("Возраст не может быть отрицательным") 
        self._age = value
```

Теперь можно обращаться к возрасту как к обычному атрибуту:

```python
user = User(20)print(user.age)user.age = 25print(user.age)
```

Но при попытке записать отрицательный возраст:

```python
user.age = -5
```

возникнет ошибка `ValueError`.

Свойства полезны, когда необходимо проверять данные при их изменении.

## 8. Наследование

Наследование — механизм, позволяющий создавать новые классы на основе существующих.

Новый класс получает доступ к поведению родительского класса и может дополнять или изменять его.

Представим серверное приложение, в котором существуют обычные пользователи и администраторы.

У обоих есть имя и электронная почта. Однако администратор обладает дополнительными возможностями.

Вместо дублирования общего кода можно использовать наследование.

User — родительский класс

name, email, show_info()

Admin

Наследует User

Дополнительно: delete_user()

Moderator

Наследует User

Дополнительно: block_user()

### Создание родительского класса

```python
class User:
    def __init__(self, name, email):
        self.name = name 
        self.email = email 
        
    def show_info(self):
        print(f"{self.name}: {self.email}")
```

### Создание дочернего класса

```python
class Admin(User):
    def delete_user(self, user_id):
        print(f"Удаление пользователя {user_id}")
```

Обратите внимание на запись:

```python
class Admin(User):
```

Она означает, что `Admin` наследуется от `User`.

Теперь создадим объект администратора:

```python
admin = Admin("Алексей", "admin@example.com")
admin.show_info()
admin.delete_user(15)
```

Результат:

```
Алексей: admin@example.com
Удаление пользователя 15
```

Хотя метод `show_info()` не был объявлен внутри класса `Admin`, он доступен благодаря наследованию.

Метод `delete_user()` в этом примере только выводит сообщение. В настоящем серверном приложении удаление пользователей потребовало бы проверки прав доступа и выполнения соответствующей операции с базой данных.

### Переопределение методов

Дочерний класс может изменять поведение методов родительского класса.

```python
class User:
    def show_role(self):
        print("Обычный пользователь")
class Admin(User):
    def show_role(self):
        print("Администратор")
```

Использование:

```python
user = User()
admin = Admin()
user.show_role()
admin.show_role()
```

Результат:

```
Обычный пользователь
Администратор
```

Это называется переопределением метода.

### Функция `super()`

Иногда необходимо дополнить поведение родительского класса, а не полностью заменять его.

Для этого используется `super()`.

```python
class User:
    def __init__(self, name):
        self.name = name
        
class Admin(User):
    def __init__(self, name, access_level):
        super().__init__(name)
        self.access_level = access_level
```

Использование:

```python
admin = Admin("Алексей", 5)
print(admin.name)
print(admin.access_level)
```

Результат:

```
Алексей
5
```

В данном случае `super().__init__(name)` вызывает инициализацию, определённую в родительском классе.

Таким образом, нам не пришлось повторно писать код присваивания имени.

## 9. Полиморфизм

Полиморфизм — возможность работать с разными объектами через общий интерфейс, при этом каждый объект может реализовывать собственное поведение.

Рассмотрим два класса:

```python
class EmailNotification:
    def send(self, message):
        print(f"Отправка Email: {message}")

class SMSNotification:
    def send(self, message):
        print(f"Отправка SMS: {message}")
```

Оба класса содержат метод `send()`, но выполняют разные действия.

Теперь создадим функцию:

```python
def send_notification(notification, message):
    notification.send(message)
```

Использование:

```python
email = EmailNotification()
sms = SMSNotification()
send_notification(email, "Регистрация успешна")
send_notification(sms, "Ваш код: 1234")
```

Результат:

```
Отправка Email: Регистрация успешна
Отправка SMS: Ваш код: 1234
```

Функции `send_notification()` неважно, какой именно объект передан, если у него есть подходящий метод `send()`.

Такой подход в Python также называют утиной типизацией (duck typing).

### Почему это полезно?

Представим, что серверное приложение должно отправлять уведомления через электронную почту, SMS и мессенджеры.

Вместо создания отдельных функций для каждого способа можно определить общий интерфейс `send()`.

Это упрощает расширение приложения: при добавлении нового способа отправки уведомлений не обязательно изменять код, который вызывает метод `send()`.

В нашем примере отправка только имитируется выводом в консоль. Для реальной отправки понадобятся соответствующие сервисы и библиотеки.

## 10. Магические методы

В Python существуют специальные методы, имена которых начинаются и заканчиваются двумя подчёркиваниями.

Их часто называют магическими методами или dunder methods.

С одним из них мы уже познакомились:

```python
__init__()
```

Однако существуют и другие.

Например:

|Метод|Назначение|
|---|---|
|`__init__()`|Инициализация объекта|
|`__str__()`|Удобное строковое представление|
|`__repr__()`|Представление объекта для разработчика|
|`__len__()`|Поддержка функции `len()`|
|`__eq__()`|Определение поведения оператора `==`|
|`__add__()`|Определение поведения оператора `+`|

### Метод `__str__()`

Рассмотрим класс:

```python
class User:
    def __init__(self, name, age):
        self.name = name   
        self.age = age
```

Создадим объект:

```python
user = User("Алексей", 20)
print(user)
```

По умолчанию Python выведет представление объекта, похожее на:

```
<__main__.User object at 0x...>
```

Такой вывод не очень удобен для пользователя.

Добавим метод `__str__()`:

```python
class User:
    def __init__(self, name, age):
            self.name = name 
            self.age = age 
    def __str__(self):
        return f"Пользователь {self.name}, возраст: {self.age}"
```

Теперь:

```python
user = User("Алексей", 20)
print(user)
```

Результат:

```
Пользователь Алексей, возраст: 20
```

Метод `__str__()` определяет, как объект будет преобразован в строку при использовании `str()` и, например, `print()`.

### Метод `__len__()`

Создадим класс, который хранит список пользователей:

```python
class UserCollection:
    def __init__(self):
        self.users = []
        
    def add_user(self, name):
        self.users.append(name)
        
    def __len__(self):  
        return len(self.users)
```

Использование:

```python
collection = UserCollection()
collection.add_user("Алексей")
collection.add_user("Мария")
collection.add_user("Иван")
print(len(collection))
```

Результат:

```
3
```

Теперь встроенная функция `len()` работает с нашим собственным классом.

Это позволяет создавать объекты, которые взаимодействуют со стандартными возможностями Python привычным способом.

## 11. Применение ООП в backend-разработке

Объектно-ориентированное программирование активно используется в серверной разработке.

Например, классы могут представлять:

- пользователей;
    
- товары;
    
- заказы;
    
- подключения к базам данных;
    
- сервисы обработки платежей;
    
- системы уведомлений;
    
- бизнес-логику приложения.
    

Рассмотрим пример небольшой системы управления товарами.

### Класс товара

```python
class Product:
    def __init__(self, product_id, name, price, stock):
        self.product_id = product_id  
        self.name = name
        self.price = price
        self.stock = stock
        
    def is_available(self):   
         return self.stock > 0
         
    def get_total_price(self, quantity):    
        if quantity <= 0:          
            raise ValueError("Количество должно быть положительным") 
        if quantity > self.stock: 
            raise ValueError("Недостаточно товара на складе")     
        return self.price * quantity
    def __str__(self):
        return f"{self.name} — {self.price} руб."
```

Создадим несколько товаров:

```python
product1 = Product(1, "Клавиатура", 2500, 10)
product2 = Product(2, "Мышь", 1200, 0)
```

Проверим наличие:

```python
print(product1.is_available())
print(product2.is_available())
```

Результат:

```
True
False
```

Рассчитаем стоимость трёх клавиатур:

```python
print(product1.get_total_price(3))
```

Результат:

```
7500
```

Выведем информацию о товаре:

```python
print(product1)
```

Результат:

```
Клавиатура — 2500 руб.
```

### Что даёт такой подход?

Мы создали класс, который объединяет данные о товаре и операции над ними.

Теперь для каждого нового товара достаточно создать объект:

```python
product3 = Product(3, "Монитор", 15000, 5)
product4 = Product(4, "Наушники", 3500, 12)
```

Все товары будут обладать одинаковой структурой и методами.

При разработке настоящего backend-приложения эти объекты могут использоваться в сервисном слое, взаимодействовать с базой данных или участвовать в обработке HTTP-запросов.

Например, обработчик API может получить идентификатор товара, запросить его данные из базы и вернуть клиенту результат.

При этом важно понимать, что ООП не является обязательным для каждой части backend-приложения. Некоторые задачи удобнее решать обычными функциями. Классы полезны тогда, когда они действительно помогают объединять связанные данные и поведение.

## 12. Четыре основных принципа ООП

В учебной литературе традиционно выделяют четыре основных принципа объектно-ориентированного программирования.

|Принцип|Суть|Пример|
|---|---|---|
|Абстракция|Выделение существенных свойств и поведения|Класс `User` описывает пользователя|
|Инкапсуляция|Объединение данных и методов, управление доступом|Баланс изменяется через `deposit()`|
|Наследование|Создание нового класса на основе существующего|`Admin` наследуется от `User`|
|Полиморфизм|Единый интерфейс для разных реализаций|Метод `send()` у разных уведомлений|

### Абстракция

Абстракция заключается в том, что мы выделяем только те характеристики объекта, которые важны для конкретной программы.

Например, в системе интернет-магазина пользователь может описываться именем, электронной почтой, идентификатором и ролью.

Нам необязательно хранить все возможные сведения о человеке. Мы выделяем только то, что необходимо для работы приложения.

На этом занятии мы познакомились с основами объектно-ориентированного программирования в Python.

Теперь необходимо понимать следующие понятия:

- Класс — описание структуры и поведения объектов.
    
- Объект — экземпляр класса с собственным состоянием.

- `__init__()` — метод инициализации объекта.
    
- Инкапсуляция — управление состоянием объекта через определённый интерфейс.
    
- Наследование — повторное использование и расширение поведения классов.
    
- Полиморфизм — работа с разными объектами через общий интерфейс.
    
- Магические методы — специальные методы, позволяющие объектам взаимодействовать с механизмами языка Python.
