## 6.1. Назначение функций

Функция — именованный блок кода, предназначенный для выполнения определённой задачи.

Функции помогают избегать повторения кода, разделять программу на логические части и повторно использовать реализованные операции.

Например, если необходимо трижды вывести одинаковое сообщение, можно создать функцию:

```python
def show_message():
    print("Добро пожаловать!")
```

Объявление функции само по себе не запускает её. Для выполнения необходимо вызвать её:

```python
show_message()
show_message()
show_message()
```

## 6.2. Синтаксис функции

Общая форма:

```python
def имя_функции():
    команды
```

Ключевое слово `def` объявляет функцию. После него указывается имя, круглые скобки и двоеточие.

Тело функции записывается с отступом.

Имена функций обычно оформляются в стиле `snake_case`:

```python
def calculate_total():
    pass
```

`pass` — команда-заглушка, которая позволяет оставить блок кода пустым.

## 6.3. Параметры и аргументы

Параметры позволяют передавать функции данные.

```python
def greet(name):
    print(f"Привет, {name}!")


greet("Иван")
greet("Мария")
```

`name` — параметр, а `"Иван"` и `"Мария"` — аргументы вызовов.

Функция выполняет одну операцию с разными значениями.

### Несколько параметров

```python
def calculate_sum(a, b):
    print(a + b)


calculate_sum(10, 5)
```

Значения передаются по позиции: первый аргумент соответствует первому параметру, второй — второму.

### Именованные аргументы

```python
def show_person(name, age):
    print(name, age)


show_person(age=18, name="Иван")
```

Именованные аргументы позволяют явно указать, какому параметру соответствует каждое значение.

## 6.4. Значения по умолчанию

Параметрам можно назначать значения по умолчанию.

```python
def greet(name="Гость"):
    print(f"Привет, {name}!")


greet()
greet("Иван")
```

Если аргумент не передан, используется значение по умолчанию.

Пример вычисления стоимости:

```python
def calculate_total(price, quantity=1):
    return price * quantity


print(calculate_total(500))
print(calculate_total(500, 3))
```

В первом вызове количество равно 1, во втором — 3.

Обязательные параметры обычно указывают перед параметрами со значениями по умолчанию.

Не следует использовать изменяемые значения по умолчанию, например `items=[]`, если требуется новый список при каждом вызове. Вместо этого часто применяют `None` и создают список внутри функции.

## 6.5. Возвращение результата: `return`

`return` возвращает результат из функции вызывающему коду.

```python
def calculate_sum(a, b):
    return a + b


result = calculate_sum(10, 5)

print(result)
```

Результат:

```python
15
```

Возвращаемое значение можно сохранить, передать другой функции или использовать в вычислениях.

### Отличие `print()` от `return`

`print()` выводит информацию на экран.

`return` возвращает значение.

```python
def show_sum(a, b):
    print(a + b)


def get_sum(a, b):
    return a + b
```

В первой функции результат выводится, но не возвращается. Во второй результат можно использовать дальше.

Если функция завершилась без выполнения `return` с конкретным значением, она возвращает `None`.

### Завершение функции

При выполнении `return` текущий вызов функции завершается. Команды после него не выполняются.

```python
def check_number(number):
    if number < 0:
        return "Отрицательное число"

    return "Неотрицательное число"
```

В зависимости от условия функция возвращает один из двух результатов.

## 6.6. Функции и списки

Функции удобно использовать для обработки коллекций.

```python
def calculate_sum(numbers):
    total = 0

    for number in numbers:
        total += number

    return total


result = calculate_sum([10, 20, 30])

print(result)
```

Результат:

```python
60
```

Функция принимает список, перебирает его элементы, вычисляет сумму и возвращает результат.

Другой пример — поиск максимального значения:

```python
def find_max(numbers):
    if len(numbers) == 0:
        return None

    maximum = numbers[0]

    for number in numbers:
        if number > maximum:
            maximum = number

    return maximum
```

В начале функция проверяет, не пуст ли список. Затем предполагает, что первый элемент — максимальный, и сравнивает с ним остальные элементы.

## 6.7. Локальные и глобальные переменные

Локальная переменная объявляется внутри функции и доступна в её области видимости.

```python
def calculate():
    number = 10
    print(number)
```

Переменная `number` в этом примере локальная.

Глобальная переменная объявляется за пределами функций:

```python
shop_name = "TechStore"


def show_shop():
    print(shop_name)
```

Функция может читать глобальную переменную, если она доступна в текущей области видимости.

Для изменения глобальной переменной используется `global`, однако злоупотреблять этим механизмом не рекомендуется. Часто лучше передавать значения через параметры и возвращать результат через `return`.

## 6.8. Передача списков и словарей в функции

Списки и словари являются изменяемыми объектами. Если функция меняет их содержимое, изменения могут сохраниться после завершения функции.

```python
numbers = [1, 2, 3]


def add_number(items):
    items.append(4)


add_number(numbers)

print(numbers)
```

Результат:

```python
[1, 2, 3, 4]
```

Параметр `items` ссылается на тот же объект списка.

Если функция не должна изменять исходные данные, можно создать копию:

```python
def add_number(items):
    result = items.copy()
    result.append(4)
    return result
```

Теперь исходный список не изменяется.

## 6.9. Функции и условия

Функции могут использовать `if`, `elif` и `else`.

```python
def is_adult(age):
    return age >= 18


print(is_adult(20))
print(is_adult(15))
```

Функция возвращает логическое значение.

Более сложный пример:

```python
def calculate_discount(price, discount):
    if price < 0 or discount < 0 or discount > 100:
        return None

    return price - price * discount / 100
```

Здесь функция сначала проверяет корректность данных, а затем рассчитывает стоимость.

## 6.10. Функции и словари

Рассмотрим список товаров:

```python
products = [
    {"name": "Мышь", "price": 1500, "quantity": 10},
    {"name": "Клавиатура", "price": 3000, "quantity": 5},
    {"name": "Монитор", "price": 12000, "quantity": 3}
]
```

Функция расчёта стоимости склада:

```python
def calculate_stock_value(products):
    total = 0

    for product in products:
        total += product["price"] * product["quantity"]

    return total
```

Функция принимает список словарей, обращается к полям каждого товара и суммирует стоимость всех единиц продукции.

Функция поиска товара:

```python
def find_product(products, name):
    for product in products:
        if product["name"].lower() == name.lower():
            return product

    return None
```

Если товар найден, функция возвращает словарь. Если перебор завершился без совпадения, возвращается `None`.

## 6.11. Анонимные функции `lambda`

`lambda` позволяет создать небольшую функцию, состоящую из одного выражения.

```python
square = lambda number: number ** 2

print(square(5))
```

Результат:

```python
25
```

Однако для сложных операций предпочтительнее обычные функции, объявленные через `def`.

Часто `lambda` используется для сортировки словарей по определённому полю:

```python
products = [
    {"name": "Мышь", "price": 1500},
    {"name": "Монитор", "price": 12000},
    {"name": "Клавиатура", "price": 3000}
]

sorted_products = sorted(
    products,
    key=lambda product: product["price"]
)
```

Здесь функция `lambda` возвращает цену каждого товара, и по этой цене выполняется сортировка.

## 6.12. Область видимости и рекурсия

Рекурсия — это ситуация, когда функция вызывает саму себя.

Например, вычисление факториала:

```python
def factorial(n):
    if n <= 1:
        return 1

    return n * factorial(n - 1)
```

Для положительного целого числа функция последовательно уменьшает аргумент, пока не достигнет базового случая `n <= 1`.

Базовый случай необходим для завершения рекурсии. Без него функция может вызывать себя до возникновения `RecursionError`.

Рекурсия полезна для некоторых алгоритмов, но не всегда является лучшим решением. Простые повторяющиеся вычисления часто удобнее реализовать с помощью циклов.

## 6.13. Документация функций

Для описания назначения функции используют документационные строки (_docstring_).

```python
def calculate_area(width, height):
    """Вычисляет площадь прямоугольника."""
    return width * height
```

Документационная строка располагается в начале тела функции и объясняет её назначение.

В больших программах полезно документировать параметры, возвращаемые значения и ограничения.

## 6.14. Принципы хорошей функции

Хорошая функция обычно:

- выполняет одну понятную задачу;
    
- имеет осмысленное имя;
    
- принимает только необходимые данные;
    
- возвращает результат, если он нужен вызывающему коду;
    
- корректно обрабатывает граничные случаи;
    
- не изменяет внешние данные без необходимости;
    
- не содержит избыточного повторения логики.
    

## 6.15. Итоги лекции

Функции позволяют строить программу из отдельных логических блоков.

- `def` объявляет функцию;
    
- параметры определяют, какие данные принимает функция;
    
- аргументы передаются при вызове;
    
- значения по умолчанию позволяют задавать стандартные параметры;
    
- `return` возвращает результат;
    
- локальные переменные доступны в пределах своей области видимости;
    
- списки и словари могут изменяться внутри функций;
    
- `lambda` полезна для коротких выражений;
    
- разделение программы на функции делает её понятнее и удобнее в сопровождении.
