
## 8.1. Зачем программе нужны файлы

До этого момента мы работали с данными, которые хранились в переменных.

```python
username = "Alex"
age = 20
print(username)
print(age)
```

Пока программа работает, значения доступны в памяти. Но после завершения программы эти переменные исчезают. При следующем запуске Python не будет знать, какие значения мы использовали раньше, если мы не сохранили их во внешнем источнике.

Для постоянного хранения данных можно использовать файлы или базы данных.

Например, файл может содержать:

- настройки программы;
    
- список пользователей;
    
- историю действий;
    
- текстовые документы;
    
- данные в формате JSON;
    
- изображения и другие загруженные файлы.
    

### 8.2. Память программы и постоянное хранение

Разница между переменной и файлом заключается в том, где находятся данные и как долго они сохраняются.

|Характеристика|Переменная|Файл|
|---|---|---|
|Где хранятся данные|В памяти процесса|В файловой системе|
|После завершения программы|Обычно теряются|Остаются|
|Как получить данные|Обратиться к имени переменной|Открыть и прочитать файл|
|Для чего используется|Текущие вычисления и состояние|Сохранение данных между запусками|

Например, если мы разрабатываем систему учёта оборудования колледжа, список оборудования можно временно хранить в списке Python:

```python
equipment = ["Компьютер", "Принтер", "Монитор"]
```

Но для сохранения этого списка между запусками его нужно записать в файл или базу данных.

Важно понимать, что файлы подходят для простого хранения данных, но не заменяют базу данных во всех задачах. В веб-приложениях с большим количеством пользователей, связями между данными и параллельными запросами обычно используют СУБД, например PostgreSQL.

## 8.3. Пути к файлам

Прежде чем открыть файл, программе нужно понять, где он находится. Для этого используются пути.

Допустим, структура проекта выглядит так:

```
python_project/
├── main.py
└── data/
    └── users.txt
```

Файл `users.txt` расположен внутри папки `data`, которая находится в папке проекта.

## `Относительный путь`

Относительный путь указывает расположение файла относительно текущей рабочей директории программы.

```python
file = open("data/users.txt", "r", encoding="utf-8")
```

Здесь `"data/users.txt"` — относительный путь.

Он означает: найти папку `data`, а в ней файл `users.txt`, начиная поиск из текущей рабочей директории.

Важный момент: относительный путь отсчитывается не обязательно от папки, в которой лежит файл `main.py`, а от текущей рабочей директории процесса.

Узнать текущую рабочую директорию можно с помощью модуля `os`:

```python
import osprint(os.getcwd())
```

Метод `os.getcwd()` возвращает путь к директории, из которой программа сейчас выполняется с точки зрения файловой системы.

Например, результат может выглядеть так:

```bash
C:\Users\Student\python_project
```

Если рабочая директория отличается от ожидаемой, Python может не найти файл, даже если тот действительно существует.

### `Абсолютный путь`

Абсолютный путь указывает полное расположение файла в файловой системе.

Пример для Windows:

```python
file = open(r"C:\Users\Student\python_project\data\users.txt", "r", encoding="utf-8")
```

Пример для Linux или macOS:

```python
file = open("/home/student/python_project/data/users.txt", "r", encoding="utf-8")
```

В примере Windows используется префикс `r` перед строкой:

```python
r"C:\Users\Student\data\users.txt"
```

Это так называемая сырая строка. Она помогает избежать проблем с обратными слешами, которые в обычных строках могут использоваться для специальных последовательностей.

Без сырой строки можно использовать двойные обратные слеши:

```python
path = "C:\\Users\\Student\\data\\users.txt"
```

Или прямые слеши, которые Python на Windows также обычно обрабатывает корректно:

```python
path = "C:/Users/Student/data/users.txt"
```

## Какой путь использовать?

|Тип пути|Пример|Особенность|
|---|---|---|
|Относительный|`data/users.txt`|Зависит от рабочей директории|
|Абсолютный|`C:/project/data/users.txt`|Указывает конкретное место|
|Путь через `pathlib`|`Path("data") / "users.txt"`|Удобнее собирать и обрабатывать пути программно|

В учебных проектах лучше привыкать к относительным путям и `pathlib`, чтобы приложение не зависело от конкретного имени пользователя или расположения папок на одном компьютере.

## 8.4. Открытие файлов с помощью `open()`

Для открытия файла в Python используется встроенная функция `open()`.

Общий синтаксис:

```python
open(file, mode="r", encoding=None)
```

Разберём основные параметры:

- `file` — путь к файлу;
    
- `mode` — режим открытия;
    
- `encoding` — кодировка текста.
    

Пример:

```python
file = open("users.txt", "r", encoding="utf-8")
```

Python пытается открыть файл `users.txt` для чтения в кодировке UTF-8. Если файл не существует, в обычном режиме чтения возникнет исключение `FileNotFoundError`.

Переменная `file` содержит объект файлового потока. Через него программа может читать данные, записывать информацию и получать сведения о состоянии файла.

###  `Чтение содержимого`

```python
file = open("users.txt", "r", encoding="utf-8")
content = file.read()
print(content)
file.close()
```

Что происходит:

1. `open()` открывает файл.
    
2. `file.read()` считывает его содержимое.
    
3. Результат сохраняется в переменной `content`.
    
4. `print()` выводит текст на экран.
    
5. `file.close()` закрывает файл.
    

Метод `close()` сообщает Python, что работа с файловым потоком завершена. Закрытие важно, потому что открытые файлы используют системные ресурсы, а незакрытая запись может привести к тому, что данные не будут своевременно сброшены на диск.

Однако вручную закрывать файл не всегда удобно. Позже мы рассмотрим конструкцию `with`, которая делает это автоматически.

## `Что возвращает read()`?

В текстовом режиме `read()` возвращает строку типа `str`.

Допустим, в файле находится:

```
Анна
Иван
Пётр
```

Тогда:

```python
file = open("users.txt", "r", encoding="utf-8")
content = file.read()
print(type(content))
print(content)
file.close()
```

Результат:

```
<class 'str'>
Анна
Иван
Пётр
```

Внутри строки сохраняются и символы переноса строки. Это важно, когда нужно разделять прочитанный текст на отдельные строки или обрабатывать его построчно.

## 8.5. Режимы открытия файлов

Параметр `mode` определяет, что программа собирается делать с файлом.

Основные режимы:

|Режим|Назначение|Если файла нет|
|---|---|---|
|`r`|Чтение|Возникает ошибка|
|`w`|Запись с очисткой старого содержимого|Файл создаётся|
|`a`|Добавление в конец|Файл создаётся|
|`x`|Создание нового файла|Файл создаётся; если уже существует, возникает ошибка|
|`b`|Бинарный режим|Сам по себе не определяет действие; комбинируется с другим режимом|
|`t`|Текстовый режим|Обычно используется по умолчанию|
|`+`|Чтение и запись|Поведение зависит от основной буквы режима|

###  Режим `r` — чтение

```python
file = open("users.txt", "r", encoding="utf-8")
```

Режим `r` предназначен для чтения существующего файла. Его содержимое не предназначено для изменения через этот поток.

Если файл отсутствует, Python выбросит исключение.

###  Режим `w` — запись

```python
file = open("users.txt", "w", encoding="utf-8")
file.write("Новый пользователь")
file.close()
```

Режим `w` создаёт файл, если его нет, а если файл уже существует — очищает его содержимое при открытии.

Это одна из самых важных особенностей файловой работы.

Предположим, в файле уже было:

```
Анна
Иван
Пётр
```

После открытия файла в режиме `w` и записи нового текста прежнее содержимое будет потеряно.

Поэтому этот режим нельзя использовать для добавления новых строк к существующему содержимому.

### Режим `a` — добавление

```python
file = open("users.txt", "a", encoding="utf-8")
file.write("\nМария")file.close()
```

Режим `a` открывает файл для добавления данных в конец. Если файла нет, он будет создан.

Если в файле уже записаны имена, новая запись не заменит их.

Обратите внимание на `\n` — символ переноса строки. Он нужен, чтобы имя `Мария` оказалось на новой строке, если предыдущий текст не завершался переносом строки.

###  Режим `x` — создание нового файла

```python
file = open("new_users.txt", "x", encoding="utf-8")
file.write("Первый пользователь")
file.close()
```

Режим `x` создаёт новый файл, но не позволяет случайно перезаписать уже существующий файл с таким именем.

Если файл уже существует, Python выбросит `FileExistsError`.

Этот режим полезен, когда перезапись существующих данных недопустима.

### Комбинированные режимы

Можно совместить основное действие с чтением или бинарным режимом:

- `r+` — чтение и запись существующего файла без автоматического удаления всего содержимого;
    
- `w+` — чтение и запись, но при открытии старое содержимое очищается;
    
- `a+` — чтение и добавление в конец;
    
- `rb` — чтение бинарных данных;
    
- `wb` — запись бинарных данных;
    
- `ab` — добавление бинарных данных.
    

При работе с режимами `+` необходимо учитывать положение курсора файла. Он определяет, откуда будут читаться данные и где будет происходить запись. Это поведение требует внимательного обращения, поэтому в начале обучения лучше использовать отдельные операции чтения и записи.

## 8.6. Чтение данных из файла

Мы уже познакомились с `read()`, который читает всё содержимое файла. Но в Python есть и другие способы чтения.

###  Метод `read()`

```python
with open("users.txt", "r", encoding="utf-8") as file:
    content = file.read()
	print(content)
```

Метод `read()` читает содержимое от текущей позиции курсора до конца файла.

Можно передать количество символов:

```python
with open("users.txt", "r", encoding="utf-8") as file:
    content = file.read(5)
    print(content)
```

Если файл содержит `Alexander`, результат будет:

```
Alexa
```

Здесь `5` означает количество символов, которые нужно прочитать в текстовом режиме, а не количество байтов.

Повторный вызов `read()` продолжит чтение с текущей позиции. Если первый вызов уже прочитал файл до конца, второй обычно вернёт пустую строку.

```python
with open("users.txt", "r", encoding="utf-8") as file:
    first = file.read()
    second = file.read()
    print(first)
    print(repr(second))
```

`repr()` позволяет увидеть представление строки. Для пустой строки результатом будет `''`.

### Метод `readline()`

Метод `readline()` читает одну строку за вызов.

Предположим, в `users.txt` записано:

```
Анна
Иван
Пётр
```

Код:

```python
with open("users.txt", "r", encoding="utf-8") as file:
    first_line = file.readline()
    second_line = file.readline()
    print(first_line)
    print(second_line)
```

Результат — первые две строки файла.

Обычно `readline()` сохраняет символ переноса строки `\n`, если он присутствует в файле. Поэтому при выводе могут возникать лишние пустые строки, если дополнительно использовать `print()`, который сам добавляет перенос строки.

Чтобы удалить пробельные символы с краёв строки, можно использовать `strip()`:

```python
with open("users.txt", "r", encoding="utf-8") as file:
	name = file.readline().strip()
	print(name)
```

`strip()` удаляет пробельные символы в начале и конце строки, в том числе переносы строк. При этом он может удалить и другие пробелы по краям, поэтому использовать его следует осознанно.

### Метод `readlines()`

Метод `readlines()` читает все строки файла и возвращает список строк.

```python
with open("users.txt", "r", encoding="utf-8") as file:
    users = file.readlines()
    print(users)
```

Если файл содержит три имени, результат будет примерно таким:

```python
['Анна\n', 'Иван\n', 'Пётр\n']
```

Обратите внимание: `readlines()` не возвращает список имён без дополнительных символов. Переносы строк обычно остаются в элементах списка.

Можно обработать результат:

```python
with open("users.txt", "r", encoding="utf-8") as file:   
	users = [line.strip() for line in file.readlines()]
	print(users)
```

Теперь получится:

```python
['Анна', 'Иван', 'Пётр']
```

Здесь используется уже знакомое выражение-генератор списка: каждая строка очищается от пробелов по краям и добавляется в новый список.

### Перебор файла в цикле

Для обработки текстового файла построчно часто удобнее всего использовать цикл `for`.

```python
with open("users.txt", "r", encoding="utf-8") as file:
	for line in file:
		print(line.strip())
```

Python последовательно читает строки файла, не загружая весь файл в один список заранее.

Этот подход особенно полезен при обработке больших текстовых файлов и журналов событий.

Что выбрать?

|Способ|Когда применять|
|---|---|
|`read()`|Нужно получить весь текст целиком|
|`read(size)`|Нужно прочитать ограниченное количество символов|
|`readline()`|Нужно прочитать одну строку|
|`readlines()`|Нужен список всех строк|
|`for line in file`|Нужно последовательно обработать строки|

## 8.7. Запись данных в файл

Чтобы сохранить данные, используется метод `write()`.

###  Метод `write()`

```python
with open("message.txt", "w", encoding="utf-8") as file:
	file.write("Привет, Python!")
```

Этот код создаёт файл `message.txt`, если его ещё нет, и записывает в него текст.

Если файл существует, его старое содержимое будет удалено, поскольку используется режим `w`.

Метод `write()` принимает строку и возвращает количество записанных символов.

```python
with open("message.txt", "w", encoding="utf-8") as file:
	result = file.write("Python")
	print(result)
```

Результат:

```
6
```

Сам метод `write()` не добавляет перенос строки автоматически. Если записать две строки подряд:

```python
with open("message.txt", "w", encoding="utf-8") as file:
	file.write("Первая строка")   
	file.write("Вторая строка")
```

Файл будет содержать:

```
Первая строкаВторая строка
```

Чтобы получить две отдельные строки, нужно добавить `\n`:

```python
with open("message.txt", "w", encoding="utf-8") as file:
    file.write("Первая строка\n")    
    file.write("Вторая строка\n")
```

### Запись переменных

В файлы часто записывают не только заранее подготовленный текст, но и значения переменных.

```python
username = "Алексей"
age = 19
with open("user.txt", "w", encoding="utf-8") as file: 
  file.write(f"Имя: {username}\n")    
  file.write(f"Возраст: {age}\n")
```

В этом примере используются знакомые f-строки. Они позволяют вставлять значения переменных непосредственно в текст.

Однако `write()` в текстовом режиме ожидает строку. Если передать число напрямую, например `file.write(19)`, возникнет `TypeError`. Число нужно преобразовать в строку или вставить в f-строку.

### Метод `writelines()`

Метод `writelines()` записывает последовательность строк.

```python
users = ["Анна\n", "Иван\n", "Пётр\n"]
with open("users.txt", "w", encoding="utf-8") as file:  
	file.writelines(users)
```

Каждый элемент списка будет записан в файл.

Важное отличие: `writelines()` не добавляет `\n` автоматически. Переносы строк нужно включить в сами элементы, если они нужны.

Например:

```python
users = ["Анна", "Иван", "Пётр"]
with open("users.txt", "w", encoding="utf-8") as file:   
	file.writelines(name + "\n" for name in users)
```

Здесь передаётся генератор выражений, который формирует строку с переносом для каждого имени.

###  Добавление данных в конец файла

Для накопления данных используется режим `a`.

```python
event = "Пользователь вошёл в систему"
with open("events.txt", "a", encoding="utf-8") as file:   
	file.write(event + "\n")
```

При каждом запуске этот код добавляет новую запись в конец файла, не удаляя старые.

Так можно реализовать простейший журнал событий (лог), хотя в реальных серверных приложениях для логирования обычно используют специализированный модуль `logging`.

## 8.8. Конструкция `with open()`

В предыдущих примерах мы использовали конструкцию:

```python
with open("users.txt", "r", encoding="utf-8") as file:    
	content = file.read()
```

Это один из самых важных шаблонов работы с файлами в Python.

###  Зачем нужен `with`?

При ручном открытии файла нужно не забыть закрыть его:

```python
file = open("users.txt", "r", encoding="utf-8")
content = file.read()
file.close()
```

Проблема заключается в том, что между открытием и закрытием может возникнуть ошибка. Если выполнение программы прервётся исключением, вызов `file.close()` может не выполниться.

Например:

```python
file = open("users.txt", "r", encoding="utf-8")
content = file.read()
result = 10 / 0
file.close()
```

Здесь возникает `ZeroDivisionError`. До `file.close()` выполнение не дойдёт.

###  Как работает `with`

```python
with open("users.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)
```

Конструкция `with` использует механизм управления ресурсами Python. Когда блок завершается — нормально или из-за исключения — файловый объект автоматически закрывается.

Разберём структуру:

- `with` начинает контекстный блок.
    
- `open(...)` создаёт файловый объект.
    
- `as file` связывает этот объект с переменной `file`.
    
- Двоеточие начинает блок команд.
    
- Отступ показывает, какие команды выполняются внутри блока.
    

После выхода из блока файл уже закрыт:

```python
with open("users.txt", "r", encoding="utf-8") as file:
    content = file.read()
    print(content)
```

Переменная `content` доступна после блока, поскольку она была создана вне зависимости от времени жизни файлового ресурса. А вот использовать `file` для чтения после закрытия нельзя.

Главное правило: при обычной работе с файлами в Python предпочитайте `with open()` ручному вызову `open()` и `close()`.

### Запись через `with`

Эта конструкция одинаково работает и при чтении, и при записи.

```python
with open("result.txt", "w", encoding="utf-8") as file:   
	file.write("Результат обработки данных")
```

После завершения блока Python корректно завершает работу с файловым потоком, в том числе выполняет необходимые действия для сброса буферизованных данных.

## 8.9. Кодировки и переносы строк

При работе с русским текстом важно понимать, как Python преобразует байты файла в символы.

### Что такое кодировка?

На диске текст хранится в виде байтов. Кодировка определяет, как эти байты соответствуют символам текста.

В Python текстовые файлы лучше открывать с явно указанной кодировкой, если формат файла её предполагает:

```python
with open("message.txt", "r", encoding="utf-8") as file: 
   text = file.read()
```

UTF-8 — широко используемая кодировка, поддерживающая русский, английский и другие языки.

Если файл был сохранён в другой кодировке, например Windows-1251, попытка прочитать его как UTF-8 может привести к ошибке `UnicodeDecodeError` или к неправильному отображению текста.

Параметр `encoding="utf-8"` не преобразует файл на диске заранее — он указывает Python, как декодировать прочитанные байты и кодировать записываемый текст.

### Удаление переноса строки

Если мы читаем файл построчно, часто требуется убрать окончание строки.

```python
with open("users.txt", "r", encoding="utf-8") as file:
	for line in file:
	    name = line.rstrip("\n")
        print(name)
```

`rstrip("\n")` удаляет символы `\n` справа от строки. В отличие от `strip()`, он не удаляет пробелы в начале и конце и не затрагивает пробелы слева.

Если необходимо удалить окончание строки независимо от того, представлено ли оно как `\n` или `\r\n`, можно использовать:

```python
name = line.rstrip("\r\n")
```

Выбор между `strip()` и `rstrip()` зависит от того, нужно ли сохранять пробелы, которые могут быть частью данных.

## 8.10. Обработка ошибок при работе с файлами

При работе с файловой системой ошибки вполне ожидаемы. Файл может отсутствовать, доступ к нему может быть запрещён, а его содержимое может иметь неожиданную кодировку.

Для обработки подобных ситуаций мы используем уже изученную конструкцию `try/except`.

### `FileNotFoundError` — файл не найден

```python
try:
with open("users.txt", "r", encoding="utf-8") as file:        
	content = file.read()
	print(content)
except FileNotFoundError:
	print("Файл не найден")
```

Если `users.txt` отсутствует, выполнение блока `try` прервётся при вызове `open()`, и управление перейдёт в `except`.

Это позволяет сообщить об ошибке, не завершая программу необработанным исключением.

###  `PermissionError` — недостаточно прав

```python
try:
    with open("protected.txt", "w", encoding="utf-8") as file:      
	    file.write("Новые данные")
except PermissionError:
	print("Нет разрешения на запись")
```

Ошибка может возникнуть, если у пользователя нет необходимых прав для записи в файл или каталог.

###  `UnicodeDecodeError` — ошибка декодирования

```python
try: 
   with open("data.txt", "r", encoding="utf-8") as file:        
	   content = file.read()
except UnicodeDecodeError:
    print("Не удалось прочитать файл в кодировке UTF-8")
```

Такое исключение возникает, когда байты файла не удаётся корректно декодировать с указанной кодировкой.

Правильное решение — определить реальную кодировку файла и использовать её, а не просто подставлять случайное значение.

###  `OSError` — ошибки операционной системы

`OSError` — базовый класс для многих ошибок взаимодействия с операционной системой, в том числе некоторых ошибок файловой системы.

```python
try:  
	  with open("report.txt", "w", encoding="utf-8") as file:
        file.write("Отчёт")
except OSError as error: 
   print(f"Ошибка при работе с файлом: {error}")
```

Здесь переменная `error` содержит объект исключения. В строковом представлении можно получить сообщение, помогающее определить причину проблемы.

Важно: `OSError` не перехватывает вообще все возможные ошибки. Например, `UnicodeDecodeError` и `TypeError` относятся к другим ветвям иерархии исключений.

## 8.11. Бинарные файлы

До этого мы работали с текстом. Но файлы могут содержать изображения, аудиозаписи, архивы, документы и другие данные, которые нельзя корректно обработать как обычный текст.

Для таких случаев существует бинарный режим.

### Текстовый и бинарный режимы

|Текстовый режим|Бинарный режим|
|---|---|
|`r`, `w`, `a`|`rb`, `wb`, `ab`|
|Читает и записывает текст|Читает и записывает байты|
|Может использовать `encoding`|Не использует `encoding`|
|Чтение возвращает `str`|Чтение возвращает `bytes`|

### Чтение бинарных данных

```python
with open("image.png", "rb") as file:
	content = file.read()
	print(type(content))
	print(len(content))
```

Переменная `content` будет содержать объект типа `bytes`.

Он представляет последовательность байтов, а не строку символов.

###  Копирование файла

```python
with open("source.bin", "rb") as source:
	content = source.read()
	with open("copy.bin", "wb") as destination:
		destination.write(content)
```

Здесь данные считываются из исходного файла как байты, а затем записываются в другой файл без попытки преобразовать их в текст.

Для больших файлов такой вариант загружает всё содержимое в память. В реальных приложениях часто используют копирование частями или стандартные средства вроде `shutil.copyfile()`.

В веб-разработке бинарный режим может понадобиться при обработке изображений и других загружаемых пользователями файлов.

## 8.12. Типичные ошибки при работе с файлами

Ошибка 1. Открытие несуществующего файла для чтения

Проблема:

```python
with open("unknown.txt", "r", encoding="utf-8") as file:
   print(file.read())
```

Исправление: проверить существование файла или обработать `FileNotFoundError`.

Ошибка 2. Потеря старого содержимого

Проблема: использование `w`, когда требовалось добавить текст.

```python
with open("log.txt", "w", encoding="utf-8") as file:
   file.write("Новое событие")
```

Исправление: использовать `a`, если нужно сохранить предыдущие записи.

Ошибка 3. Отсутствие переноса строки

Проблема: `write()` не разделяет последовательные записи автоматически.

```python
file.write("Анна")
file.write("Иван")
```

Исправление: добавить `\n`, если записи должны быть на разных строках.

Ошибка 4. Несовпадение кодировки

Проблема: файл прочитан не в той кодировке, в которой он сохранён.

Исправление: определить кодировку источника и корректно указать `encoding`.

Ошибка 5. Незакрытый файл

Проблема: ручное управление открытием и закрытием усложняет обработку ошибок.

Исправление: использовать `with open()`.
