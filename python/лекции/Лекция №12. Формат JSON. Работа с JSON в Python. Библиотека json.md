# **1. Что такое JSON**

При разработке программ часто возникает необходимость передавать информацию между различными приложениями или сохранять её в файл.

Например:

- передать информацию о пользователе с сайта на сервер;
    
- сохранить настройки программы;
    
- получить список товаров из интернет-магазина;
    
- передать данные между Python и JavaScript;
    
- сохранить результаты работы приложения.
    

Для решения таких задач используются специальные форматы представления данных.

Один из самых распространённых форматов — **JSON (JavaScript Object Notation)**.

JSON — это текстовый формат обмена данными, основанный на структуре объектов и массивов JavaScript.

Несмотря на то, что JSON появился на основе синтаксиса JavaScript, сегодня он используется практически во всех языках программирования.

Например:

- Python;
    
- JavaScript;
    
- PHP;
    
- Java;
    
- C#;
    
- Go;
    
- Ruby.
    

**Главная идея JSON:** представить данные в текстовом виде таким образом, чтобы их могли легко прочитать и обработать различные программы.

## **1.1. Пример JSON**

Представим, что нам необходимо сохранить информацию о студенте.

В формате JSON это будет выглядеть следующим образом:

```json
{
    "id": 1,
    "name": "Александр",
    "age": 19,
    "group": "ИС-23",
    "is_active": true
}
```

Здесь мы видим несколько пар ключ-значение:

- `id` — идентификатор;
    
- `name` — имя;
    
- `age` — возраст;
    
- `group` — учебная группа;
    
- `is_active` — статус активности.
    

Такая структура позволяет хранить связанные между собой данные в одном объекте.

## **1.2. Где используется JSON**

Рассмотрим несколько распространённых ситуаций.

**1. Обмен данными между клиентом и сервером.**

Например, пользователь заполняет форму регистрации. Браузер отправляет данные на сервер в формате JSON.

**2. Работа с API.**

Сервер предоставляет программный интерфейс, через который другие приложения могут получать и отправлять информацию.

**3. Хранение настроек.**

Программа может хранить параметры подключения, настройки интерфейса и другие данные в JSON-файле.

**4. Хранение небольших наборов данных.**

Например, список пользователей, товаров или результатов тестирования.
# **2. Структура и синтаксис JSON**

JSON имеет достаточно простой синтаксис, но при его использовании необходимо соблюдать определённые правила.

Основными структурными элементами JSON являются:

1. Объекты.
    
2. Массивы.

## **2.1. Объекты**

Объект JSON — это набор пар ключ-значение, заключённый в фигурные скобки `{}`.

Пример:

```json
{
    "name": "Иван",
    "age": 20,
    "city": "Москва"
}
```

Каждая пара состоит из двух элементов:

```
"ключ": "значение"
```

Пары разделяются запятыми.

Важно соблюдать правила:

- ключи обязательно записываются в двойных кавычках;
    
- между ключом и значением ставится двоеточие;
    
- между парами ставится запятая;
    
- после последней пары запятая не ставится.
    

Неправильный пример:

```json
{
    name: "Иван",
    "age": 20,
}
```

Здесь две ошибки:

- ключ `name` не заключён в двойные кавычки;
    
- после последнего элемента стоит лишняя запятая.
    

## **2.2. Массивы**

Массив JSON — это упорядоченный набор значений, заключённый в квадратные скобки `[]`.

Пример:

```json
[
    "Иван",
    "Пётр",
    "Александр"
]
```

Массив может содержать числа:

```json
[
    10,
    20,
    30,
    40
]
```

Или объекты:

```json
[
    {
        "id": 1,
        "name": "Иван"
    },
    {
        "id": 2,
        "name": "Пётр"
    },
    {
        "id": 3,
        "name": "Александр"
    }
]
```

Последний пример особенно интересен: мы имеем массив, состоящий из нескольких объектов пользователей.

Подобная структура часто встречается при получении данных от API.

## **2.3. Вложенные структуры**

JSON позволяет создавать объекты внутри объектов и массивы внутри объектов.

Например:

```json
{
    "id": 1,
    "name": "Александр",
    "contacts": {
        "phone": "+79990000000",
        "email": "student@mail.ru"
    },
    "subjects": [
        "Python",
        "Базы данных",
        "Веб-разработка"
    ]
}
```

Здесь объект `contacts` содержит ещё один объект, а `subjects` является массивом строк.

Вложенность позволяет создавать сложные структуры данных.
# **3. Типы данных JSON**

JSON поддерживает ограниченное количество типов данных.

Всего существует шесть основных типов.

|Тип|Описание|Пример|
|---|---|---|
|String|Строка|`"Привет"`|
|Number|Число|`25`, `3.14`|
|Boolean|Логическое значение|`true`, `false`|
|Null|Отсутствие значения|`null`|
|Object|Объект|`{"name": "Иван"}`|
|Array|Массив|`[1, 2, 3]`|

Разберём особенности каждого типа.

**Строки (String)**

Строки обязательно записываются в двойных кавычках.

```json
{
    "name": "Иван",
    "city": "Москва"
}
```

**Числа (Number)**

JSON поддерживает целые и дробные числа.

```json
{
    "age": 19,
    "price": 1250.50
}
```

Важно: JSON не разделяет целые и дробные числа на отдельные типы так, как это делает Python.

**Логические значения (Boolean)**

Используются два значения:

```json
{
    "is_active": true,
    "is_admin": false
}
```

Обратите внимание: в JSON используются маленькие буквы `true` и `false`.

**Отсутствие значения (Null)**

Используется для обозначения отсутствующего значения.

```json
{
    "middle_name": null
}
```

**Объекты (Object)**

Позволяют объединять несколько значений в одну структуру.

**Массивы (Array)**

Позволяют хранить последовательность значений.

### **Важные правила JSON**

JSON не поддерживает:

- комментарии;
    
- одинарные кавычки для строк;
    
- `undefined`;
    
- функции;
    
- классы;
    
- кортежи как отдельный тип;
    
- множества (set).

Например, такой JSON некорректен:

```json
{
    // Имя пользователя
    "name": "Иван"
}
```

Комментарии в стандартном JSON запрещены.

# **4. Соответствие типов JSON и Python**

Теперь перейдём к Python.

В Python есть собственные типы данных. При работе с JSON программа должна преобразовывать данные из одного формата в другой.

Для этого существует соответствие типов.

|JSON|Python|
|---|---|
|Object|`dict`|
|Array|`list`|
|String|`str`|
|Number (целое)|`int`|
|Number (дробное)|`float`|
|Boolean|`bool`|
|Null|`None`|

Рассмотрим пример.

JSON:

```json
{
    "name": "Иван",
    "age": 20,
    "is_student": true,
    "average_score": 4.5,
    "middle_name": null
}
```

После преобразования в Python мы получим словарь:

```python
student = {
    "name": "Иван",
    "age": 20,
    "is_student": True,
    "average_score": 4.5,
    "middle_name": None
}
```

Обратите внимание на отличия:

- `true` превращается в `True`;
    
- `false` превращается в `False`;
    
- `null` превращается в `None`.

Это важно учитывать при передаче данных между разными языками программирования.

# **5. Библиотека json в Python**

В Python существует встроенная библиотека `json`, которая позволяет работать с JSON без установки дополнительных пакетов.

Для её использования достаточно импортировать модуль:

```python
import json
```

Библиотека предоставляет несколько основных функций:

|Функция|Назначение|
|---|---|
|`json.dumps()`|Преобразовать Python-объект в JSON-строку|
|`json.loads()`|Преобразовать JSON-строку в Python-объект|
|`json.dump()`|Записать Python-объект в JSON-файл|
|`json.load()`|Прочитать JSON-файл и получить Python-объект|

Особенно важно не путать эти функции.

Удобно запомнить:

- `s` в `dumps` и `loads` означает string — строку;
    
- отсутствие `s` в `dump` и `load` означает работу с файловым объектом.

Рассмотрим каждую функцию подробнее.

# **6. Преобразование Python-объектов в JSON**

## **6.1. Функция json.dumps()**

Функция `dumps()` преобразует Python-объект в JSON-строку.

Пример:

```python
import json

student = {
    "name": "Александр",
    "age": 19,
    "group": "ИС-23",
    "is_active": True
}

json_data = json.dumps(student)

print(json_data)
print(type(json_data))
```

Результат:

```
{"name": "Александр", "age": 19, "group": "ИС-23", "is_active": true}

<class 'str'>
```

Что произошло?

1. Создали обычный Python-словарь.
    
2. Передали его в `json.dumps()`.
    
3. Получили строку в формате JSON.

Теперь эту строку можно отправить по сети, записать в текстовый файл или передать другой программе.

## **6.2. Параметр ensure_ascii**

По умолчанию библиотека может представлять символы, отсутствующие в ASCII, через специальные Unicode-последовательности.

Например, кириллица может выглядеть следующим образом:

```bash
{"name": "\u0418\u0432\u0430\u043d"}
```

Чтобы сохранить читаемый русский текст, используется параметр `ensure_ascii=False`.

```python
json_data = json.dumps(
    student,
    ensure_ascii=False
)

print(json_data)
```

Теперь результат будет выглядеть привычно:

```bash
{"name": "Александр", "age": 19, "group": "ИС-23", "is_active": true}
```

## **6.3. Параметр indent**

По умолчанию JSON может записываться в одну строку.

Чтобы сделать структуру более читаемой, используется параметр `indent`.

```python
json_data = json.dumps(
    student,
    ensure_ascii=False,
    indent=4
)

print(json_data)
```

Результат:

```json
{
    "name": "Александр",
    "age": 19,
    "group": "ИС-23",
    "is_active": true
}
```

Число `4` указывает количество пробелов для каждого уровня вложенности.

Это удобно при сохранении настроек и просмотре больших JSON-структур.

# **7. Преобразование JSON в Python**

## **7.1. Функция json.loads()**

Функция `loads()` выполняет обратное действие: преобразует JSON-строку в Python-объект.

Пример:

```python
import json

json_data = '''
{
    "name": "Иван",
    "age": 20,
    "group": "ИС-23",
    "is_active": true
}
'''

student = json.loads(json_data)

print(student)
print(type(student))
```

Результат:

```sh
{'name': 'Иван', 'age': 20, 'group': 'ИС-23', 'is_active': True}

<class 'dict'>
```

Теперь мы можем работать с данными как с обычным словарём Python.

Например:

```python
print(student["name"])
print(student["age"])
```

Результат:

```
Иван
20
```

Можно изменять данные:

```python
student["age"] = 21

student["city"] = "Москва"

print(student)
```

То есть после преобразования JSON мы получаем полноценный Python-объект, с которым можем работать привычными средствами языка.

# **8. Работа с JSON-файлами**

Одна из наиболее полезных возможностей JSON — хранение данных в файлах.

Представим, что мы разрабатываем программу, которая хранит информацию о студентах.

Вместо того чтобы каждый раз создавать список пользователей заново, мы можем сохранять его в файл.

Например, создадим файл:

`students.json`

Его содержимое:

```json
[
    {
        "id": 1,
        "name": "Иван",
        "group": "ИС-23"
    },
    {
        "id": 2,
        "name": "Пётр",
        "group": "ИС-24"
    }
]
```

Теперь рассмотрим запись данных в файл.

## **8.1. Функция json.dump()**

Функция `dump()` записывает Python-объект непосредственно в открытый файл.

```python
import json

students = [
    {
        "id": 1,
        "name": "Иван",
        "group": "ИС-23"
    },
    {
        "id": 2,
        "name": "Пётр",
        "group": "ИС-24"
    }
]

with open("students.json", "w", encoding="utf-8") as file:
    json.dump(
        students,
        file,
        ensure_ascii=False,
        indent=4
    )
```

Разберём этот код:

- `open()` открывает файл;
    
- `"w"` означает режим записи;
    
- `encoding="utf-8"` позволяет корректно сохранять русский текст;
    
- `json.dump()` записывает данные;
    
- `ensure_ascii=False` сохраняет кириллицу;
    
- `indent=4` делает файл читаемым.
    

Если файл не существует, Python создаст его автоматически.

Если файл уже существует, его содержимое будет перезаписано.

## **8.2. Функция json.load()**

Теперь научимся читать данные из JSON-файла.

```python
import json

with open("students.json", "r", encoding="utf-8") as file:
    students = json.load(file)

print(students)
```

После выполнения мы получим обычный Python-список словарей.

Теперь можно перебирать студентов:

```python
for student in students:
    print(student["name"], student["group"])
```

Результат:

```sh
Иван ИС-23
Пётр ИС-24
```

## **8.3. Добавление данных в JSON-файл**

Здесь есть важный момент.

JSON не поддерживает непосредственное добавление элементов в конец файла, как обычный текстовый файл.

Чтобы добавить нового студента, необходимо:

1. Прочитать существующие данные.
    
2. Добавить новый элемент в список.
    
3. Записать обновлённый список обратно в файл.


Пример:

```python
import json

# Читаем существующие данные
with open("students.json", "r", encoding="utf-8") as file:
    students = json.load(file)

# Добавляем нового студента
new_student = {
    "id": 3,
    "name": "Александр",
    "group": "ИС-25"
}

students.append(new_student)

# Записываем обновлённые данные
with open("students.json", "w", encoding="utf-8") as file:
    json.dump(
        students,
        file,
        ensure_ascii=False,
        indent=4
    )
```

Таким образом, можно реализовать простое хранилище данных без использования базы данных.

Но следует понимать, что JSON-файлы подходят преимущественно для небольших объёмов информации и простых задач. Для многопользовательских приложений и большого количества данных лучше использовать полноценную базу данных.

# **9. Работа с вложенными JSON-структурами**

На практике JSON часто содержит достаточно сложные структуры.

Например:

```json
{
    "id": 1,
    "name": "Александр",
    "group": "ИС-23",
    "contacts": {
        "phone": "+79990000000",
        "email": "student@mail.ru"
    },
    "grades": [
        5,
        4,
        5,
        3
    ]
}
```

После загрузки такого JSON в Python мы получаем вложенные словари и списки.

Обращаться к данным можно следующим образом:

```python
student["name"]

student["contacts"]["email"]

student["grades"][0]
```

Результаты:

```sh
Александр
student@mail.ru
5
```

Можно изменять вложенные значения:

```python
student["contacts"]["phone"] = "+78880000000"

student["grades"].append(5)
```

Также можно перебирать вложенные массивы:

```python
for grade in student["grades"]:
    print(grade)
```

Это особенно важно при работе с API, потому что ответы серверов часто содержат сложные вложенные структуры.

# **10. Обработка ошибок при работе с JSON**

При работе с JSON необходимо учитывать, что данные могут быть некорректными.

Например, пользователь может вручную изменить файл и случайно нарушить его структуру.

Рассмотрим неправильный JSON:

```json
{
    "name": "Иван",
    "age": 20,
}
```

Здесь после последнего элемента стоит лишняя запятая.

При попытке прочитать такую строку Python вызовет исключение.

Для обработки подобных ситуаций используется `try-except`.

```python
import json

json_data = '{"name": "Иван", "age": 20,}'

try:
    student = json.loads(json_data)
    print(student)

except json.JSONDecodeError:
    print("Ошибка: некорректный формат JSON")
```

В данном случае программа не завершится аварийно, а выведет сообщение об ошибке.

## **10.1. Основные ошибки**

|Ошибка|Причина|
|---|---|
|`JSONDecodeError`|Некорректная JSON-строка или содержимое файла|
|`FileNotFoundError`|Файл не найден|
|`PermissionError`|Недостаточно прав для доступа к файлу|
|`TypeError`|Объект невозможно преобразовать в JSON стандартным способом|

Например, попробуем сохранить объект `set`:

```python
import json

numbers = {1, 2, 3}

json_data = json.dumps(numbers)
```

Возникнет `TypeError`, потому что множество `set` не поддерживается JSON напрямую.

# **11. Практическое применение JSON в веб-разработке**

Теперь рассмотрим, зачем будущему веб-разработчику необходимо знать JSON.

Представим, что у нас есть веб-приложение на Python, которое должно возвращать информацию о пользователях.

Сервер формирует словарь:

```python
user = {
    "id": 1,
    "name": "Александр",
    "role": "student"
}
```

Затем преобразует его в JSON и отправляет клиенту.

Браузер получает:

```json
{
    "id": 1,
    "name": "Александр",
    "role": "student"
}
```

JavaScript может обработать полученные данные:

```json
const user = {
    "id": 1,
    "name": "Александр",
    "role": "student"
};

console.log(user.name);
```

Таким образом, Python и JavaScript могут обмениваться данными, несмотря на то, что используют разные языки программирования.

**Важный вывод:** JSON является одним из основных форматов обмена данными между Frontend и Backend. Поэтому он постоянно используется при разработке REST API, мобильных приложений и веб-сервисов.

# **12. Дополнительные возможности библиотеки json**

Для более полного понимания библиотеки рассмотрим ещё несколько полезных возможностей.

## **12.1. Проверка корректности JSON**

Можно попробовать преобразовать строку в Python-объект. Если ошибок нет, значит, синтаксис JSON корректен.

```python
import json

data = '{"name": "Иван", "age": 20}'

try:
    json.loads(data)
    print("JSON корректен")

except json.JSONDecodeError:
    print("JSON содержит ошибку")
```

## **12.2. Сортировка ключей**

Параметр `sort_keys=True` позволяет сортировать ключи по алфавиту.

```python
import json

data = {
    "name": "Иван",
    "age": 20,
    "city": "Москва"
}

result = json.dumps(
    data,
    ensure_ascii=False,
    indent=4,
    sort_keys=True
)

print(result)
```

## **12.3. Преобразование пользовательских объектов**

Стандартный JSON не умеет напрямую сохранять экземпляры пользовательских классов Python.

Например:

```python
class Student:
    def __init__(self, name, age):
        self.name = name
        self.age = age


student = Student("Иван", 20)
```

Попытка выполнить:

```python
json.dumps(student)
```

вызовет `TypeError`.

Но мы можем самостоятельно определить, какие данные объекта необходимо сохранить.

Например:

```python
json_data = json.dumps(
    student.__dict__,
    ensure_ascii=False,
    indent=4
)

print(json_data)
```

Результат:

```sh
{
    "name": "Иван",
    "age": 20
}
```

Здесь `__dict__` возвращает словарь атрибутов экземпляра класса.

Это полезно, когда необходимо сохранять данные объектов, созданных в собственной программе.
