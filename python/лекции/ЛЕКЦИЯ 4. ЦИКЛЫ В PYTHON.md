
## 4.1. Что такое цикл

Цикл — это конструкция, которая позволяет многократно выполнять один и тот же блок кода.

Например, чтобы вывести числа от 1 до 5 без цикла, пришлось бы писать несколько команд:

```python
print(1)
print(2)
print(3)
print(4)
print(5)
```

С циклом код становится короче:

```python
for number in range(1, 6):
    print(number)
```

Циклы особенно полезны при работе со списками, обработке большого количества данных и повторении операций до выполнения определённого условия.

В Python основные циклы — `for` и `while`.

## 4.2. Цикл `for`

Цикл `for` используется для перебора элементов последовательности или другого итерируемого объекта.

```python
for переменная in последовательность:
	тело цикла
```

Пример:

```python
names = ["Иван", "Мария", "Алексей"]

for name in names:
    print(name)
```

На каждой итерации переменная `name` получает очередное значение из списка.

Сначала это `"Иван"`, затем `"Мария"`, затем `"Алексей"`.

После обработки всех элементов цикл завершается.

## 4.3. Функция `range()`

Функция `range()` часто используется вместе с `for`, когда необходимо перебрать последовательность чисел.

### Один аргумент

```python
for i in range(5):
    print(i)
```

Результат:

```
0
1
2
3
4
```

`range(5)` создаёт последовательность от 0 до 4. Верхняя граница 5 не включается.

### Два аргумента

```python
for i in range(1, 6):
    print(i)
```

Результат:

```python
1
2
3
4
5
```

Общая форма:

```python
range(start, stop, step)
```

`start` — начальное значение, `stop` — исключающая верхняя граница `step` — шаг изменения.

### Три аргумента

```python
for i in range(0, 10, 2):
    print(i)
```

Результат:

```python
0
2
4
6
8
```

Третий аргумент задаёт шаг изменения значения.

### Обратный перебор

```python
for i in range(5, 0, -1):
    print(i)
```

Результат:

```python
5
4
3
2
1
```

Отрицательный шаг позволяет двигаться в обратном направлении.

Если направление шага не соответствует начальной и конечной границам, цикл может не выполнить ни одной итерации.

## 4.4. Перебор строк

Строка является последовательностью символов, поэтому её тоже можно перебирать.

```python
word = "Python"

for letter in word:
    print(letter)
```

Каждая итерация получает очередной символ строки.

Такой подход используется для подсчёта символов, поиска определённых букв и обработки текста.

## 4.5. Перебор списка

```python
numbers = [10, 20, 30, 40]

for number in numbers:
    print(number * 2)
```

Цикл последовательно получает элементы списка и выполняет действие с каждым из них.

Если нужен индекс элемента, применяется `enumerate()`:

```python
names = ["Иван", "Мария", "Алексей"]

for index, name in enumerate(names):
    print(index, name)
```

Результат:

```python
"0 Иван"
"1 Мария"
"2 Алексей"
```

По умолчанию нумерация начинается с нуля. Начальное значение можно изменить:

```python
for index, name in enumerate(names, start=1):
    print(index, name)
```

## 4.6. Цикл `while`

Цикл `while` выполняет блок кода, пока условие истинно.

Общая форма:

```python
while условие:
    тело цикла
```

Пример:

```python
number = 1

while number <= 5:
    print(number)
    number += 1
```

В начале каждой итерации Python проверяет условие `number <= 5`.

Если оно истинно, выполняется тело цикла. Затем условие проверяется снова.

Когда `number` становится равным 6, условие перестаёт выполняться, и цикл завершается.

## 4.7. Бесконечные циклы

Если условие `while` никогда не становится ложным, цикл может продолжаться бесконечно.

Например:

```python
# Опасный пример
while True:
    print("Программа работает")
```

Бесконечные циклы могут использоваться намеренно, например в меню программы, но внутри них должен быть предусмотрен способ завершения.

Типичная ошибка — забыть изменить переменную, от которой зависит условие.

```python
# Ошибка логики
number = 1
while number <= 5:
    print(number)
```

Значение `number` не меняется, поэтому условие остаётся истинным.

## 4.8. `break` и `continue`

### Оператор `break`

`break` немедленно завершает ближайший окружающий цикл.

```python
for number in range(1, 10):
    if number == 5:
        break

    print(number)
```

Результат:

```
1
2
3
4
```

Когда `number` становится равным 5, цикл завершается.

### Оператор `continue`

`continue` пропускает оставшуюся часть текущей итерации и переходит к следующей.

```python
for number in range(1, 6):
    if number == 3:
        continue

    print(number)
```

Результат:

```
1
2
4
5
```

Число 3 не выводится, потому что команда `continue` пропускает оставшиеся действия этой итерации.

## 4.9. Вложенные циклы

Один цикл можно размещать внутри другого.

```python
for row in range(3):
    for column in range(3):
        print(row, column)
```

Внешний цикл перебирает строки, а внутренний — столбцы.

На каждую итерацию внешнего цикла внутренний выполняется полностью.

Вложенные циклы применяются при обработке таблиц, двумерных списков и некоторых задачах перебора комбинаций.

Однако при большом количестве вложенных циклов количество операций может быстро увеличиваться.

## 4.10. Цикл `for` и цикл `while`: различия

|`for`|`while`|
|---|---|
|Удобен для перебора последовательностей|Удобен для повторения по условию|
|Часто используется со списками и `range()`|Часто используется, когда количество повторений заранее неизвестно|
|Самостоятельно переходит к следующему элементу|Требует следить за изменением условия|
|Обычно меньше риск случайного бесконечного цикла|Легко создать бесконечный цикл при ошибке логики|

Оба цикла можно применять для решения многих одинаковых задач. Выбор зависит от того, что делает код понятнее.

## 4.11. `else` в циклах

В Python циклы могут иметь блок `else`.

```python
for number in range(3):
    print(number)
else:
    print("Цикл завершён")
```

Блок `else` выполняется, если цикл завершился обычным образом, без `break`.

Пример поиска:

```python
numbers = [2, 4, 6, 8]

for number in numbers:
    if number == 5:
        print("Число найдено")
        break
else:
    print("Число не найдено")
```

Поскольку число 5 отсутствует, цикл завершается без `break`, и выполняется `else`.

Эта конструкция не обязательна для большинства программ, но полезна в некоторых алгоритмах поиска.

## 4.12. Типичные ошибки

- забыли изменить переменную в `while`;
    
- неверно указали верхнюю границу `range()`;
    
- перепутали `break` и `continue`;
    
- неправильно организовали отступы;
    
- изменяют список во время его прямого перебора и получают неожиданный результат;
    
- считают, что `range(1, 5)` включает число 5.
    

## 4.13. Итоги лекции

Циклы позволяют повторять действия и обрабатывать коллекции.

- `for` перебирает элементы;
    
- `range()` создаёт числовую последовательность;
    
- `while` выполняется, пока условие истинно;
    
- `break` завершает цикл;
    
- `continue` пропускает текущую итерацию;
    
- `enumerate()` позволяет получать одновременно индекс и значение;
    
- вложенные циклы используются для работы с многомерными структурами.
