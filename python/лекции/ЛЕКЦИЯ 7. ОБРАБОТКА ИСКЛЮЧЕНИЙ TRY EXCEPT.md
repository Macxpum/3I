## 7.1. Что такое ошибка выполнения

Во время выполнения программы могут возникать ситуации, которые не позволяют продолжить обычное выполнение кода.

Например:

```python
number = int("привет")
```

Python не может преобразовать строку `"привет"` в целое число. В результате возникает `ValueError`.

Другой пример:

```python
result = 10 / 0
```

Деление на ноль вызывает `ZeroDivisionError`.

Такие ситуации называются исключениями.

Исключение — механизм Python, с помощью которого сообщается об ошибке или другой особой ситуации во время выполнения программы.

Если исключение не обработано, программа обычно завершается с выводом сообщения об ошибке и трассировки стека.

## 7.2. Конструкция `try / except`

Общий синтаксис:

```python
try:
    команды, которые могут вызвать исключение

except ТипОшибки:
    обработка ошибки
```

Пример:

```python
try:
    number = int(input("Введите число: "))
    print(number)

except ValueError:
    print("Ошибка: необходимо ввести целое число")
```

Если ввод корректный, программа выполняет код в `try`, а блок `except` пропускается.

Если преобразование вызывает `ValueError`, выполнение блока `try` прерывается, и Python переходит к соответствующему обработчику.

После завершения конструкции программа продолжает выполнение со следующей команды, если исключение было обработано и не возникло другой ошибки.

## 7.3. Зачем обрабатывать исключения

Обработка исключений позволяет:

- сообщать пользователю о некорректных данных;
    
- предотвращать неожиданное завершение программы при ожидаемых ошибках;
    
- корректно реагировать на отсутствие файлов;
    
- обрабатывать ошибки преобразования типов;
    
- проверять деление на ноль;
    
- освобождать ресурсы после завершения операций.
    

Однако не каждую ошибку нужно перехватывать. Если программа содержит логическую ошибку, например неправильно рассчитывает цену, конструкция `try / except` сама по себе эту проблему не исправит.

## 7.4. Основные типы исключений

### `ValueError`

Возникает, когда значение имеет подходящий тип, но неподходящее содержимое для выполняемой операции.

```python
number = int("abc")
```

### `TypeError`

Возникает, когда операция применяется к объектам несовместимых типов.

```python
"Возраст: " + 18
```

Нельзя напрямую соединить строку и число с помощью `+`. Можно преобразовать число в строку или использовать f-строку.

### `ZeroDivisionError`

Возникает при делении на ноль.

```python
result = 10 / 0
```

### `IndexError`

Возникает при обращении к отсутствующему индексу последовательности.

```python
numbers = [10, 20, 30]

print(numbers[5])
```

### `KeyError`

Возникает, когда в словаре запрашивается отсутствующий ключ.

```python
user = {"name": "Иван"}

print(user["age"])
```

### `FileNotFoundError`

Возникает, когда программа пытается открыть файл, которого нет по указанному пути.

### `NameError`

Возникает, когда используется имя, которое не определено в доступной области видимости.

## 7.5. Несколько обработчиков `except`

Одна операция может вызывать разные исключения.

```python
try:
    a = int(input("Введите первое число: "))
    b = int(input("Введите второе число: "))

    result = a / b

    print(result)

except ValueError:
    print("Необходимо вводить числа")

except ZeroDivisionError:
    print("Делить на ноль нельзя")
```

Если пользователь вводит текст вместо числа, срабатывает `ValueError`.

Если второе число равно нулю, срабатывает `ZeroDivisionError`.

Python выбирает первый подходящий обработчик для возникшего исключения.

## 7.6. Получение информации об ошибке

Чтобы получить объект исключения, используется `as`.

```python
try:
    number = int("abc")

except ValueError as error:
    print("Возникла ошибка:", error)
```

Переменная `error` содержит информацию об исключении.

Это полезно для диагностики, но подробные сообщения ошибок не всегда следует показывать конечному пользователю. В приложениях обычно отображают понятное сообщение, а технические подробности записывают в журнал.

## 7.7. Блок `else`

Блок `else` выполняется, если внутри `try` не возникло исключений.

```python
try:
    number = int(input("Введите число: "))

except ValueError:
    print("Некорректный ввод")

else:
    print("Вы ввели:", number)
    print("Квадрат числа:", number ** 2)
```

Если преобразование успешно, выполняется `else`.

Использование `else` помогает отделить операцию, которая может вызвать ошибку, от дальнейшей обработки корректного результата.

## 7.8. Блок `finally`

Блок `finally` выполняется при завершении конструкции независимо от того, возникло исключение или нет.

```python
try:
    number = int(input("Введите число: "))

except ValueError:
    print("Ошибка ввода")

finally:
    print("Обработка завершена")
```

`finally` обычно применяется для действий, которые необходимо выполнить независимо от результата: например, для закрытия ресурсов или завершения определённых операций.

При этом `finally` не гарантирует выполнение при абсолютно любых обстоятельствах, например при принудительном завершении процесса или отключении питания.

## 7.9. Полная конструкция

В одной конструкции можно использовать все четыре блока:

```python
try:
    number = int(input("Введите число: "))

except ValueError:
    print("Нужно ввести целое число")

else:
    print("Квадрат числа:", number ** 2)

finally:
    print("Проверка завершена")
```

Порядок блоков:

1. `try` — основной код.
    
2. `except` — обработка исключений.
    
3. `else` — действия при отсутствии исключений.
    
4. `finally` — завершающие действия.
    

`else` и `finally` необязательны. Блоков `except` может быть несколько.

## 7.10. Обработка ошибок при работе со словарями

Предположим, программа хранит данные пользователя:

```python
user = {
    "name": "Иван",
    "age": 18
}
```

Если ключ может отсутствовать, часто удобнее использовать `get()`:

```python
age = user.get("age")
```

Этот подход не вызывает `KeyError` при отсутствии ключа.

Если отсутствие ключа является исключительной ситуацией, можно обработать ошибку:

```python
try:
    age = user["age"]

except KeyError:
    print("Возраст не указан")
```

Выбор зависит от задачи. Если отсутствие значения ожидаемо, обычно лучше использовать `get()`. Если ключ обязателен, обработка `KeyError` может быть уместной.

## 7.11. Обработка ошибок при работе с файлами

Файл может отсутствовать, быть недоступным или не открываться из-за проблем с разрешениями.

```python
try:
    file = open("data.txt", "r", encoding="utf-8")
    content = file.read()
    file.close()

except FileNotFoundError:
    print("Файл не найден")
```

Однако в Python предпочтительнее использовать `with`, который автоматически управляет закрытием файла:

```python
try:
    with open("data.txt", "r", encoding="utf-8") as file:
        content = file.read()

except FileNotFoundError:
    print("Файл не найден")
```

Даже если чтение завершается исключением, конструкция `with` корректно закрывает файл при выходе из блока.

## 7.12. Повторный ввод с помощью цикла

Обработка исключений часто применяется вместе с циклом `while`.

```python
while True:
    try:
        age = int(input("Введите возраст: "))

        if age < 0:
            print("Возраст не может быть отрицательным")
            continue

        break

    except ValueError:
        print("Введите целое число")

print("Возраст:", age)
```

Программа повторяет ввод до тех пор, пока не будет получено целое неотрицательное число.

`continue` начинает следующую итерацию цикла, а `break` завершает цикл при корректном вводе.

## 7.13. Почему не стоит использовать пустой `except`

Рассмотрим:

```python
try:
    number = int(input("Введите число: "))

except:
    print("Ошибка")
```

Такой обработчик может перехватить гораздо больше исключений, чем предполагалось, включая специальные исключения завершения программы.

В большинстве случаев следует указывать конкретный тип:

```python
except ValueError:
    print("Некорректное число")
```

Если действительно необходимо перехватить широкий круг обычных ошибок, используют `except Exception as error`, но только когда это оправдано задачей.

Не рекомендуется скрывать все ошибки без разбора: это затрудняет поиск дефектов программы.

## 7.14. Создание собственных исключений

В Python можно самостоятельно вызывать исключения с помощью `raise`.

```
def calculate_discount(price, discount):
    if price < 0:
        raise ValueError("Цена не может быть отрицательной")

    if not 0 <= discount <= 100:
        raise ValueError("Скидка должна быть от 0 до 100")

    return price - price * discount / 100
```

Здесь функция сообщает об ошибочных аргументах с помощью `ValueError`.

Исключение можно обработать при вызове:

```
try:
    result = calculate_discount(1000, 150)

except ValueError as error:
    print("Ошибка:", error)
```

`raise` полезен, когда функция обнаруживает ситуацию, в которой она не может корректно выполнить свою задачу.

## 7.15. Типичные ошибки при обработке исключений

**Ошибка 1. Перехватываются не те исключения.** Нужно выбирать тип, соответствующий ожидаемой проблеме.

**Ошибка 2. Исключение скрывается без сообщения.** Это затрудняет диагностику.

**Ошибка 3. В** **`try`** **помещён слишком большой блок кода.** В результате может быть сложно определить, какая именно операция вызвала исключение.

**Ошибка 4. Обработка исключений заменяет проверку данных.** Если простая проверка условия делает ситуацию понятной, не всегда нужно полагаться на исключения.

**Ошибка 5. Предполагается, что** **`finally`** **всегда выполняется при любых обстоятельствах.** При аварийном завершении процесса это не гарантируется.

## 7.16. Итоги лекции

Обработка исключений позволяет программе корректно реагировать на ошибки выполнения.

- `try` содержит код, в котором может возникнуть исключение;
    
- `except` обрабатывает исключения;
    
- `else` выполняется, если ошибок не возникло;
    
- `finally` используется для завершающих действий;
    
- `raise` позволяет явно вызвать исключение;
    
- конкретные типы исключений делают обработку предсказуемее;
    
- `with` упрощает безопасную работу с ресурсами.
