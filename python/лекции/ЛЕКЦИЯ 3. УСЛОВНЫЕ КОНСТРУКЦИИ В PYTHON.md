## 3.1. Назначение условий

Условные конструкции позволяют программе выбирать, какие команды выполнять, в зависимости от значения выражения.

Без условий программа обычно выполняет команды последовательно. С помощью `if`, `elif` и `else` можно изменять ход выполнения в зависимости от ситуации.

Например, программа должна определить, достиг ли пользователь совершеннолетия.

```python
age = 20

if age >= 18:
    print("Совершеннолетний")
```

Если условие `age >= 18` истинно, выполняется блок кода внутри `if`.

## 3.2. Конструкция `if`

Общий синтаксис:

```python
if условие:
    команды
```

Пример:

```python
temperature = 25

if temperature > 20:
    print("Тепло")
```

Здесь `temperature > 20` — условие. Оно вычисляется перед выполнением блока.

Если результат `True`, Python выполняет команды с отступом. Если результат `False`, блок пропускается.

### Отступы

В Python отступы определяют структуру программы.

Правильно:

```python
if age >= 18:
    print("Доступ разрешён")
```

Неправильно:

```python
#Пример ошибки синтаксиса
if age >= 18:
print("Доступ разрешён")
```

Обычно для отступа используют четыре пробела.

Фигурные скобки, как в PHP или JavaScript, для выделения тела `if` не нужны.

## 3.3. Конструкция `if / else`

Если необходимо выбрать один из двух вариантов, используется `else`.

```python
age = 16

if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

Если условие истинно, выполняется первый блок. Если ложно — второй.

`else` не имеет собственного условия: он обрабатывает оставшийся вариант.

## 3.4. Конструкция `if / elif / else`

Если вариантов больше двух, применяется `elif`, сокращение от _else if_.

```python
score = 85

if score >= 90:
    print("Отлично")
elif score >= 70:
    print("Хорошо")
elif score >= 50:
    print("Удовлетворительно")
else:
    print("Неудовлетворительно")
```

Python проверяет условия сверху вниз.

В этом примере:

1. Проверяется, не меньше ли оценка 90.
    
2. Если нет, проверяется, не меньше ли она 70.
    
3. Если нет, проверяется, не меньше ли она 50.
    
4. Если ни одно условие не сработало, выполняется `else`.
    

После выполнения первого подходящего блока остальные ветви пропускаются.

Поэтому порядок условий имеет значение.

## 3.5. Несколько условий

Логические операторы позволяют объединять условия.

```python
age = 20
has_ticket = True

if age >= 18 and has_ticket:
    print("Вход разрешён")
else:
    print("Вход запрещён")
```

Для доступа необходимы одновременно оба условия: возраст не меньше 18 лет и наличие билета.

Другой пример:

```python
day = "суббота"

if day == "суббота" or day == "воскресенье":
    print("Выходной")
else:
    print("Рабочий день")
```

В этом случае достаточно, чтобы было истинно хотя бы одно условие.

## 3.6. Вложенные условия

Одну условную конструкцию можно размещать внутри другой.

```python
age = 20
has_permission = True

if age >= 18:
    if has_permission:
        print("Доступ разрешён")
    else:
        print("Нет разрешения")
else:
    print("Недостаточный возраст")
```

Вложенные условия полезны, когда вторую проверку необходимо выполнять только после успешного прохождения первой.

Однако слишком большое количество уровней вложенности усложняет код. Иногда логичнее объединить проверки через `and` или вынести отдельную проверку в функцию.

## 3.7. Истинные и ложные значения

В Python условие не обязательно должно содержать выражение сравнения. В качестве условия можно использовать любое значение.

Например:

```python
name = ""

if name:
    print("Имя введено")
else:
    print("Имя не указано")
```

Пустая строка считается ложным значением.

К ложным значениям относятся:

- `False`;
    
- `None`;
    
- числовой ноль, включая `0`, `0.0` и `0j`;
    
- пустая строка `""`;
    
- пустой список `[]`;
    
- пустой словарь `{}`;
    
- пустое множество `set()`.
    

Большинство остальных объектов считаются истинными.

Например:

```python
products = []

if products:
    print("Товары есть")
else:
    print("Список пуст")
```

Такой подход позволяет удобно проверять наличие данных.

## 3.8. Тернарное выражение

Для простого выбора одного из двух значений можно использовать условное выражение.

```python
age = 20

status = "Совершеннолетний" if age >= 18 else "Несовершеннолетний"

print(status)
```

Общая форма:

```python
значение_если_истина if условие else значение_если_ложь
```

Это выражение возвращает значение, поэтому его можно присвоить переменной или передать в другую функцию.

Для сложных условий лучше использовать обычную конструкцию `if / elif / else`.

## 3.9. Проверка нескольких значений

В Python можно записывать цепочки сравнений:

```python
age = 20

if 18 <= age <= 65:
    print("Возраст находится в заданном диапазоне")
```

Это эквивалентно проверке:

```python
if age >= 18 and age <= 65:
    print("Возраст находится в заданном диапазоне")
```

Цепочки сравнений делают код короче и читаемее.

## 3.10. Сравнение с PHP

В PHP:

```php
if ($age >= 18) {
    echo "Доступ разрешён";
} else {
    echo "Доступ запрещён";
}
```

В Python:

```python
if age >= 18:
    print("Доступ разрешён")
else:
    print("Доступ запрещён")
```

Основные отличия:

- в Python не нужен символ `$` перед переменными;
    
- блоки кода выделяются отступами;
    
- после условия ставится двоеточие;
    
- `else if` в PHP соответствует `elif` в Python;
    
- для вывода используется `print()`.
    

## 3.11. Типичные ошибки

**Ошибка 1. Пропущено двоеточие.**

```python
if age >= 18
    print("Доступ разрешён")
```

После условия обязательно ставится `:`.

**Ошибка 2. Неправильный отступ.**

Команды внутри блока должны иметь одинаковый уровень отступа.

**Ошибка 3. Использование** **`=`** **вместо** **`==`****.

В условии сравнения обычно требуется `==`, а не оператор присваивания `=`.

**Ошибка 4. Неправильный порядок ветвей.**

Если сначала проверить слишком широкое условие, до более конкретных проверок выполнение может не дойти.

## 3.12. Итоги лекции

Условные конструкции позволяют принимать решения в зависимости от данных.

- `if` проверяет условие;
    
- `elif` добавляет дополнительные варианты;
    
- `else` выполняется, если предыдущие условия не подошли;
    
- `and`, `or`, `not` помогают объединять и изменять условия;
    
- отступы определяют структуру блоков;
    
- пустые коллекции и нулевые значения считаются ложными.
