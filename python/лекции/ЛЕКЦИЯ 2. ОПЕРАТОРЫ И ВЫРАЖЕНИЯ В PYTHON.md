## 2.1. Что такое оператор

Оператор — это символ или конструкция, которая выполняет определённое действие над значениями.

Например:

```python
a = 10
b = 5

result = a + b
```

В выражении `a + b` оператор `+` выполняет сложение.

В Python используются арифметические, сравнительные, логические операторы, операторы присваивания, принадлежности и идентичности.

## 2.2. Арифметические операторы

|Оператор|Назначение|Пример|
|---|---|---|
|`+`|Сложение|`10 + 5` → `15`|
|`-`|Вычитание|`10 - 5` → `5`|
|`*`|Умножение|`10 * 5` → `50`|
|`/`|Деление|`10 / 4` → `2.5`|
|`//`|Целочисленное деление|`10 // 4` → `2`|
|`%`|Остаток от деления|`10 % 4` → `2`|
|`**`|Возведение в степень|`2 ** 3` → `8`|

### Деление `/`

Оператор `/` возвращает результат обычного деления.

```python
print(10 / 2)
print(7 / 2)
```

Результат:

```python
5.0
3.5
```

Даже если результат математически целый, обычное деление возвращает число типа `float`.

### Целочисленное деление `//`

Оператор `//` выполняет деление с округлением вниз до целого значения по математическому правилу.

```python
print(10 // 3)
```

Результат:

```python
3
```

Для отрицательных чисел важно помнить, что округление происходит вниз:

```python
print(-10 // 3)
```

Результат:

```python
-4
```

Это не то же самое, что просто отбросить дробную часть в сторону нуля.

### Остаток от деления `%`

Оператор `%` возвращает остаток от деления.

```python
print(10 % 3)
```

Результат:

```python
1
```

Этот оператор часто используется для проверки чётности числа:

```python
number = 8

print(number % 2 == 0)
```

Если остаток от деления на 2 равен нулю, число чётное.

### Возведение в степень `**`

```python
print(2 ** 3)
print(5 ** 2)
```

Результат:

```python
8
25
```

В отличие от некоторых других языков программирования, в Python оператор `^` не означает возведение в степень. Он выполняет побитовое исключающее ИЛИ.

## 2.3. Операторы присваивания

Оператор `=` присваивает переменной значение.

```python
number = 10
```

Сокращённые операторы присваивания позволяют выполнить операцию и записать результат в ту же переменную.

|Оператор|Эквивалент|
|---|---|
|`x += 5`|`x = x + 5`|
|`x -= 5`|`x = x - 5`|
|`x *= 5`|`x = x * 5`|
|`x /= 5`|`x = x / 5`|
|`x //= 5`|`x = x // 5`|
|`x %= 5`|`x = x % 5`|
|`x **= 2`|`x = x ** 2`|

Пример:

```python
balance = 1000

balance += 500
balance -= 200

print(balance)
```

Результат:

```python
1300
```

### Инкремент и декремент

В Python нет операторов `++` и `--`, аналогичных тем, которые используются в PHP, JavaScript и некоторых других языках.

Вместо них применяются:

```python
counter = 0

counter += 1
counter -= 1
```

Это позволяет увеличивать или уменьшать значение переменной на единицу.

## 2.4. Операторы сравнения

Операторы сравнения сопоставляют значения и возвращают `True` или `False`.

|Оператор|Значение|
|---|---|
|`==`|Равно|
|`!=`|Не равно|
|`>`|Больше|
|`<`|Меньше|
|`>=`|Больше или равно|
|`<=`|Меньше или равно|

Пример:

```python
a = 10
b = 5

print(a > b)
print(a == b)
print(a != b)
```

Результат:

```python
True
False
True
```

### Разница между `=` и `==`

Это одна из распространённых ошибок.

```python
x = 10
```

Здесь значение присваивается переменной.

```python
x == 10
```

Здесь проверяется, равна ли переменная `x` числу 10.

Оператор `==` возвращает логический результат, но сам по себе не изменяет значение переменной.

### Сравнение строк

Строки можно сравнивать между собой:

```python
print("apple" == "apple")
print("apple" == "Apple")
```

Второй результат — `False`, поскольку Python различает регистр.

Строки также могут сравниваться лексикографически, то есть в порядке кодовых точек символов:

```python
print("apple" < "banana")
```

При этом нельзя напрямую использовать операторы порядка для сравнения обычного числа со строкой:

```python
10 < "20"  # TypeError
```

Python 3 не устанавливает произвольный порядок между такими значениями.

## 2.5. Логические операторы

Логические операторы используются для объединения и изменения условий.

В Python есть три основных логических оператора:

- `and` — логическое И;
    
- `or` — логическое ИЛИ;
    
- `not` — логическое НЕ.
    

### Оператор `and`

Возвращает истинный результат, когда оба условия истинны.

```python
age = 20
has_ticket = True

print(age >= 18 and has_ticket)
```

Результат:

```python
True
```

Если хотя бы одно условие ложно, всё выражение будет ложным.

### Оператор `or`

Возвращает истинный результат, если хотя бы одно из условий истинно.

```python
is_admin = False
is_moderator = True

print(is_admin or is_moderator)
```

Результат:

```python
True
```

### Оператор `not`

Меняет логическое значение на противоположное.

```python
is_blocked = False

print(not is_blocked)
```

Результат:

```python
True
```

### Таблица логических операций

|`A`|`B`|`A and B`|`A or B`|
|---|---|---|---|
|`True`|`True`|`True`|`True`|
|`True`|`False`|`False`|`True`|
|`False`|`True`|`False`|`True`|
|`False`|`False`|`False`|`False`|

В Python `and` и `or` могут возвращать не только `True` и `False`, но и один из операндов. В условиях это используется для проверки значений, однако в начале изучения языка лучше сосредоточиться на их логическом поведении.

## 2.6. Операторы принадлежности

Операторы `in` и `not in` проверяют, содержится ли элемент в последовательности или коллекции.

```python
name = "Python"

print("P" in name)
print("z" in name)
```

Результат:

```python
True
False
```

Для списков:

```python
numbers = [10, 20, 30]

print(20 in numbers)
print(50 not in numbers)
```

Для словарей оператор `in` по умолчанию проверяет наличие ключа:

```python
user = {
    "name": "Иван",
    "age": 18
}

print("name" in user)
print("Иван" in user)
```

Результат:

```python
True
False
```

Чтобы проверить наличие значения словаря, можно использовать `user.values()`.

## 2.7. Операторы идентичности `is` и `is not`

Операторы `is` и `is not` проверяют, являются ли две ссылки ссылками на один и тот же объект.

```python
value = None

print(value is None)
```

Для проверки `None` рекомендуется использовать именно `is None`.

Не следует путать идентичность с равенством:

- `==` проверяет равенство значений;
    
- `is` проверяет идентичность объектов.
    

Например, два разных списка могут содержать одинаковые значения, но быть разными объектами:

```python
a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)
print(a is b)
```

Результат:

```python
True
False
```

## 2.8. Приоритет операторов

В одном выражении может использоваться несколько операторов.

```python
result = 2 + 3 * 4
print(result)
```

Результат:

```python
14
```

Умножение выполняется раньше сложения.

Для управления порядком вычислений используются скобки:

```python
result = (2 + 3) * 4
print(result)
```

Результат:

```python
20
```

В сложных выражениях рекомендуется явно использовать скобки, если это делает код понятнее.

## 2.9. Итоги лекции

Операторы позволяют выполнять вычисления, сравнивать значения, объединять условия, изменять переменные и проверять принадлежность элементов коллекциям.

Особенно важно различать:

- `=` и `==`;
    
- `/` и `//`;
    
- `and`, `or` и `not`;
    
- `==` и `is`;
    
- `in` для последовательностей и словарей.
