## 1.1. Что такое Python

Python — высокоуровневый язык программирования общего назначения. Он применяется для разработки веб-приложений, автоматизации задач, обработки данных, создания программ и работы с искусственным интеллектом.

Одной из главных особенностей Python является простой и читаемый синтаксис. Во многих случаях программа на Python содержит меньше служебных конструкций, чем аналогичная программа на PHP, Java или C++.

Например, вывод сообщения в Python:

```python
print("Hello, World!")
```

Для сравнения, в PHP:

```php
<?php
echo "Hello, World!";
?>
```

В Python не требуется ставить точку с запятой после каждой команды. Блоки кода обычно выделяются отступами, а не фигурными скобками.

Ещё одна важная особенность — динамическая типизация. Тип данных определяется во время выполнения программы, поэтому программисту не требуется заранее указывать тип каждой переменной.

## 1.2. Переменные

Переменная — это имя, с помощью которого программа обращается к некоторому объекту или значению.

Например:

```python
name = "Алексей"
age = 18
price = 1500.50
```

Здесь созданы три переменные:

- `name` хранит строку;
    
- `age` хранит целое число;
    
- `price` хранит число с плавающей точкой.
    

В Python переменная создаётся при первом присваивании значения.

```python
number = 10
print(number)
```

Результат:

```python
10
```

Оператор `=` называется оператором присваивания. Он связывает имя переменной с объектом, содержащим значение.

Важно понимать: `=` не означает математическое равенство. Он означает, что переменной присваивается значение выражения справа.

Например:

```python
a = 10
b = 5

result = a + b

print(result)
```

Сначала Python получает значения переменных `a` и `b`, складывает их, а затем связывает имя `result` с полученным результатом.

### Изменение значения переменной

Одну и ту же переменную можно использовать повторно:

```python
number = 10
print(number)

number = 25
print(number)
```

Результат:

```python
10
25
```

При втором присваивании имя `number` начинает ссылаться на новое значение.

### Повторное присваивание с использованием старого значения

```python
number = 10
number = number + 5

print(number)
```

Результат:

```python
15
```

Python сначала вычисляет выражение справа: `10 + 5`. После этого полученный результат присваивается переменной.

Сокращённая запись:

```python
number = 10
number += 5
```

Оператор `+=` означает увеличение текущего значения на указанную величину и присваивание результата обратно переменной.

## 1.3. Правила именования переменных

Имена переменных должны соответствовать синтаксическим правилам Python.

Допустимые примеры:

```python
name = "Иван"
user_age = 20
price2 = 1500
_total = 100
```

Недопустимые примеры:

```python
2price = 100
user-name = "Иван"
class = "ИС-21"
```

Основные правила:

1. Имя может содержать латинские буквы, цифры и символ подчёркивания `_`.
    
2. Имя не может начинаться с цифры.
    
3. Пробелы и дефисы в имени переменной не допускаются.
    
4. Нельзя использовать зарезервированные ключевые слова Python, например `if`, `for`, `class`, `return`.
    
5. Python различает регистр букв: `name`, `Name` и `NAME` — разные имена.
    

Для составных имён обычно применяется стиль `snake_case`, при котором слова разделяются подчёркиваниями:

```python
student_name = "Иван"
total_price = 5000
product_quantity = 10
```

Такая запись соответствует общепринятому стилю оформления Python-кода.

## 1.4. Основные типы данных

Тип данных определяет, какие значения может представлять объект и какие операции с ним допустимы.

В Python существуют разные встроенные типы данных.

### Целые числа — `int`

Тип `int` используется для хранения целых чисел.

```python
age = 18
quantity = 25
temperature = -10
```

Целые числа могут быть положительными, отрицательными и нулём.

С ними можно выполнять арифметические операции:

```python
a = 10
b = 3

print(a + b)
print(a - b)
print(a * b)
```

Python поддерживает целые числа произвольной точности, ограниченные доступными ресурсами компьютера.

### Числа с плавающей точкой — `float`

Тип `float` применяется для представления дробных чисел.

```python
price = 1500.50
temperature = 23.7
discount = 0.15
```

В качестве десятичного разделителя используется точка, а не запятая.

```python
number = 12.5
```

Запись `12,5` не является стандартной записью одного дробного числа в Python.

У `float` есть особенности точности. Некоторые десятичные дроби невозможно представить в двоичной системе точно.

```python
print(0.1 + 0.2)
```

В результате может появиться:

```python
0.30000000000000004
```

Это не ошибка арифметики, а особенность представления чисел с плавающей точкой.

Для денежных расчётов, где важна точная десятичная арифметика, часто используют модуль `decimal`.

### Строки — `str`

Тип `str` предназначен для хранения текстовых данных.

```python
name = "Алексей"
city = "Москва"
message = 'Добро пожаловать!'
```

Строки можно создавать с помощью одинарных или двойных кавычек.

```python
text1 = "Python"
text2 = 'Python'
```

Оба варианта корректны.

Для строк, содержащих переносы строк, можно использовать тройные кавычки:

```python
text = """Первая строка
Вторая строка
Третья строка"""

print(text)
```

Строки в Python являются неизменяемыми. Это означает, что отдельный символ существующей строки нельзя заменить прямым присваиванием по индексу.

```python
word = "Python"

word[0] = "J"  # TypeError
```

Чтобы получить изменённый текст, нужно создать новую строку.

### Логический тип — `bool`

Тип `bool` содержит два значения:

- `True` — истина;
    
- `False` — ложь.
    

Пример:

```python
is_student = True
is_admin = False

print(is_student)
print(is_admin)
```

Логические значения широко используются в условиях и проверках.

```python
age = 20
is_adult = age >= 18

print(is_adult)
```

Результат:

```python
True
```

Выражение `age >= 18` возвращает логическое значение, которое сохраняется в переменной `is_adult`.

### Отсутствие значения — `None`

`None` — специальное значение, обозначающее отсутствие значения или его неопределённость.

```python
result = None
```

Например, функция может возвращать `None`, если не нашла нужный объект.

```python
product = None

if product is None:
    print("Товар не найден")
```

Для проверки отсутствия значения обычно используют `is None`, а не сравнение с текстом `"None"`.

## 1.5. Определение типа: `type()`

Функция `type()` позволяет узнать тип объекта.

```python
print(type(10))
print(type(10.5))
print(type("Python"))
print(type(True))
print(type(None))
```

Результат:

```python
<class 'int'>
<class 'float'>
<class 'str'>
<class 'bool'>
<class 'NoneType'>
```

Это полезно при изучении языка и поиске ошибок, связанных с типами данных.

## 1.6. Преобразование типов

Иногда значение необходимо преобразовать из одного типа в другой.

Для этого используются встроенные функции.

```python
number = int("25")
price = float("19.99")
text = str(100)
```

Здесь:

- `int()` преобразует значение в целое число;
    
- `float()` — в число с плавающей точкой;
    
- `str()` — в строку.
    

Пример:

```python
age = "18"

print(age + " лет")
```

Результат:

```python
'18 лет'
```

Оба операнда являются строками, поэтому выполняется соединение строк.

Если нужно выполнить арифметику:

```python
age = int("18")

print(age + 2)
```

Результат:

```python
20
```

Не каждую строку можно преобразовать в число:

```python
number = int("привет")
```

Такой код вызывает `ValueError`, потому что текст не представляет целое число.

## 1.7. Ввод и вывод данных

Для вывода информации используется функция `print()`.

```python
name = "Иван"
age = 18

print(name)
print(age)
print("Имя:", name, "Возраст:", age)
```

Для получения данных от пользователя применяется `input()`.

```python
name = input("Введите имя: ")

print("Привет,", name)
```

Важная особенность: `**input()**` **возвращает строку**, даже если пользователь ввёл цифры.

```python
number = input("Введите число: ")

print(type(number))
```

Если необходимо выполнять вычисления, значение следует преобразовать:

```python
number = int(input("Введите число: "))

print(number + 10)
```

Для ввода дробного числа можно использовать `float()`:

```python
price = float(input("Введите цену: "))
```

Если пользователь введёт неподходящее значение, преобразование может завершиться ошибкой. Обработка таких ситуаций рассматривается в седьмой лекции.

## 1.8. Форматирование строк

Для удобной вставки переменных в текст используются f-строки.

```python
name = "Иван"
age = 18

print(f"Студент {name}, возраст: {age}")
```

Выражения в фигурных скобках вычисляются при формировании строки.

```python
price = 1000
quantity = 3

print(f"Общая стоимость: {price * quantity} рублей")
```

Результат:

```python
'Общая стоимость: 3000 рублей'
```

F-строки также позволяют форматировать числа:

```python
price = 19.9876

print(f"{price:.2f}")
```

Результат:

```python
19.99
```

Формат `.2f` задаёт вывод двух цифр после десятичной точки.

- переменная создаётся при присваивании значения;

- f-строки позволяют удобно формировать текст с переменными.
