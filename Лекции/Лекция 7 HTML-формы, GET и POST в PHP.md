
## Цель занятия

До этого мы в основном сами создавали данные внутри PHP-кода:

```php
$name = "Иван";
$age = 20;
```

Мы научились:

- создавать переменные;
- работать с операторами;
- проверять условия;
- использовать циклы;
- хранить данные в массивах;
- создавать функции.

Но реальный сайт должен уметь получать данные не только от программиста.

Например, пользователь может:

- ввести имя;
- указать возраст;
- написать сообщение;
- выполнить поиск;
- ввести логин и пароль;
- выбрать товар;
- заполнить форму регистрации.

На этом занятии мы научимся получать такие данные в PHP.

---

# 1. Зачем нужны формы?

HTML-форма позволяет пользователю вводить информацию и отправлять её серверу.

Например, форма входа:

```text
Логин:
[____________]

Пароль:
[____________]

[ Войти ]
```

Форма поиска:

```text
Поиск:
[____________]

[ Найти ]
```

Форма регистрации:

```text
Имя:
[____________]

Возраст:
[____________]

Email:
[____________]

[ Зарегистрироваться ]
```

Во всех этих случаях браузеру необходимо передать данные PHP.

---

# 2. Простая HTML-форма

Создадим файл:

```text
index.php
```

И напишем:

```html
<form>
  <input type="text" />
  <button type="submit">Отправить</button>
</form>
```

В браузере появится текстовое поле и кнопка.

Но пока сервер не знает:

- что находится в этом поле;
- как называется это значение;
- куда его отправлять;
- каким способом его отправлять.

Поэтому форму необходимо настроить.

---

# 3. Атрибут `name`

Каждому полю формы необходимо дать имя.

Например:

```html
<input type="text" name="username" />
```

Теперь введённое пользователем значение будет связано с именем:

```text
username
```

Например, пользователь ввёл:

```text
Иван
```

Можно представить данные так:

```text
username → Иван
```

Это очень похоже на ассоциативный массив, который мы уже изучали:

```php
$user = [
    "username" => "Иван"
];
```

И это не случайность.

Позже мы увидим, что PHP действительно получает данные формы в виде массива.

---

# 4. Атрибут `method`

Форма должна знать, каким способом отправить данные.

Для этого используется:

```html
method
```

Основные варианты:

```text
GET
POST
```

Например:

```html
<form method="GET"></form>
```

или:

```html
<form method="POST"></form>
```

Сегодня мы разберём оба варианта.

---

# 5. Первая GET-форма

Напишем:

```html
<form method="GET">
  <input type="text" name="name" />
  <button type="submit">Отправить</button>
</form>
```

Пользователь вводит:

```text
Иван
```

и нажимает:

```text
Отправить
```

После этого в адресной строке браузера можно увидеть что-то похожее:

```text
index.php?name=Иван
```

После символа:

```text
?
```

находятся данные запроса.

---

# 6. Как выглядит GET-запрос?

Например:

```text
index.php?name=Иван
```

Можно разделить:

```text
index.php
   │
   └── страница

?name=Иван
 │     │
 │     └── значение
 │
 └── имя параметра
```

То есть браузер отправил:

```text
name → Иван
```

---

# 8. Несколько GET-параметров

Можно отправить несколько значений.

Например:

```html
<form method="GET">
  <input type="text" name="name" />

  <input type="number" name="age" />

  <button type="submit">Отправить</button>
</form>
```

Пользователь ввёл:

```text
Иван
20
```

Адрес может выглядеть примерно так:

```text
index.php?name=Иван&age=20
```

Здесь:

```text
name → Иван
age  → 20
```

Символ:

```text
&
```

разделяет параметры.

---

# 9. `$_GET`

Теперь самое важное.

PHP автоматически собирает GET-параметры в специальный массив:

```php
$_GET
```

Например, запрос:

```text
index.php?name=Иван&age=20
```

примерно превращается в:

```php
$_GET = [
    "name" => "Иван",
    "age" => "20"
];
```

Получается, что знания массивов нам уже пригодились.

Мы можем получить имя:

```php
echo $_GET["name"];
```

Возраст:

```php
echo $_GET["age"];
```

---

# 10. `$_GET` — это ассоциативный массив

Раньше мы писали:

```php
$user = [
    "name" => "Иван",
    "age" => 20
];

echo $user["name"];
```

Теперь:

```php
echo $_GET["name"];
```

Принцип абсолютно тот же.

Можно представить:

```text
$_GET

name → Иван
age  → 20
```

Поэтому массивы изучались не сами по себе.

Они постоянно используются в реальной веб-разработке.

---

# 11. Посмотрим весь `$_GET`

Для отладки можно использовать:

```php
var_dump($_GET);
```

Например, пользователь отправил:

```text
name = Иван
age = 20
```

PHP покажет примерно:

```text
array(2) {
    ["name"] =>
    string(...)
    ["age"] =>
    string(...)
}
```

Или можно использовать:

```php
print_r($_GET);
```

Получим примерно:

```text
Array
(
    [name] => Иван
    [age] => 20
)
```

---

# 12. Важный момент: данные формы обычно приходят строками

Пользователь вводит:

```text
20
```

Но PHP может получить:

```php
"20"
```

то есть строку.

Поэтому:

```php
$_GET["age"]
```

не обязательно является `int`.

Можно проверить:

```php
var_dump($_GET["age"]);
```

Это важно помнить при работе с пользовательским вводом.

---

# 13. Проблема отсутствующего значения

Рассмотрим:

```php
echo $_GET["name"];
```

Что произойдёт, если страница открыта просто так:

```text
index.php
```

и никакого параметра `name` нет?

В массиве:

```php
$_GET
```

нет ключа:

```text
name
```

Поэтому обращаться к нему напрямую не всегда безопасно.

---

# 14. Проверка через `isset()`

Можно проверить:

```php
if (isset($_GET["name"])) {
    echo $_GET["name"];
}
```

Мы спрашиваем:

> Существует ли элемент `name` в массиве `$_GET`?

Если существует, выводим его.

---

# 15. Вспоминаем оператор `??`

В лекции про операторы мы уже изучали:

```php
??
```

Он идеально подходит для работы с формами.

Например:

```php
$name = $_GET["name"] ?? "";
```

Можно прочитать:

> Если `$_GET["name"]` существует, взять его. Иначе использовать пустую строку.

Если имя передано:

```text
?name=Иван
```

получим:

```php
$name = "Иван";
```

Если нет:

```php
$name = "";
```

---

# 16. Первая полноценная форма

```php
<form method="GET">

    <input type="text" name="name">

    <button type="submit">Отправить</button>

</form>

<?php

$name = $_GET["name"] ?? "";

if ($name !== "") {
    echo "Привет, " . $name;
}

?>
```

Пользователь вводит:

```text
Иван
```

Получаем:

```text
Привет, Иван
```

---

# 17. Что происходит по шагам?

Когда пользователь нажимает кнопку:

```text
1. Браузер берёт данные формы

2. Формирует GET-запрос

3. Отправляет его серверу

4. PHP получает параметры

5. PHP помещает их в $_GET

6. Наш код получает $_GET["name"]

7. Выполняется if

8. Сервер формирует HTML-ответ

9. Браузер показывает результат
```

Это уже полноценная клиент-серверная работа.

---

# 18. Атрибут `action`

У формы есть ещё один важный атрибут:

```html
action
```

Он указывает, куда отправлять данные.

Например:

```html
<form action="result.php" method="GET"></form>
```

Теперь данные отправятся в:

```text
result.php
```

Можно создать два файла:

```text
index.php
result.php
```

---

# 19. Форма в `index.php`

```html
<form action="result.php" method="GET">
  <input type="text" name="name" />

  <button type="submit">Отправить</button>
</form>
```

---

# 20. Получение данных в `result.php`

```php
<?php

$name = $_GET["name"] ?? "";

echo "Привет, " . $name;
```

Теперь схема:

```text
index.php
   │
   │ пользователь заполняет форму
   ▼
result.php
   │
   │ PHP обрабатывает данные
   ▼
результат
```

---

# 21. Когда `action` не указан?

Можно написать:

```html
<form method="GET"></form>
```

без:

```html
action
```

Тогда форма обычно отправляет данные на текущую страницу.

То есть одна страница может:

1. показывать форму;
2. принимать данные;
3. обрабатывать данные;
4. выводить результат.

Для первых учебных примеров это очень удобно.

---

# 22. Что такое POST?

Теперь второй основной способ отправки данных:

```text
POST
```

Пример формы:

```html
<form method="POST">
  <input type="text" name="name" />

  <button type="submit">Отправить</button>
</form>
```

Главное отличие, которое сразу заметно:

данные не появляются в адресной строке так, как это происходит с GET.

---

# 23. `$_POST`

PHP помещает POST-данные в специальный массив:

```php
$_POST
```

Например:

```html
<form method="POST">
  <input type="text" name="name" />

  <button type="submit">Отправить</button>
</form>
```

PHP:

```php
$name = $_POST["name"] ?? "";

echo $name;
```

---

# 24. Сравнение `$_GET` и `$_POST`

GET:

```php
$_GET["name"]
```

POST:

```php
$_POST["name"]
```

Принцип почти одинаковый.

Разница заключается прежде всего в способе передачи данных.

---

# 25. Основное различие GET и POST

## GET

Данные передаются через URL.

Например:

```text
search.php?query=php&page=2
```

Подходит, например, для:

- поиска;
- фильтров;
- номера страницы;
- параметров просмотра.

## POST

Данные отправляются в теле HTTP-запроса.

Обычно используется для:

- форм регистрации;
- авторизации;
- отправки сообщений;
- изменения данных;
- создания записей.

---

# 26. GET хорошо подходит для поиска

Представим поиск:

```html
<form method="GET">
  <input type="text" name="query" />

  <button type="submit">Найти</button>
</form>
```

Пользователь вводит:

```text
PHP
```

URL:

```text
index.php?query=PHP
```

PHP:

```php
$query = $_GET["query"] ?? "";

if ($query !== "") {
    echo "Вы ищете: " . $query;
}
```

Такой URL можно:

- скопировать;
- сохранить;
- отправить другому человеку.

Поэтому для поиска GET очень удобен.

---

# 27. POST для формы регистрации

Например:

```html
<form method="POST">
  <input type="text" name="name" />

  <input type="number" name="age" />

  <button type="submit">Регистрация</button>
</form>
```

PHP:

```php
$name = $_POST["name"] ?? "";
$age = $_POST["age"] ?? "";

echo "Имя: " . $name . "<br>";
echo "Возраст: " . $age;
```

---

# 28. Несколько полей формы

Форма:

```html
<form method="POST">
  <input type="text" name="name" />

  <input type="email" name="email" />

  <input type="number" name="age" />

  <button type="submit">Отправить</button>
</form>
```

После отправки можно представить `$_POST` примерно так:

```php
$_POST = [
    "name" => "Иван",
    "email" => "ivan@mail.ru",
    "age" => "20"
];
```

То есть:

```text
HTML name
     ↓
ключ массива $_POST
```

---

# 29. Главное правило `name`

Рассмотрим:

```html
<input type="text" name="username" />
```

Получаем:

```php
$_POST["username"]
```

Если:

```html
<input type="text" name="city" />
```

то:

```php
$_POST["city"]
```

Если:

```html
<input type="number" name="age" />
```

то:

```php
$_POST["age"]
```

Название должно совпадать.

---

# 30. Если забыть `name`

Например:

```html
<input type="text" />
```

Пользователь сможет вводить данные.

Но поле не имеет имени.

PHP не сможет нормально получить его через:

```php
$_POST
```

Поэтому:

> Поля формы, данные которых необходимо отправлять серверу, должны иметь `name`.

---

# 31. Проверка пустого значения

Рассмотрим:

```php
$name = $_POST["name"] ?? "";
```

Пользователь может отправить форму, ничего не введя.

Тогда:

```php
$name === ""
```

Мы можем проверить:

```php
if ($name === "") {
    echo "Введите имя";
} else {
    echo "Привет, " . $name;
}
```

---

# 32. `trim()`

Но пользователь может ввести:

```text

```

То есть несколько пробелов.

Формально строка не пустая.

Для этого пригодится функция из прошлой лекции:

```php
trim()
```

Например:

```php
$name = $_POST["name"] ?? "";

$name = trim($name);
```

Теперь:

```text
"     "
```

превратится в:

```text
""
```

И проверка станет правильнее:

```php
if ($name === "") {
    echo "Введите имя";
}
```

# 34. Не всегда нужно сразу показывать ошибку

Есть небольшая проблема.

Когда пользователь только открыл страницу, он ещё ничего не отправлял.

Но наш код уже может вывести:

```text
Введите имя
```

Хотя пользователь ещё даже не пытался отправить форму.

Нужно определить:

> Была ли форма вообще отправлена?

---

# 35. `$_SERVER["REQUEST_METHOD"]`

PHP предоставляет ещё один специальный массив:

```php
$_SERVER
```

В нём находится информация о запросе и сервере.

Сейчас нам нужен только один элемент:

```php
$_SERVER["REQUEST_METHOD"]
```

Он может содержать, например:

```text
GET
```

или:

```text
POST
```

---

# 36. Проверка отправки POST-формы

```php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    echo "Форма отправлена";
}
```

Теперь код внутри выполняется только после POST-запроса.

---

# 37. Более правильный пример формы

```php
<form method="POST">

    <input type="text" name="name">

    <button type="submit">Отправить</button>

</form>

<?php

if ($_SERVER["REQUEST_METHOD"] === "POST") {

    $name = $_POST["name"] ?? "";

    $name = trim($name);

    if ($name === "") {
        echo "Введите имя";
    } else {
        echo "Привет, " . $name;
    }
}

?>
```

Теперь при первом открытии страницы ошибки нет.

Она появится только после отправки пустой формы.

---

# 38. Связь с функциями

В шестой лекции мы изучили важный принцип:

> Одна функция — одна понятная задача.

Поэтому проверку имени можно вынести отдельно.

Например:

```php
function validateName($name) {

    $name = trim($name);

    if ($name === "") {
        return false;
    }

    return true;
}
```

Теперь:

```php
$name = $_POST["name"] ?? "";

if (validateName($name)) {
    echo "Имя принято";
} else {
    echo "Введите имя";
}
```

---

# 39. Проверка длины имени

Мы уже знаем функцию:

```php
strlen()
```

Создадим:

```php
function validateName($name) {

    $name = trim($name);

    if ($name === "") {
        return false;
    }

    if (strlen($name) < 2) {
        return false;
    }

    return true;
}
```

Теперь имя должно:

1. быть введено;
2. содержать хотя бы два символа.

---

# 40. Проверка возраста

Получим:

```php
$age = $_POST["age"] ?? "";
```

Можно проверить:

```php
if ($age === "") {
    echo "Введите возраст";
}
```

Затем:

```php
if ($age < 18) {
    echo "Несовершеннолетний";
}
```

Но необходимо помнить:

> Данные формы являются внешними данными.

Нельзя автоматически считать, что пользователь ввёл именно то, что мы ожидаем.

---

# 41. `is_numeric()`

Для простой проверки числа существует:

```php
is_numeric()
```

Например:

```php
$age = "20";

if (is_numeric($age)) {
    echo "Это число";
}
```

Функция возвращает:

```text
true
```

если значение можно интерпретировать как число.

---

# 42. Функция проверки возраста

```php
function validateAge($age) {

    if ($age === "") {
        return false;
    }

    if (!is_numeric($age)) {
        return false;
    }

    if ($age < 0) {
        return false;
    }

    return true;
}
```

Использование:

```php
$age = $_POST["age"] ?? "";

if (validateAge($age)) {
    echo "Возраст принят";
} else {
    echo "Некорректный возраст";
}
```

---

# 43. Несколько проверок

Представим форму:

```html
<form method="POST">
  <input type="text" name="name" />

  <input type="number" name="age" />

  <button type="submit">Отправить</button>
</form>
```

PHP:

```php
$name = $_POST["name"] ?? "";
$age = $_POST["age"] ?? "";

$name = trim($name);

if ($name === "") {

    echo "Введите имя";

} elseif ($age === "") {

    echo "Введите возраст";

} elseif (!is_numeric($age)) {

    echo "Возраст должен быть числом";

} else {

    echo "Данные приняты";
}
```

Теперь начинают объединяться почти все предыдущие темы.

---

# 44. Полученные данные можно собрать в массив

Например:

```php
$name = $_POST["name"] ?? "";
$age = $_POST["age"] ?? "";
$email = $_POST["email"] ?? "";
```

После проверки можно создать:

```php
$user = [
    "name" => $name,
    "age" => $age,
    "email" => $email
];
```

Теперь:

```php
echo $user["name"];
```

или:

```php
foreach ($user as $key => $value) {
    echo $key . ": " . $value . "<br>";
}
```

То есть данные прошли такую цепочку:

```text
HTML-форма
    ↓
$_POST
    ↓
проверка
    ↓
$user
    ↓
дальнейшая обработка
```

---

# 45. Почему нельзя полностью доверять данным пользователя?

Пользователь может отправить:

```text
возраст = -100
```

или:

```text
возраст = abc
```

или оставить поле пустым.

Поэтому правило:

> Любые данные, пришедшие от пользователя, необходимо проверять.

Даже если HTML содержит:

```html
<input type="number" />
```

проверку всё равно необходимо выполнять на сервере.

HTML работает в браузере.

PHP работает на сервере.

Пользователь может отправить запрос и без нашей HTML-формы.

Поэтому сервер должен самостоятельно проверять данные.

# 46. Вывод пользовательского текста

Представим:

```php
$name = $_POST["name"] ?? "";

echo $name;
```

Пользователь управляет содержимым `$name`.

При выводе пользовательских данных в HTML обычно необходимо выполнять экранирование.

Для этого существует:

```php
htmlspecialchars()
```

Пример:

```php
$name = $_POST["name"] ?? "";

echo htmlspecialchars($name);
```

На данном этапе достаточно запомнить:

> Если выводим пользовательский текст обратно на HTML-страницу, безопаснее использовать `htmlspecialchars()`.

Подробно вопросы безопасности можно рассмотреть на отдельной лекции.

# 47. Функция безопасного вывода

Можно создать:

```php
function escape($value) {
    return htmlspecialchars($value);
}
```

Использование:

```php
$name = $_POST["name"] ?? "";

echo escape($name);
```

Это снова показывает, зачем нам нужны функции.

# 48. Пример анкеты пользователя

HTML:

```html
<form method="POST">
  <label>
    Имя:
    <input type="text" name="name" />
  </label>

  <br />

  <label>

    <input type="text" name="city" />
```

PHP:

```php
<?php

if ($_SERVER["REQUEST_METHOD"] === "POST") {

    $name = trim($_POST["name"] ?? "");

        echo "Введите имя";

        echo "Город: " . htmlspecialchars($city);
```

# 49. Разделяем программу на функции

Теперь сделаем код ближе к структуре, которую изучали в шестой лекции.

```php
function validateName($name) {

    $name = trim($name);

    return $name !== "";
}

function validateAge($age) {

    if ($age === "") {
        return false;
    }

    if (!is_numeric($age)) {
        return false;
    }

    if ($age < 0) {
        return false;
    }

    return true;
}
```

Основная программа:

```php
if ($_SERVER["REQUEST_METHOD"] === "POST") {

    $name = $_POST["name"] ?? "";
    $age = $_POST["age"] ?? "";

    if (!validateName($name)) {

        echo "Некорректное имя";

    } elseif (!validateAge($age)) {

        echo "Некорректный возраст";

    } else {

        echo "Данные приняты";
    }
}
```

Теперь каждая функция выполняет отдельную задачу.

# 50. GET и функции

Функции можно использовать и для GET.

Например, форма поиска:

```html
<form method="GET">
  <input type="text" name="query" />

  <button type="submit">Поиск</button>
</form>
```

Создадим функцию:

```php
function prepareSearchQuery($query) {
    return trim($query);
}
```

Использование:

```php
$query = $_GET["query"] ?? "";

$query = prepareSearchQuery($query);

if ($query !== "") {
    echo "Поиск: " . htmlspecialchars($query);
}
```

# 51. GET + массив + `in_array()`

Представим выбор категории:

```html
<form method="GET">
  <input type="text" name="category" />

  <button type="submit">Открыть</button>
</form>
```

У нас разрешены только:

```php
$categories = [
    "phones",
    "laptops",
    "monitors"
];
```

Получаем значение:

```php
$category = $_GET["category"] ?? "";
```

Проверяем:

```php
if (in_array($category, $categories)) {
    echo "Категория существует";
} else {
    echo "Категория не найдена";
}
```

Здесь используются:

```text
GET
$_GET
массив
in_array()
if
```

# 52. POST + функция + массив

Представим форму регистрации.

Получаем:

```php
$name = $_POST["name"] ?? "";
$age = $_POST["age"] ?? "";
$email = $_POST["email"] ?? "";
```

После проверки создаём:

```php
$user = [
    "name" => $name,
    "age" => $age,
    "email" => $email
];
```

Затем можно передать массив функции:

```php
function showUser($user) {

    echo "Имя: " . htmlspecialchars($user["name"]) . "<br>";
    echo "Возраст: " . htmlspecialchars($user["age"]) . "<br>";
    echo "Email: " . htmlspecialchars($user["email"]);
}
```

И вызвать:

```php
showUser($user);
```

# 53. Что такое superglobal?

Массивы:

```php
$_GET
$_POST
$_SERVER
```

относятся к специальным переменным PHP.

Их называют:

```text
superglobals
```

или:

```text
суперглобальные переменные
```

Пока не нужно запоминать все суперглобальные массивы.

На этом занятии достаточно знать:

```text
$_GET
→ данные GET-запроса

$_POST
→ данные POST-запроса

$_SERVER
→ информация о сервере и текущем запросе
```

# 54. Важная связь с областью видимости

На прошлом занятии мы говорили, что обычная внешняя переменная недоступна внутри функции автоматически.

Например:

```php
$name = "Иван";

function test() {
    echo $name;
}
```

Так писать неправильно.

Но суперглобальные массивы являются специальным исключением.

Например:

```php
function getName() {
    return $_POST["name"] ?? "";
}
```

`$_POST` доступен внутри функции.

Но злоупотреблять этим не стоит.

Часто понятнее передать данные через параметры.

Например:

```php
function validateName($name) {
    return trim($name) !== "";
}
```

# 55. GET или POST?

Можно использовать простое правило.

### GET

Когда пользователь получает или ищет информацию.

Например:

```text
поиск
фильтр
страница каталога
категория
сортировка
```

### POST

Когда пользователь отправляет данные для обработки или изменения состояния.

Например:

```text
регистрация
авторизация
отправка сообщения
создание записи
изменение профиля
```

Это пока упрощённое правило, но для начала его достаточно.

# 56. Пароли и GET

Пароли нельзя отправлять через GET-форму.

Плохо:

```html
<form method="GET">
  <input type="password" name="password" />
</form>
```

Потому что значение может оказаться в URL.

Для форм авторизации используется POST:

```html
<form method="POST">
  <input type="password" name="password" />
</form>
```

При этом важно понимать:

> POST сам по себе не шифрует данные.

За защищённую передачу данных отвечает HTTPS.

К безопасности авторизации мы вернёмся позже.

# 57. Типичная ошибка №1 — забыли `name`

Плохо:

```html
<input type="text" />
```

PHP не получает удобного имени параметра.

Правильно:

```html
<input type="text" name="username" />
```

Теперь:

```php
$_POST["username"]
```

# 58. Типичная ошибка №2 — перепутали GET и POST

Форма:

```html
<form method="POST"></form>
```

Но PHP:

```php
$name = $_GET["name"];
```

Это неправильно.

Для:

```html
method="POST"
```

используем:

```php
$_POST
```

Для:

```html
method="GET"
```

используем:

```php
$_GET
```

# 59. Типичная ошибка №3 — обращение к отсутствующему ключу

Плохо:

```php
$name = $_POST["name"];
```

если форма ещё не отправлена.

Лучше:

```php
$name = $_POST["name"] ?? "";
```

# 60. Типичная ошибка №4 — отсутствие проверки

Плохо:

```php
$age = $_POST["age"] ?? "";

echo "Возраст: " . $age;
```

Здесь мы просто принимаем любое значение.

Лучше сначала проверить:

```php
if ($age === "") {
    echo "Введите возраст";
} elseif (!is_numeric($age)) {
    echo "Возраст должен быть числом";
}
```

---

# 61. Типичная ошибка №5 — доверять HTML-проверке

Например:

```html
<input type="number" name="age" />
```

Это удобно для пользователя.

Но PHP всё равно должен проверить:

```php
is_numeric($age)
```

Потому что сервер не должен доверять данным клиента.

# 62. Типичная ошибка №6 — сразу выводить пользовательский текст

Лучше:

```php
echo htmlspecialchars($name);
```

чем:

```php
echo $name;
```

если значение пришло непосредственно от пользователя.

# 63. Большой пример — регистрационная форма

HTML:

```html
<form method="POST">
  <label>
    Имя:
    <input type="text" name="name" />
  </label>

  <br /><br />

  <label>
    Возраст:
    <input type="number" name="age" />
  </label>

  <br /><br />

  <label>
    Email:
    <input type="email" name="email" />
  </label>

  <br /><br />

  <button type="submit">Зарегистрироваться</button>
</form>
```

PHP:

```php
<?php

function validateName($name) {

    $name = trim($name);

    if ($name === "") {
        return false;
    }

    if (strlen($name) < 2) {
        return false;
    }

    return true;
}

function validateAge($age) {

    if ($age === "") {
        return false;
    }

    if (!is_numeric($age)) {
        return false;
    }

    if ($age < 1) {
        return false;
    }

    return true;
}

if ($_SERVER["REQUEST_METHOD"] === "POST") {

    $name = $_POST["name"] ?? "";
    $age = $_POST["age"] ?? "";
    $email = $_POST["email"] ?? "";

    if (!validateName($name)) {

        echo "Некорректное имя";

    } elseif (!validateAge($age)) {

        echo "Некорректный возраст";

    } elseif (trim($email) === "") {

        echo "Введите email";

    } else {

        $user = [
            "name" => trim($name),
            "age" => $age,
            "email" => trim($email)
        ];

        echo "Регистрация успешна<br><br>";

        echo "Имя: " . htmlspecialchars($user["name"]) . "<br>";
        echo "Возраст: " . htmlspecialchars($user["age"]) . "<br>";
        echo "Email: " . htmlspecialchars($user["email"]);
    }
}

?>
```

# 64. Какие темы здесь объединились?

В одном примере уже используются:

```text
HTML-форма
        ↓
POST
        ↓
$_POST
        ↓
ассоциативный массив
        ↓
переменные
        ↓
функции
        ↓
return
        ↓
if / elseif / else
        ↓
операторы
        ↓
встроенные функции
        ↓
$user
        ↓
вывод результата
```

Это важный момент курса.

Раньше мы изучали конструкции по отдельности.

Теперь начинаем использовать их вместе в одной программе.

# 65. Общая схема обработки формы

Эту последовательность важно запомнить:

```text
1. Показать форму
        ↓
2. Пользователь вводит данные
        ↓
3. Пользователь нажимает кнопку
        ↓
4. Браузер отправляет запрос
        ↓
5. PHP получает $_GET или $_POST
        ↓
6. Получаем нужные значения
        ↓
7. Проверяем данные
        ↓
8. Выполняем нужную логику
        ↓
9. Выводим результат
```

### GET-форма

### POST-форма

```php
$value = $_POST["name"] ?? "";
```

```php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
```

```php
$value = trim($value);
```

```php
isset($array["key"])
```

```php
$value = $array["key"] ?? "";
```

```php
is_numeric($value)
```

```php
htmlspecialchars($value)
```
