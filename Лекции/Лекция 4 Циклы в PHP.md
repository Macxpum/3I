## 1. Зачем нужны циклы?

Представим, что нам нужно вывести числа от 1 до 5.

Без цикла:

```php
echo 1;
echo 2;
echo 3;
echo 4;
echo 5;
```

Работает, но уже при 100 числах такой подход становится бессмысленным.

С циклом:

```php
for ($i = 1; $i <= 5; $i++) {
    echo $i;
}
```

Получаем тот же результат, но всего несколькими строками.

Циклы особенно полезны, когда необходимо:

- повторить действие несколько раз;
- перебрать массив;
- обработать список пользователей;
- вывести товары;
- выполнить операцию определённое количество раз;
- работать с данными, количество которых заранее неизвестно.

---

# 2. Как вообще работает цикл?

У любого цикла есть примерно такая логика:

```text
             ┌─────────────┐
             │   Условие   │
             └──────┬──────┘
                    │
              ┌─────┴─────┐
             true        false
              │             │
              ▼             ▼
        Выполнить код      Выход
              │
              ▼
          Вернуться
          к условию
```

Например:

```php
while ($i <= 5) {
    echo $i;
    $i++;
}
```

PHP делает:

```text
Проверить условие
       ↓
Выполнить код
       ↓
Изменить переменную
       ↓
Снова проверить условие
       ↓
...
```

# 3. Основные виды циклов в PHP

В PHP используются несколько основных циклов:

```text
for
while
do...while
foreach
```

Каждый из них подходит для своей ситуации.

| Цикл         | Основное применение                           |
| ------------ | --------------------------------------------- |
| `for`        | когда заранее известно количество повторений  |
| `while`      | когда повторяем, пока выполняется условие     |
| `do...while` | когда код должен выполниться хотя бы один раз |
| `foreach`    | перебор элементов массива                     |

---

# 4. Цикл `for`

Начнём с самого распространённого варианта.

Общий синтаксис:

```php
for (начало; условие; изменение) {
    // код
}
```

Например:

```php
for ($i = 1; $i <= 5; $i++) {
    echo $i;
}
```

Результат:

```text
12345
```

Если добавить перенос строки:

```php
for ($i = 1; $i <= 5; $i++) {
    echo $i . "<br>";
}
```

Получим:

```text
1
2
3
4
5
```

---

# 5. Из чего состоит `for`?

Вот эта конструкция:

```php
for ($i = 1; $i <= 5; $i++) {
```

состоит из трёх частей:

```text
for (
    начало;
    условие;
    изменение
)
```

### 1. Начало

```php
$i = 1
```

Создаём счётчик и устанавливаем его начальное значение.

### 2. Условие

```php
$i <= 5
```

Пока условие истинно, цикл продолжает работать.

### 3. Изменение

```php
$i++
```

После каждой итерации увеличиваем `$i` на единицу.

---

# 6. Что такое итерация?

**Итерация — это одно выполнение тела цикла.**

Например:

```php
for ($i = 1; $i <= 3; $i++) {
    echo $i;
}
```

Будет три итерации:

```text
Итерация 1 → $i = 1
Итерация 2 → $i = 2
Итерация 3 → $i = 3
```

После этого:

```text
$i = 4
```

Проверяется:

```text
4 <= 3
```

Получаем `false`.

Цикл заканчивается.

---

# 7. Подробно разберём работу `for`

Рассмотрим:

```php
for ($i = 1; $i <= 3; $i++) {
    echo $i;
}
```

PHP выполняет:

### Шаг 1

```php
$i = 1;
```

Проверка:

```text
1 <= 3 → true
```

Выполняем:

```text
1
```

Затем:

```php
$i++;
```

Теперь `$i = 2`.

---

### Шаг 2

```text
2 <= 3 → true
```

Вывод:

```text
2
```

Затем `$i++`.

Теперь `$i = 3`.

---

### Шаг 3

```text
3 <= 3 → true
```

Вывод:

```text
3
```

Затем `$i++`.

Теперь `$i = 4`.

---

### Шаг 4

```text
4 <= 3 → false
```

Цикл заканчивается.

---

# 8. Обратный отсчёт

Счётчик может не только увеличиваться.

Например:

```php
for ($i = 5; $i >= 1; $i--) {
    echo $i . "<br>";
}
```

Получим:

```text
5
4
3
2
1
```

Здесь:

```php
$i--
```

уменьшает значение на единицу.

---

# 9. Шаг может быть больше единицы

Например, вывести только чётные числа:

```php
for ($i = 2; $i <= 10; $i += 2) {
    echo $i . "<br>";
}
```

Результат:

```text
2
4
6
8
10
```

Здесь после каждой итерации:

```text
$i = $i + 2
```

---

# 10. Цикл от 0

Очень часто счётчик начинается с нуля:

```php
for ($i = 0; $i < 5; $i++) {
    echo $i . "<br>";
}
```

Получим:

```text
0
1
2
3
4
```

Обратите внимание:

```php
$i < 5
```

а не:

```php
$i <= 5
```

Поэтому `5` уже не выводится.

---

# 11. `for` и массивы

Например:

```php
$numbers = [10, 20, 30, 40];
```

У массива четыре элемента.

Их индексы:

```text
0 → 10
1 → 20
2 → 30
3 → 40
```

Можно перебрать их через `for`:

```php
for ($i = 0; $i < 4; $i++) {
    echo $numbers[$i] . "<br>";
}
```

Получим:

```text
10
20
30
40
```

Но для обычного перебора массива существует более удобный `foreach`.

# 12. Цикл `while`

Теперь другой подход.

`while` означает примерно:

> **Пока условие истинно — выполняй код.**

Синтаксис:

```php
while (условие) {
    // код
}
```

Например:

```php
$i = 1;

while ($i <= 5) {
    echo $i . "<br>";
    $i++;
}
```

Результат:

```text
1
2
3
4
5
```

---

# 13. Отличие `while` от `for`

Сравним.

### `for`

```php
for ($i = 1; $i <= 5; $i++) {
    echo $i;
}
```

### `while`

```php
$i = 1;

while ($i <= 5) {
    echo $i;
    $i++;
}
```

Оба варианта делают одно и то же.

Разница в том, как мы мыслим о задаче.

`for` удобно использовать, когда мы говорим:

> Сделать что-то **5 раз**.

`while`:

> Делать что-то **пока выполняется условие**.

---

# 14. Пример, где `while` удобнее

Представим, что у нас есть баланс:

```php
$balance = 1000;
```

И каждый месяц со счёта списывается:

```text
200 рублей
```

Мы хотим узнать, сколько месяцев можно оплачивать расходы.

```php
$balance = 1000;
$months = 0;

while ($balance >= 200) {
    $balance -= 200;
    $months++;
}

echo "Можно оплатить месяцев: " . $months;
```

Результат:

```text
Можно оплатить месяцев: 5
```

Здесь заранее не обязательно писать:

```text
for 5 раз
```

Мы говорим:

> Пока на счёте достаточно денег — продолжать.

Это естественный случай для `while`.

---

# 15. Очень важный момент: изменение условия

Рассмотрим:

```php
$i = 1;

while ($i <= 5) {
    echo $i;
}
```

Что произойдёт?

Программа никогда не изменяет `$i`.

Поэтому:

```text
$i = 1
1 <= 5 → true

$i = 1
1 <= 5 → true

$i = 1
1 <= 5 → true

...
```

Получится **бесконечный цикл**.

Правильно:

```php
$i = 1;

while ($i <= 5) {
    echo $i;
    $i++;
}
```

---

# 16. Бесконечные циклы

Бесконечный цикл — это цикл, который никогда не заканчивается.

Например:

```php
while (true) {
    echo "Hello";
}
```

Условие всегда:

```text
true
```

Поэтому цикл продолжается бесконечно.

В реальных программах бесконечные циклы иногда нужны, например в серверных процессах, но для обычных учебных задач это почти всегда ошибка.

---

# 17. Цикл `do...while`

Теперь интересная разновидность `while`.

Синтаксис:

```php
do {
    // код
} while (условие);
```

Главное отличие:

> **Сначала выполняется код, а потом проверяется условие.**

Например:

```php
$i = 1;

do {
    echo $i;
    $i++;
} while ($i <= 5);
```

Получим:

```text
12345
```

---

# 18. Главное отличие while и do...while

Рассмотрим:

```php
$i = 10;

while ($i < 5) {
    echo "Hello";
}
```

Условие сразу:

```text
10 < 5 → false
```

Поэтому код **не выполнится ни разу**.

Теперь:

```php
$i = 10;

do {
    echo "Hello";
} while ($i < 5);
```

Сначала выполняется:

```text
Hello
```

И только потом проверяется:

```text
10 < 5 → false
```

Поэтому `do...while` выполнит тело **минимум один раз**.

---

# 19. Сравнение циклов

| Цикл         | Когда проверяется условие? |
| ------------ | -------------------------- |
| `while`      | перед выполнением          |
| `do...while` | после выполнения           |
| `for`        | перед каждой итерацией     |
| `foreach`    | для каждого элемента       |

Можно запомнить:

```text
while
↓
сначала проверка
потом действие


do...while
↓
сначала действие
потом проверка
```

---

# 20. Где может пригодиться do...while?

Классический пример — меню.

Допустим, программа должна показать меню хотя бы один раз:

```php
do {
    echo "1. Просмотреть профиль<br>";
    echo "2. Настройки<br>";
    echo "0. Выход<br>";

    // получение выбора пользователя

} while ($choice !== 0);
```

Сначала меню должно появиться.

После выбора пользователя программа решает, продолжать ли работу.

# 21. Цикл foreach

Теперь самый важный цикл для работы с массивами.

`foreach` используется для **перебора элементов массива**.

Например:

```php
$names = ["Иван", "Пётр", "Анна"];
```

Можно написать:

```php
foreach ($names as $name) {
    echo $name . "<br>";
}
```

Результат:

```text
Иван
Пётр
Анна
```

---

# 22. Как работает foreach?

Конструкция:

```php
foreach ($names as $name)
```

означает:

> Взять каждый элемент массива `$names` и по очереди записать его в переменную `$name`.

Можно представить:

```text
$names
   │
   ├── "Иван"  → $name
   ├── "Пётр"  → $name
   └── "Анна"  → $name
```

На каждой итерации `$name` содержит очередной элемент.

---

# 23. Почему foreach удобнее for?

Допустим:

```php
$names = ["Иван", "Пётр", "Анна"];
```

Через `for`:

```php
for ($i = 0; $i < count($names); $i++) {
    echo $names[$i];
}
```

Через `foreach`:

```php
foreach ($names as $name) {
    echo $name;
}
```

Второй вариант проще читать.

Мы не занимаемся индексами — нам просто нужны элементы.

Поэтому правило:

> Если нужно просто перебрать массив — чаще всего используйте `foreach`.

---

# 24. foreach с индексом

Иногда нам нужен не только элемент, но и его ключ.

Можно написать:

```php
foreach ($names as $index => $name) {
    echo $index . ": " . $name . "<br>";
}
```

Получим:

```text
0: Иван
1: Пётр
2: Анна
```

Здесь:

```text
$index → ключ
$name  → значение
```

# 25. Ассоциативные массивы

Массив может иметь не числовые, а именованные ключи.

Например:

```php
$student = [
    "name" => "Иван",
    "age" => 20,
    "group" => "ИСП-231"
];
```

Можно перебрать его:

```php
foreach ($student as $key => $value) {
    echo $key . ": " . $value . "<br>";
}
```

Получим:

```text
name: Иван
age: 20
group: ИСП-231
```

Это очень важный шаблон, который постоянно встречается в PHP.

# 26. Циклы и if

Циклы часто используются вместе с условиями.

Например, вывести только чётные числа:

```php
for ($i = 1; $i <= 10; $i++) {
    if ($i % 2 === 0) {
        echo $i . "<br>";
    }
}
```

Результат:

```text
2
4
6
8
10
```

Логика:

```text
Цикл
 ↓
получить число
 ↓
проверить if
 ↓
чётное?
 ├─ да → вывести
 └─ нет → пропустить
 ↓
следующее число
```

---

# 27. Цикл внутри цикла

Циклы можно вкладывать друг в друга.

Например, вывести таблицу:

```php
for ($i = 1; $i <= 3; $i++) {

    for ($j = 1; $j <= 3; $j++) {
        echo "$i $j<br>";
    }

}
```

Получим:

```text
1 1
1 2
1 3
2 1
2 2
2 3
3 1
3 2
3 3
```

Внешний цикл управляет `$i`.

Внутренний — `$j`.

---

# 28. Пример: таблица умножения

```php
for ($i = 1; $i <= 10; $i++) {

    for ($j = 1; $j <= 10; $j++) {
        echo $i * $j . " ";
    }

    echo "<br>";
}
```

Получаем таблицу умножения.

Это хороший пример для понимания **вложенных циклов**.

# 29. Оператор break

Иногда нужно досрочно завершить цикл.

Для этого используется:

```php
break;
```

Например:

```php
for ($i = 1; $i <= 10; $i++) {

    if ($i === 5) {
        break;
    }

    echo $i . "<br>";
}
```

Результат:

```text
1
2
3
4
```

Когда `$i` становится `5`, выполняется:

```php
break;
```

и цикл полностью заканчивается.

---

# 30. Где полезен break?

Например, ищем пользователя:

```php
$names = ["Иван", "Пётр", "Анна", "Алексей"];

foreach ($names as $name) {

    if ($name === "Анна") {
        echo "Пользователь найден";
        break;
    }
}
```

После нахождения нужного элемента нет смысла продолжать перебор.

---

# 31. Оператор continue

Другой оператор:

```php
continue;
```

Он **не завершает цикл**, а пропускает текущую итерацию.

Например:

```php
for ($i = 1; $i <= 5; $i++) {

    if ($i === 3) {
        continue;
    }

    echo $i . "<br>";
}
```

Результат:

```text
1
2
4
5
```

Когда `$i` равен `3`, выполняется `continue`.

PHP пропускает оставшуюся часть текущей итерации и переходит к следующей.

---

# 32. Разница между break и continue

Это обязательно нужно закрепить:

```text
break
↓
полностью остановить цикл


continue
↓
пропустить текущую итерацию
↓
продолжить цикл
```

Пример:

```php
if ($i === 5) {
    break;
}
```

→ цикл заканчивается.

А:

```php
if ($i === 5) {
    continue;
}
```

→ `5` пропускается, но цикл продолжается.

$products = [

foreach ($products as $product) {

```text

```

foreach ($products as $product) {

# 35. Какой цикл когда использовать?

Это один из главных вопросов лекции.

### Используйте `for`, когда:

количество повторений известно:

```php
for ($i = 0; $i < 10; $i++) {
}
```

Например:

> Вывести числа от 1 до 10.

---

### Используйте `while`, когда:

важно условие продолжения:

```php
while ($balance > 0) {
}
```

Например:

> Пока есть деньги — выполнять операцию.

---

### Используйте `do...while`, когда:

код должен выполниться хотя бы один раз:

```php
do {
    // меню
} while ($choice !== 0);
```

---

### Используйте `foreach`, когда:

нужно перебрать массив:

```php
foreach ($users as $user) {
}
```

# 36. Типичные ошибки

## Ошибка 1. Забыли изменить счётчик

Плохо:

```php
$i = 1;

while ($i <= 10) {
    echo $i;
}
```

Получится бесконечный цикл.

Правильно:

```php
$i = 1;

while ($i <= 10) {
    echo $i;
    $i++;
}
```

---

## Ошибка 2. Неправильная граница

Например:

```php
for ($i = 0; $i <= 10; $i++) {
```

выполнится **11 раз**:

```text
0 ... 10
```

Если нужно ровно 10 раз:

```php
for ($i = 0; $i < 10; $i++) {
```

будет:

```text
0 ... 9
```

---

## Ошибка 3. Неправильное изменение счётчика

Например:

```php
for ($i = 10; $i <= 1; $i++) {
```

Цикл не выполнится ни разу.

Если идём от 10 к 1:

```php
for ($i = 10; $i >= 1; $i--) {
```
