
## 1. Что такое условные конструкции?

До этого момента наши программы в основном выполняли команды последовательно:

```php
$name = "Иван";
$age = 20;

echo $name;
echo $age;
```

PHP выполняет эти инструкции одну за другой.

Но реальные программы должны уметь **принимать решения**.

Например:

- если пользователю есть 18 лет — разрешить доступ;
- если пароль правильный — выполнить вход;
- если сумма заказа больше 5000 — дать скидку;
- если оценка равна 5 — вывести «Отлично»;
- если товар закончился — сообщить об этом.

Для этого используются **условные конструкции**.

Основная идея:

```text
ЕСЛИ условие выполняется
    сделать одно
ИНАЧЕ
    сделать другое
```

В PHP для этого используются:

- `if`
- `else`
- `elseif`
- `switch`
- `case`
- `default`
- `match` — современная конструкция, которую можно изучить дополнительно.

---

# 2. Что такое условие?

Условие — это выражение, результатом которого является `true` или `false`.

Например:

```php
$age >= 18
```

Если:

```php
$age = 20;
```

то:

```text
20 >= 18
```

результат:

```text
true
```

Если:

```php
$age = 15;
```

то:

```text
15 >= 18
```

результат:

```text
false
```

То есть условие можно представить так:

```text
        УСЛОВИЕ
           │
      ┌────┴────┐
    true       false
      │           │
      ▼           ▼
   действие    другое
```

---

# 3. Конструкция if

Самая простая условная конструкция — `if`.

Синтаксис:

```php
if (условие) {
    // код
}
```

Например:

```php
$age = 20;

if ($age >= 18) {
    echo "Доступ разрешён";
}
```

Разберём программу:

```php
if ($age >= 18)
```

PHP проверяет условие:

```text
20 >= 18
```

Получает:

```text
true
```

Поэтому выполняет код внутри фигурных скобок:

```php
{
    echo "Доступ разрешён";
}
```

Результат:

```text
Доступ разрешён
```

---

# 4. Что произойдёт, если условие false?

Например:

```php
$age = 15;

if ($age >= 18) {
    echo "Доступ разрешён";
}
```

Проверяем:

```text
15 >= 18
```

Получаем:

```text
false
```

Поэтому код внутри `if` не выполняется.

Программа ничего не выведет.

Это важно:

> `if` выполняет код только тогда, когда условие истинно.

---

# 5. Фигурные скобки

Код, который должен выполняться при истинном условии, помещается в `{ }`.

Например:

```php
if ($age >= 18) {
    echo "Доступ разрешён";
    echo "Добро пожаловать!";
}
```

Если условие истинно, выполняются **обе команды**:

```text
Доступ разрешён
Добро пожаловать!
```

Фигурные скобки показывают PHP, какой именно блок кода относится к условию.

---

# 6. Несколько действий внутри if

Например:

```php
$balance = 1000;

if ($balance > 0) {
    echo "Баланс положительный";
    echo "Можно совершить покупку";
    echo "Текущий баланс: $balance";
}
```

Все три команды выполнятся, если условие истинно.

---

# 7. Конструкция else

Что делать, если условие оказалось ложным?

Для этого используется `else`.

Синтаксис:

```php
if (условие) {
    // если true
} else {
    // если false
}
```

Пример:

```php
$age = 15;

if ($age >= 18) {
    echo "Доступ разрешён";
} else {
    echo "Доступ запрещён";
}
```

Проверяем:

```text
15 >= 18
```

Получаем:

```text
false
```

Поэтому выполняется `else`.

Результат:

```text
Доступ запрещён
```

---

# 8. Как работает if + else

Можно представить конструкцию как развилку:

```text
                  Условие
                     │
             ┌───────┴───────┐
            true            false
             │                │
             ▼                ▼
        код if            код else
```

Например:

```php
if ($age >= 18) {
    echo "Совершеннолетний";
} else {
    echo "Несовершеннолетний";
}
```

Всегда будет выполнена **одна из двух ветвей**.

---

# 9. Пример с паролем

```php
$password = "12345";

if ($password === "12345") {
    echo "Пароль правильный";
} else {
    echo "Неверный пароль";
}
```

Здесь условие:

```php
$password === "12345"
```

Проверяет, совпадает ли введённый пароль с правильным.

Обратите внимание на `===`.

При сравнении строк желательно использовать строгое сравнение:

```php
===
```

---

# 10. Несколько условий: elseif

Иногда двух вариантов недостаточно.

Например, нужно определить оценку:

```text
5 → Отлично
4 → Хорошо
3 → Удовлетворительно
2 → Неудовлетворительно
```

Можно использовать `elseif`.

Синтаксис:

```php
if (условие1) {

} elseif (условие2) {

} elseif (условие3) {

} else {

}
```

Пример:

```php
$grade = 4;

if ($grade === 5) {
    echo "Отлично";
} elseif ($grade === 4) {
    echo "Хорошо";
} elseif ($grade === 3) {
    echo "Удовлетворительно";
} else {
    echo "Неудовлетворительно";
}
```

---

# 11. Как PHP выполняет elseif?

Очень важно понять принцип.

PHP проверяет условия **сверху вниз**.

Например:

```php
$grade = 4;

if ($grade === 5) {
    echo "Отлично";
} elseif ($grade === 4) {
    echo "Хорошо";
} elseif ($grade === 3) {
    echo "Удовлетворительно";
}
```

PHP делает:

```text
grade === 5?
     │
    нет
     ↓
grade === 4?
     │
    да
     ↓
"Хорошо"
```

После нахождения первого истинного условия PHP выполняет соответствующий блок и **не проверяет остальные `elseif`**.

---

# 12. Важный пример с несколькими подходящими условиями

Рассмотрим:

```php
$age = 20;

if ($age >= 18) {
    echo "18+";
} elseif ($age >= 21) {
    echo "21+";
}
```

На первый взгляд может показаться, что для возраста 20 программа дойдёт до второго условия.

Но нет.

Первое условие:

```text
20 >= 18
```

равно `true`.

Поэтому PHP сразу выполнит:

```text
18+
```

и до второго `elseif` не дойдёт.

Поэтому **порядок условий имеет значение**.

---

# 13. Правильный порядок условий

Если мы хотим определить возрастную категорию:

```php
$age = 25;

if ($age >= 21) {
    echo "21+";
} elseif ($age >= 18) {
    echo "18+";
} else {
    echo "До 18";
}
```

Теперь:

```text
25 >= 21 → true
```

Получаем:

```text
21+
```

Условия расположены от более строгого к менее строгому.

---

# 14. Вложенные условия

`if` может находиться внутри другого `if`.

Например:

```php
$age = 20;
$hasTicket = true;

if ($age >= 18) {
    if ($hasTicket === true) {
        echo "Можно войти";
    }
}
```

Сначала проверяется возраст.

Если пользователь совершеннолетний, проверяется наличие билета.

Логика:

```text
Возраст >= 18?
       │
      да
       ↓
Есть билет?
       │
      да
       ↓
Можно войти
```

---

# 15. Когда нужны вложенные if?

Вложенные условия полезны, когда одно действие имеет смысл только после другого.

Например:

```php
if ($isAuthorized) {
    if ($isAdmin) {
        echo "Панель администратора";
    }
}
```

Но чрезмерное использование вложенных условий делает код сложным.

Иногда лучше объединить условия:

```php
if ($isAuthorized && $isAdmin) {
    echo "Панель администратора";
}
```

Вторая запись обычно проще для понимания.

---

# 16. Логические операторы внутри if

В условиях активно используются логические операторы.

Например:

```php
$age = 20;
$isBlocked = false;

if ($age >= 18 && $isBlocked === false) {
    echo "Доступ разрешён";
}
```

Здесь одновременно проверяются два условия:

```text
возраст >= 18
        И
пользователь не заблокирован
```

Оба должны быть истинными.

---

# 17. Использование OR

Например, у пользователя может быть один из двух типов доступа:

```php
$isAdmin = false;
$isTeacher = true;

if ($isAdmin || $isTeacher) {
    echo "Доступ разрешён";
}
```

Условие читается:

> Если пользователь администратор ИЛИ преподаватель — разрешить доступ.

---

# 18. Отрицание условия

Можно использовать `!`.

Например:

```php
$isBlocked = false;

if (!$isBlocked) {
    echo "Пользователь не заблокирован";
}
```

Здесь:

```text
$isBlocked = false

!false → true
```

Поэтому условие выполняется.

Однако для начинающих часто понятнее писать:

```php
if ($isBlocked === false) {
```

чем:

```php
if (!$isBlocked) {
```

По мере изучения PHP студенты научатся выбирать более подходящую форму.

---

# 19. Условия можно строить из разных операторов

Например:

```php
$age = 20;
$city = "Москва";

if ($age >= 18 && $city === "Москва") {
    echo "Условие выполнено";
}
```

Здесь используются:

- переменные;
- строки;
- числа;
- `>=`;
- `===`;
- `&&`;
- `if`.

Это хороший пример того, как темы предыдущих лекций начинают объединяться.

# 20. Конструкция switch

Теперь рассмотрим другой способ построения условий.

Представим, что у нас есть переменная:

```php
$day = 3;
```

Нужно определить день недели:

```text
1 → Понедельник
2 → Вторник
3 → Среда
4 → Четверг
5 → Пятница
```

Можно написать много `elseif`:

```php
if ($day === 1) {
    echo "Понедельник";
} elseif ($day === 2) {
    echo "Вторник";
} elseif ($day === 3) {
    echo "Среда";
} elseif ($day === 4) {
    echo "Четверг";
} elseif ($day === 5) {
    echo "Пятница";
}
```

Но когда мы сравниваем **одну переменную с множеством конкретных значений**, `switch` может быть удобнее.

---

# 21. Синтаксис switch

Общий вид:

```php
switch ($variable) {
    case значение1:
        // код
        break;

    case значение2:
        // код
        break;

    default:
        // если ничего не подошло
}
```

Например:

```php
$day = 3;

switch ($day) {
    case 1:
        echo "Понедельник";
        break;

    case 2:
        echo "Вторник";
        break;

    case 3:
        echo "Среда";
        break;

    case 4:
        echo "Четверг";
        break;

    case 5:
        echo "Пятница";
        break;

    default:
        echo "Неизвестный день";
}
```

Результат:

```text
Среда
```

---

# 22. Как работает switch?

Сначала PHP получает значение:

```php
$day = 3;
```

Затем сравнивает его с `case`.

```text
3 == 1 → нет
3 == 2 → нет
3 == 3 → да
```

После этого выполняется:

```php
echo "Среда";
```

---

# 23. Зачем нужен break?

Это одна из самых важных вещей в `switch`.

Рассмотрим:

```php
$day = 3;

switch ($day) {
    case 1:
        echo "Понедельник";

    case 2:
        echo "Вторник";

    case 3:
        echo "Среда";

    case 4:
        echo "Четверг";
}
```

В старом стиле PHP после совпадения выполнение может продолжиться в следующих `case`.

То есть без `break` можно получить несколько результатов.

Поэтому обычно пишут:

```php
case 3:
    echo "Среда";
    break;
```

`break` говорит:

> Мы нашли нужный вариант. Выходим из `switch`.

---

# 24. Правильный switch

Обычно конструкция выглядит так:

```php
switch ($day) {
    case 1:
        echo "Понедельник";
        break;

    case 2:
        echo "Вторник";
        break;

    case 3:
        echo "Среда";
        break;

    default:
        echo "Неизвестный день";
}
```

Каждый `case` обычно заканчивается `break`.

---

# 25. Что такое default?

`default` — это вариант:

> Ни один `case` не подошёл.

Например:

```php
$day = 10;

switch ($day) {
    case 1:
        echo "Понедельник";
        break;

    case 2:
        echo "Вторник";
        break;

    case 3:
        echo "Среда";
        break;

    default:
        echo "Такого дня нет";
}
```

Поскольку:

```text
10
```

не совпало ни с одним `case`, выполнится:

```text
Такого дня нет
```

---

# 26. Несколько case для одного действия

Это полезная возможность.

Допустим, нужно определить рабочий или выходной день.

```php
$day = 6;

switch ($day) {
    case 1:
    case 2:
    case 3:
    case 4:
    case 5:
        echo "Рабочий день";
        break;

    case 6:
    case 7:
        echo "Выходной";
        break;

    default:
        echo "Некорректный день";
}
```

Здесь несколько `case` приводят к одному действию.

Логика:

```text
1 ─┐
2 ─┤
3 ─┤
4 ─┤──→ Рабочий день
5 ─┘

6 ─┐
   ├──→ Выходной
7 ─┘
```

---

# 27. switch и строки

`switch` можно использовать не только с числами.

Например:

```php
$role = "admin";

switch ($role) {
    case "admin":
        echo "Администратор";
        break;

    case "manager":
        echo "Менеджер";
        break;

    case "user":
        echo "Пользователь";
        break;

    default:
        echo "Неизвестная роль";
}
```

Это особенно удобно, когда у нас есть фиксированный набор вариантов.

---

# 28. switch или if/elseif?

Это важный вопрос.

### Используйте if/elseif, когда:

условия разные:

```php
if ($age >= 18) {

} elseif ($age >= 14) {

} else {

}
```

Здесь мы проверяем диапазоны.

---

### Используйте switch, когда:

мы сравниваем одну переменную с конкретными значениями:

```php
switch ($role) {
    case "admin":
        ...
        break;

    case "user":
        ...
        break;
}
```

То есть:

```text
if/elseif
→ сложные или диапазонные условия

switch
→ много конкретных вариантов одного значения
```

# 29. Пример: оценка через if

Можно сделать:

```php
$grade = 5;

if ($grade === 5) {
    echo "Отлично";
} elseif ($grade === 4) {
    echo "Хорошо";
} elseif ($grade === 3) {
    echo "Удовлетворительно";
} elseif ($grade === 2) {
    echo "Неудовлетворительно";
} else {
    echo "Некорректная оценка";
}
```

Здесь `switch` тоже подходит.

---

# 30. Тот же пример через switch

```php
$grade = 5;

switch ($grade) {
    case 5:
        echo "Отлично";
        break;

    case 4:
        echo "Хорошо";
        break;

    case 3:
        echo "Удовлетворительно";
        break;

    case 2:
        echo "Неудовлетворительно";
        break;

    default:
        echo "Некорректная оценка";
}
```

Для фиксированных значений такой код выглядит достаточно понятно.

---

# 31. Важный момент: switch не заменяет все if

Не стоит думать:

> `switch` — это просто более короткий `if`.

Это не совсем так.

Например:

```php
if ($age >= 18 && $balance > 1000) {
    echo "Доступ";
}
```

Такое условие естественно записывать через `if`.

`switch` больше подходит для ситуации:

```text
если значение равно A
если значение равно B
если значение равно C
```

# 32. Современный PHP: match

В современных версиях PHP появился `match`.

Он похож на `switch`, но работает несколько иначе и часто позволяет написать более компактный и безопасный код.

Например:

```php
$day = 3;

$result = match ($day) {
    1 => "Понедельник",
    2 => "Вторник",
    3 => "Среда",
    4 => "Четверг",
    5 => "Пятница",
    default => "Неизвестный день"
};

echo $result;
```

Получим:

```text
Среда
```

---

# 33. Чем match отличается от switch?

Для первого знакомства достаточно запомнить несколько различий.

`switch`:

```php
switch ($day) {
    case 1:
        $result = "Понедельник";
        break;

    case 2:
        $result = "Вторник";
        break;
}
```

`match`:

```php
$result = match ($day) {
    1 => "Понедельник",
    2 => "Вторник",
    default => "Неизвестный день"
};
```

`match`:

- возвращает значение;
- использует строгое сравнение;
- не требует `break`;
- должен обработать совпадение или иметь `default`.

---

# 34. Типичная ошибка №1 — забыли `===`

Например:

```php
$age = "18";

if ($age == 18) {
    echo "Совершеннолетний";
}
```

Это сработает из-за приведения типов.

Но в большинстве случаев лучше:

```php
if ($age === 18) {
    echo "Совершеннолетний";
}
```

Однако здесь есть ещё одна проблема: данные от пользователя часто приходят строками.

Поэтому правильная обработка данных — отдельная тема.

---

# 35. Типичная ошибка №2 — неправильный порядок elseif

Плохо:

```php
if ($age >= 18) {
    echo "18+";
} elseif ($age >= 21) {
    echo "21+";
}
```

Для `$age = 25` будет выведено:

```text
18+
```

Потому что первое условие уже истинно.

Правильно:

```php
if ($age >= 21) {
    echo "21+";
} elseif ($age >= 18) {
    echo "18+";
}
```

---

# 36. Типичная ошибка №3 — забыли break

Например:

```php
switch ($role) {
    case "admin":
        echo "Администратор";

    case "user":
        echo "Пользователь";
}
```

Лучше явно завершать ветку:

```php
case "admin":
    echo "Администратор";
    break;
```

---

# 37. Типичная ошибка №4 — слишком много вложенности

Например:

```php
if ($user) {
    if ($user["active"]) {
        if ($user["age"] >= 18) {
            if ($user["hasAccess"]) {
                echo "Доступ";
            }
        }
    }
}
```

Такой код быстро становится трудно читать.

Иногда можно написать:

```php
if (
    $user
    && $user["active"]
    && $user["age"] >= 18
    && $user["hasAccess"]
) {
    echo "Доступ";
}
```

На практике структура условий должна оставаться понятной человеку.

# 38. Реальный пример: авторизация

Представим:

```php
$login = "admin";
$password = "12345";
```

Проверяем:

```php
if ($login === "admin" && $password === "12345") {
    echo "Добро пожаловать!";
} else {
    echo "Неверный логин или пароль";
}
```

Логика:

```text
       Логин правильный?
              │
             да
              ↓
      Пароль правильный?
              │
             да
              ↓
      Добро пожаловать
```

Это уже пример реальной бизнес-логики.

# 39. Реальный пример: скидка

Допустим:

```php
$sum = 7500;
```

Наша система должна определить скидку:

```text
от 10000 → 20%
от 5000  → 10%
меньше   → 0%
```

Можно написать:

```php
if ($sum >= 10000) {
    $discount = 20;
} elseif ($sum >= 5000) {
    $discount = 10;
} else {
    $discount = 0;
}
```

Здесь хорошо видно, почему порядок условий важен.

Сначала проверяется максимальная граница.

# 40. Практический пример: система оценок

```php
$grade = 4;

if ($grade === 5) {
    echo "Отлично";
} elseif ($grade === 4) {
    echo "Хорошо";
} elseif ($grade === 3) {
    echo "Удовлетворительно";
} elseif ($grade === 2) {
    echo "Неудовлетворительно";
} else {
    echo "Некорректная оценка";
}
```

Здесь программа принимает решение на основании значения переменной.

# 41. Общая схема условных конструкций

Можно дать студентам такую схему:

```text
                    Условие
                       │
              ┌────────┴────────┐
             true             false
              │                  │
              ▼                  ▼
          if-блок           elseif / else
```

А `switch`:

```text
                 Значение
                     │
       ┌─────────────┼─────────────┐
       ▼             ▼             ▼
     case 1        case 2        case 3
       │             │             │
       ▼             ▼             ▼
    действие      действие      действие
       │             │             │
      break         break         break

                     │
                     ▼
                  default
```

# 42. Главное различие конструкций

| Конструкция | Когда использовать                                           |
| ----------- | ------------------------------------------------------------ |
| `if`        | одно условие                                                 |
| `if + else` | два варианта                                                 |
| `elseif`    | несколько разных условий                                     |
| `switch`    | много конкретных значений                                    |
| `case`      | один вариант внутри `switch`                                 |
| `default`   | ни один `case` не подошёл                                    |
| `match`     | современная альтернатива `switch` для сопоставления значений |
