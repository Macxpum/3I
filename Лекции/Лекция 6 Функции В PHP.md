
# 1. Что такое функция?

**Функция — это отдельный блок кода, который выполняет определённую задачу.**

Например:

```php
function sayHello() {
    echo "Привет!";
}
```

Мы создали функцию `sayHello`.

Но пока она **не выполняется**.

Чтобы запустить функцию, её необходимо вызвать:

```php
sayHello();
```

Результат:

```text
Привет!
```

---

# 2. Зачем нужны функции?

Представим, что нам нужно 10 раз вывести:

```text
Добро пожаловать на сайт!
```

Без функции:

```php
echo "Добро пожаловать на сайт!";
echo "Добро пожаловать на сайт!";
echo "Добро пожаловать на сайт!";
echo "Добро пожаловать на сайт!";
```

С функцией:

```php
function welcome() {
    echo "Добро пожаловать на сайт!";
}

welcome();
welcome();
welcome();
welcome();
```

Мы описали действие **один раз**, а использовать его можем сколько угодно раз.

---

# 3. Создание функции

Общий синтаксис:

```php
function имяФункции() {
    // код функции
}
```

Например:

```php
function sayHello() {
    echo "Привет!";
}
```

Здесь:

```text
function
```

говорит PHP, что мы создаём функцию.

```text
sayHello
```

— название функции.

```text
()
```

— место для параметров.

```text
{}
```

— тело функции, то есть код, который будет выполняться.

---

# 4. Вызов функции

После создания функции её можно вызвать:

```php
sayHello();
```

Полный пример:

```php
function sayHello() {
    echo "Привет!";
}

sayHello();
```

Результат:

```text
Привет!
```

Функцию можно вызвать несколько раз:

```php
function sayHello() {
    echo "Привет!<br>";
}

sayHello();
sayHello();
sayHello();
```

Результат:

```text
Привет!
Привет!
Привет!
```

---

# 5. Названия функций

Название функции должно отражать то, что она делает.

Например:

```php
function showMenu() {
    // ...
}
```

```php
function calculateSum() {
    // ...
}
```

```php
function checkAge() {
    // ...
}
```

```php
function printUser() {
    // ...
}
```

Лучше избегать названий вроде:

```php
function test() {
    // ...
}
```

если функция на самом деле выполняет какую-то конкретную задачу.

Название должно помогать понять код.

# 6. Функция с параметром

До этого функция всегда выполняла одну и ту же операцию.

Но что делать, если мы хотим передать функции какие-то данные?

Например:

```text
Привет, Иван!
Привет, Анна!
Привет, Пётр!
```

Создадим функцию:

```php
function sayHello($name) {
    echo "Привет, " . $name . "!";
}
```

Теперь при вызове передаём имя:

```php
sayHello("Иван");
```

Получим:

```text
Привет, Иван!
```

Можно вызвать ещё:

```php
sayHello("Анна");
sayHello("Пётр");
```

Получим:

```text
Привет, Анна!
Привет, Пётр!
```

---

# 7. Что такое параметр и аргумент?

Это важное различие.

В объявлении функции:

```php
function sayHello($name) {
    echo "Привет, " . $name;
}
```

`$name` — это **параметр**.

При вызове:

```php
sayHello("Иван");
```

`"Иван"` — это **аргумент**.

Можно запомнить так:

> **Параметр — переменная, которую функция ожидает получить.**
> **Аргумент — конкретное значение, которое мы передаём при вызове.**

---

# 8. Несколько параметров

Функция может принимать несколько параметров.

Например, функция сложения:

```php
function sum($a, $b) {
    echo $a + $b;
}
```

Вызов:

```php
sum(10, 20);
```

Результат:

```text
30
```

Можно передавать другие значения:

```php
sum(5, 7);
sum(100, 200);
```

---

# 9. Порядок параметров имеет значение

Посмотрим:

```php
function showUser($name, $age) {
    echo $name . " — " . $age . " лет";
}
```

Вызываем:

```php
showUser("Иван", 20);
```

Получаем:

```text
Иван — 20 лет
```

Если поменять значения местами:

```php
showUser(20, "Иван");
```

получится некорректный результат.

Поэтому необходимо передавать аргументы в правильном порядке.

---

# 10. Значение параметра по умолчанию

Иногда мы хотим, чтобы параметр имел значение, если его не передали.

Например:

```php
function sayHello($name = "Гость") {
    echo "Привет, " . $name;
}
```

Теперь можно вызвать:

```php
sayHello("Иван");
```

Получим:

```text
Привет, Иван
```

А можно не передавать имя:

```php
sayHello();
```

Получим:

```text
Привет, Гость
```

То есть:

```php
$name = "Гость"
```

— значение параметра по умолчанию.

---

# 11. Что не так с `echo` внутри функции?

Рассмотрим:

```php
function sum($a, $b) {
    echo $a + $b;
}
```

Функция выводит результат на экран.

Например:

```php
sum(10, 20);
```

Результат:

```text
30
```

Но иногда нам необходимо **не вывести результат**, а получить его и использовать дальше.

Например:

```php
$result = sum(10, 20);
```

Мы хотим, чтобы `$result` содержал `30`.

Для этого используется `return`.

---

# 12. `return`

`return` позволяет функции **вернуть результат своей работы**.

Например:

```php
function sum($a, $b) {
    return $a + $b;
}
```

Теперь:

```php
$result = sum(10, 20);

echo $result;
```

Получим:

```text
30
```

Главное отличие:

### `echo`

Выводит информацию:

```php
echo $a + $b;
```

### `return`

Возвращает результат:

```php
return $a + $b;
```

---

# 13. `echo` и `return` — разница

Рассмотрим два варианта.

### Вариант 1

```php
function sum($a, $b) {
    echo $a + $b;
}

sum(10, 20);
```

Функция сама выводит:

```text
30
```

Но мы не можем нормально использовать этот результат дальше как значение.

---

### Вариант 2

```php
function sum($a, $b) {
    return $a + $b;
}

$result = sum(10, 20);

echo $result;
```

Теперь результат можно сохранить:

```php
$result
```

И использовать дальше:

```php
$result = sum(10, 20);

if ($result > 20) {
    echo "Результат больше 20";
}
```

Именно поэтому `return` особенно важен.

---

# 14. `return` завершает выполнение функции

Посмотрим:

```php
function test() {

    echo "Начало";

    return;

    echo "Конец";
}
```

Вызов:

```php
test();
```

Получим:

```text
Начало
```

`"Конец"` не выводится.

После выполнения `return` функция прекращает работу.

# 15. Функция может возвращать разные типы данных

Функция может вернуть число:

```php
function getAge() {
    return 20;
}
```

Строку:

```php
function getName() {
    return "Иван";
}
```

Логическое значение:

```php
function isAdult() {
    return true;
}
```

И даже массив — с ним подробнее мы будем работать после изучения массивов.

# 16. Функции и условия

Функция может содержать `if`.

Например:

```php
function checkAge($age) {

    if ($age >= 18) {
        return "Совершеннолетний";
    } else {
        return "Несовершеннолетний";
    }

}
```

Теперь:

```php
echo checkAge(20);
```

Получим:

```text
Совершеннолетний
```

А:

```php
echo checkAge(15);
```

получим:

```text
Несовершеннолетний
```

Здесь мы уже объединяем две темы:

```text
Функции
   ↓
if / else
```

---

# 17. Функции и операторы

Например, функция проверки числа:

```php
function isEven($number) {

    if ($number % 2 === 0) {
        return true;
    }

    return false;
}
```

Теперь:

```php
if (isEven(10)) {
    echo "Число чётное";
}
```

Результат:

```text
Число чётное
```

Почему это работает?

Функция:

```php
isEven(10)
```

возвращает:

```text
true
```

И `if` получает это значение.

---

# 18. Функции и циклы

Функция может использоваться внутри цикла.

Например:

```php
function square($number) {
    return $number * $number;
}
```

Теперь:

```php
for ($i = 1; $i <= 5; $i++) {
    echo square($i) . "<br>";
}
```

Результат:

```text
1
4
9
16
25
```

Получается:

```text
цикл
  ↓
функция
  ↓
результат
```

---

# 19. Функция может вызывать другую функцию

Например:

```php
function sum($a, $b) {
    return $a + $b;
}

function doubleSum($a, $b) {
    return sum($a, $b) * 2;
}
```

Теперь:

```php
echo doubleSum(10, 20);
```

Сначала:

```text
10 + 20 = 30
```

Затем:

```text
30 × 2 = 60
```

Результат:

```text
60
```

Это позволяет разбивать сложную задачу на несколько небольших функций.

# 20. Область видимости переменных

Очень важное понятие.

Рассмотрим:

```php
function test() {
    $name = "Иван";

    echo $name;
}

test();
```

Внутри функции переменная `$name` существует.

Но если написать:

```php
function test() {
    $name = "Иван";
}

test();

echo $name;
```

переменная `$name` не будет доступна за пределами функции.

Почему?

Потому что переменная была создана **внутри функции**.

---

# 21. Локальные переменные

Переменные, созданные внутри функции, называются **локальными**.

Например:

```php
function calculate() {

    $a = 10;
    $b = 20;

    return $a + $b;
}
```

Переменные:

```text
$a
$b
```

существуют внутри этой функции.

Снаружи мы не можем обратиться к ним напрямую.

---

# 22. Переменные вне функции

Например:

```php
$name = "Иван";

function sayHello() {
    echo $name;
}
```

На первый взгляд кажется, что функция должна вывести:

```text
Иван
```

Но это не так.

Переменная `$name` находится за пределами функции.

Вместо того чтобы пытаться напрямую обращаться к внешним переменным, лучше передавать данные через параметры:

```php
$name = "Иван";

function sayHello($name) {
    echo $name;
}

sayHello($name);
```

Это более понятный и безопасный подход.

# 23. Встроенные функции PHP

До этого мы создавали собственные функции.

Но PHP уже содержит огромное количество готовых функций.

Например:

```php
strlen()
```

узнаёт длину строки:

```php
$text = "Привет";

echo strlen($text);
```

Результат:

```text
6
```

# 24. `strtoupper()`

Переводит строку в верхний регистр:

```php
$text = "hello";

echo strtoupper($text);
```

Результат:

```text
HELLO
```

---

# 25. `strtolower()`

Переводит строку в нижний регистр:

```php
$text = "HELLO";

echo strtolower($text);
```

Результат:

```text
hello
```

---

# 26. `trim()`

Удаляет лишние пробелы в начале и конце строки:

```php
$text = "   Иван   ";

$text = trim($text);

echo $text;
```

Получим:

```text
Иван
```

# 27. Функции — это способ разбить программу

Представим программу регистрации пользователя.

Если написать всё в одном месте:

```text
получить имя
проверить имя
получить возраст
проверить возраст
проверить пароль
создать пользователя
вывести результат
```

код быстро станет большим.

Можно разделить его:

```php
validateName()
validateAge()
validatePassword()
createUser()
showMessage()
```

Каждая функция отвечает за свою задачу.

Получается:

```text
Главная программа
       │
       ├── проверка имени
       │
       ├── проверка возраста
       │
       ├── проверка пароля
       │
       └── создание пользователя
```

Это один из основных принципов хорошего программирования:

> **Одна функция — одна понятная задача.**

# 28. Большой пример

Рассмотрим небольшую программу:

```php
function calculateDiscount($price, $discount) {
    return $price - ($price * $discount / 100);
}

function checkPrice($price) {

    if ($price <= 0) {
        return false;
    }

    return true;
}

$price = 5000;
$discount = 10;

if (checkPrice($price)) {

    $result = calculateDiscount($price, $discount);

    echo "Цена со скидкой: " . $result;
}
```

Здесь уже используются:

* переменные;
* функции;
* параметры;
* `return`;
* `if`;
* арифметические операторы.

Именно так постепенно строится реальный PHP-код.
