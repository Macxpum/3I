
## 1. Что мы уже умеем

В прошлой лекции мы научились получать данные из формы:

```
$name = $_POST["name"] ?? "";
```

Например, пользователь ввёл:

```
Иван
```

Мы можем получить это значение и обработать его.

Но возникает вопрос:

**А как сохранить имя пользователя, чтобы оно осталось и после перехода на другую страницу?**

Обычная переменная для этого не подходит:

```
$name = "Иван";
```

После завершения запроса эта переменная больше не хранится.

Для сохранения данных между запросами используются:

- **cookies**;
    
- **сессии**.
    

---

# 2. Что такое cookie

**Cookie** — это небольшая информация, которую сайт сохраняет в браузере пользователя.

Например, можно сохранить:

- имя;
    
- выбранный язык;
    
- настройки сайта;
    
- тему оформления.
    

В PHP для создания cookie используется:

```
setcookie();
```

Например:

```
setcookie("name", "Иван");
```

Здесь:

```
name
```

— имя cookie,

а:

```
Иван
```

— её значение.

---

# 3. Как получить cookie

Cookie можно получить через специальный массив:

```
$_COOKIE
```

Например:

```
echo $_COOKIE["name"];
```

Если cookie содержит:

```
name = Иван
```

то на экране будет:

```
Иван
```

Можно представить это так:

```
$_COOKIE
    ↓
"name" → "Иван"
```

То есть `$_COOKIE` работает как обычный ассоциативный массив.

---

# 4. Если cookie ещё нет

Не всегда cookie существует.

Поэтому лучше использовать уже знакомый нам оператор `??`:

```
$name = $_COOKIE["name"] ?? "";
```

Это означает:

> Если cookie `name` существует — взять её значение. Если нет — использовать пустую строку.

Например:

```
$name = $_COOKIE["name"] ?? "Гость";

echo "Привет, " . $name;
```

Если cookie есть:

```
Привет, Иван
```

Если её нет:

```
Привет, Гость
```

---

# 5. Срок действия cookie

При создании cookie можно указать, сколько она будет храниться.

Например:

```
setcookie("name", "Иван", time() + 3600);
```

`3600` секунд — это примерно один час.

Поэтому:

```
time() + 3600
```

означает:

> хранить cookie ещё один час.

Например, можно сохранить выбранную тему на один день:

```
setcookie("theme", "dark", time() + 86400);
```

---

# 6. Как удалить cookie

Чтобы удалить cookie, можно установить для неё время в прошлом:

```
setcookie("name", "", time() - 3600);
```

После этого браузер удалит cookie.

---

# 7. Что такое сессия

Теперь самое важное.

**Сессия** позволяет сохранять данные пользователя между разными запросами и страницами сайта.

Например:

```
login.php
    ↓
profile.php
    ↓
cart.php
```

Мы хотим, чтобы PHP понимал, что все эти страницы открывает один и тот же пользователь.

Для этого используется:

```
$_SESSION
```

---

# 8. Запуск сессии

Перед работой с сессией нужно написать:

```
session_start();
```

Обычно это делается в самом начале PHP-кода:

```
<?php

session_start();
```

После этого мы можем использовать:

```
$_SESSION
```

---

# 9. Сохранение данных в сессии

Работать с `$_SESSION` очень просто.

Например:

```
session_start();

$_SESSION["name"] = "Иван";
```

Мы сохранили имя пользователя в сессии.

Теперь на другой странице:

```
session_start();

echo $_SESSION["name"];
```

Получим:

```
Иван
```

То есть данные не исчезли после перехода на другую страницу.

---

# 10. Сессия — это тоже массив

Важно понять:

```
$_SESSION
```

— это специальный массив.

Например:

```
$_SESSION["name"] = "Иван";
$_SESSION["age"] = 20;
```

В нём теперь находятся:

```
name → Иван
age  → 20
```

Получить данные можно так:

```
echo $_SESSION["name"];
```

или:

```
echo $_SESSION["age"];
```

---

# 11. Проверка данных в сессии

Предположим, мы хотим узнать, вошёл ли пользователь.

Можно использовать знакомую нам функцию `isset()`:

```
session_start();

if (isset($_SESSION["name"])) {
    echo "Пользователь вошёл";
} else {
    echo "Пользователь не вошёл";
}
```

Если `name` есть в сессии — пользователь считается вошедшим.

---

# 12. Использование `??` вместе с сессией

Можно сделать ещё проще:

```
session_start();

$name = $_SESSION["name"] ?? "Гость";

echo "Привет, " . $name;
```

Если пользователь есть:

```
Привет, Иван
```

Если пользователя нет:

```
Привет, Гость
```

Мы уже знаем этот принцип по `$_GET` и `$_POST`.

---

# 13. Сохранение имени из формы в сессию

Теперь объединим новую тему с прошлой лекцией.

HTML:

```
<form method="POST">
    <input type="text" name="name">
    <button type="submit">Сохранить</button>
</form>
```

PHP:

```
session_start();

$name = trim($_POST["name"] ?? "");

if ($name !== "") {
    $_SESSION["name"] = $name;
}
```

Здесь происходит несколько действий:

1. получаем имя из `$_POST`;
    
2. убираем лишние пробелы через `trim()`;
    
3. проверяем, что имя не пустое;
    
4. сохраняем его в `$_SESSION`.
    

После этого на другой странице:

```
session_start();

$name = $_SESSION["name"] ?? "Гость";

echo "Привет, " . $name;
```

Получим:

```
Привет, Иван
```

---

# 14. Удаление данных из сессии

Если нужно удалить только одно значение:

```
unset($_SESSION["name"]);
```

Например:

```
session_start();

unset($_SESSION["name"]);
```

Теперь имени в сессии больше нет.

---

# 15. Завершение сессии

Чтобы завершить текущую сессию, используется:

```
session_destroy();
```

Например:

```
session_start();

session_destroy();
```

Это может использоваться при выходе пользователя из аккаунта.

---

# 16. Cookies и сессии: главное отличие

Самое важное — не запутаться.

|Cookies|Сессии|
|---|---|
|Хранят информацию в браузере|Хранят данные сессии на сервере|
|`$_COOKIE`|`$_SESSION`|
|`setcookie()`|`session_start()`|
|Подходят для небольших настроек|Удобны для состояния пользователя|

Например:

**Cookie:**

```
setcookie("theme", "dark");
```

Можно использовать для запоминания темы сайта.

**Сессия:**

```
$_SESSION["name"] = "Иван";
```

Можно использовать, чтобы сайт помнил текущего пользователя.

# 17. Простой пример с авторизацией

Сделаем упрощённую систему входа.

Пользователь вводит имя:

```
<form method="POST">
    <input type="text" name="name">
    <button type="submit">Войти</button>
</form>
```

PHP:

```
session_start();

$name = trim($_POST["name"] ?? "");

if ($name !== "") {
    $_SESSION["name"] = $name;
}
```

На странице профиля:

```
session_start();

if (isset($_SESSION["name"])) {
    echo "Добро пожаловать, " . $_SESSION["name"];
} else {
    echo "Сначала войдите";
}
```

Если имя сохранено:

```
Добро пожаловать, Иван
```

Если нет:

```
Сначала войдите
```

Это уже похоже на настоящую авторизацию, хотя пока мы не проверяем пароль.

---

# 18. Выход пользователя

Добавим кнопку:

```
<form method="POST">
    <button type="submit" name="logout">Выйти</button>
</form>
```

PHP:

```
session_start();

if (isset($_POST["logout"])) {
    session_destroy();
}
```

При нажатии на кнопку сессия завершается.
