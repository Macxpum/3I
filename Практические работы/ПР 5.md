# Задание 12. Итоговая задача — интернет-магазин

**Время: 15 минут**

Это основное задание занятия.

Дан массив товаров:

```php
$products = [
    [
        "name" => "Ноутбук",
        "price" => 70000,
        "quantity" => 2
    ],
    [
        "name" => "Мышь",
        "price" => 1500,
        "quantity" => 3
    ],
    [
        "name" => "Клавиатура",
        "price" => 3000,
        "quantity" => 1
    ],
    [
        "name" => "Монитор",
        "price" => 25000,
        "quantity" => 2
    ]
];
```

Необходимо создать программу, которая:

### 1. Выводит список товаров

Например:

```text
Ноутбук — 70000 руб. — 2 шт.
Мышь — 1500 руб. — 3 шт.
...
```

### 2. Считает стоимость каждого товара

Формула:

```text
цена × количество
```

Например:

```text
70000 × 2 = 140000
```

### 3. Считает общую стоимость заказа

То есть складывает стоимость всех товаров.

### 4. Определяет скидку

Используйте `if / elseif / else`:

```text
если сумма >= 150000 → скидка 15%

если сумма >= 100000 → скидка 10%

если сумма >= 50000 → скидка 5%

иначе → скидки нет
```

### 5. Выводит итог

Например:

```text
Стоимость товаров: 179500 руб.
Скидка: 15%
Размер скидки: 26925 руб.
Итого к оплате: 152575 руб.
```
