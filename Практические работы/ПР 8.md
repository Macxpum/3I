# Практическая работа

## Задание 1. Cookie

Создайте cookie:

```
name = Иван
```

Затем выведите её значение на экран.

Если cookie ещё нет, выведите:

```
Имя не сохранено
```

---

## Задание 2. Cookie с настройкой

Создайте cookie:

```
theme = dark
```

Срок действия — один день.

Выведите:

```
Текущая тема: dark
```

---

## Задание 3. Простая сессия

Создайте страницу, которая сохраняет:

```
$_SESSION["name"] = "Иван";
```

Создайте вторую страницу и выведите сохранённое имя.

---

## Задание 4. Счётчик

Создайте счётчик посещений страницы.

При первом посещении:

```
Посещений: 1
```

При обновлении:

```
Посещений: 2
```

Используйте:

- `session_start()`;
    
- `$_SESSION`;
    
- `isset()`;
    
- `if / else`;
    
- `++`.
    

---

## Задание 5. Форма + сессия

Создайте форму:

```
<form method="POST">
    <input type="text" name="name">
    <button type="submit">Сохранить</button>
</form>
```

После отправки:

1. получите имя через `$_POST`;
    
2. примените `trim()`;
    
3. проверьте, что имя не пустое;
    
4. сохраните имя в `$_SESSION`.
    

На странице должно появиться:

```
Привет, Иван!
```

---

## Задание 6. Профиль

Создайте две страницы:

```
index.php
profile.php
```

На `index.php` пользователь вводит имя.

Имя сохраняется в сессии.

На `profile.php`:

если имя есть:

```
Добро пожаловать, Иван!
```

если имени нет:

```
Сначала войдите
```

---

## Задание 7. Выход

Добавьте кнопку:

```
Выйти
```

При нажатии завершайте сессию с помощью:

```
session_destroy();
```

После выхода пользователь должен увидеть:

```
Сначала войдите
```
