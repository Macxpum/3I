### Задание 5. `==` против `===`

**До запуска программы** определить результат:

```php
var_dump(5 == "5");
var_dump(5 === "5");

var_dump(true == 1);
var_dump(true === 1);
```

После этого запустить и объяснить каждый результат.

### Задание 6. Доступ к системе

Даны:

```php
$age = 20;
$isBlocked = false;
```

Создать выражение, которое будет `true`, если:

- пользователю 18 или больше;
- пользователь не заблокирован.

Ожидаемое выражение:

```php
$canAccess = $age >= 18 && $isBlocked === false;
```

Есть интернет-магазин:

```php
$price = 2500;
$quantity = 3;
$discount = 10;
```

Необходимо:

1. Рассчитать стоимость товаров.
2. Рассчитать размер скидки.
3. Рассчитать итоговую стоимость.
4. Проверить, превышает ли итоговая стоимость 5000 рублей.
5. Сохранить результат проверки в переменную `$isExpensive`.
