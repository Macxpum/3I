## Задание 8

Дан массив товаров:

```php
$products = [
    ["name" => "Ноутбук", "price" => 70000],
    ["name" => "Мышь", "price" => 1500],
    ["name" => "Клавиатура", "price" => 3000],
    ["name" => "Монитор", "price" => 25000]
];
```

Необходимо:

1. Вывести все товары.
2. Вывести только товары дороже 5000 рублей.
3. Посчитать количество товаров.
4. Посчитать общую стоимость всех товаров.

Для последнего пункта можно использовать:

```php
$total = 0;

foreach ($products as $product) {
    $total += $product["price"];
}

echo $total;
```
