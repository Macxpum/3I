
**Время выполнения:** 3 часа.

### Цель работы

Создать небольшой сайт, на котором пользователь может зарегистрироваться, войти в аккаунт и посмотреть свою анкету.

В работе необходимо использовать:

- HTML и CSS для создания страниц и форм;
    
- PHP для обработки данных;
    
- `$_POST` для получения данных из форм;
    
- cookies для учебного хранения зарегистрированных данных;
    
- `$_SESSION` для хранения состояния авторизации;
    
- условия и проверки для обработки пользовательского ввода.
    

## 1. Что нужно создать

Создайте проект из трёх страниц:

```
project/
├── register.php
├── login.php
├── profile.php
└── style.css
```

- `register.php` — регистрация пользователя.
    
- `login.php` — авторизация пользователя.
    
- `profile.php` — личный кабинет.
    
- `style.css` — оформление всех страниц.
    

Все страницы должны иметь единый стиль: одинаковые цвета, шрифты, поля ввода и кнопки.

## 2. Страница регистрации — `register.php`

Создайте форму, в которой пользователь сможет зарегистрироваться и заполнить анкету о себе.

### Поля формы

**Данные для входа:**

- Логин.
    
- Пароль.
    

**Личная информация:**

- Имя.
    
- Возраст.
    
- Пол.
    
- Предпочтения в еде.
    
- Предпочитаемый стиль одежды.
    
- Любимое музыкальное направление.
    
- Хобби или увлечения.
    

Для выбора пола, предпочтений в еде и стиля одежды используйте выпадающие списки `<select>`. Для остальных полей подойдут текстовые поля и числовое поле для возраста.

Внизу формы должна быть кнопка «Зарегистрироваться» и ссылка на страницу авторизации.

### Обработка регистрации

После отправки формы необходимо:

1. Получить значения полей через `$_POST`.
    
2. Убрать лишние пробелы в начале и конце введённых строк с помощью `trim()`.
    
3. Проверить, что обязательные поля заполнены.
    
4. Проверить, что возраст является числом и находится в разумных пределах.
    
5. Сохранить введённые данные в cookies с помощью `setcookie()`.
    
6. Установить срок хранения cookies, например, 7 дней.
    
7. Показать сообщение об успешной регистрации и ссылку на страницу входа.
    

Для хранения используйте отдельные cookies с понятными именами, например:

```
user_login
user_password
user_name
user_age
user_gender
user_food
user_clothing
user_music
user_hobby
```

Все эти значения PHP сможет получить через массив `$_COOKIE`.

**Важно:** `setcookie()` нужно вызывать до вывода HTML. Кроме того, новые значения cookies становятся доступны через `$_COOKIE` при следующем запросе браузера, а не сразу в том же запросе.

## 3. Страница авторизации — `login.php`

Создайте форму входа с двумя полями:

- Логин.
    
- Пароль.
    

Добавьте кнопку «Войти» и ссылку на регистрацию.

### Обработка авторизации

После отправки формы необходимо:

1. Получить логин и пароль через `$_POST`.
    
2. Получить сохранённые данные из `$_COOKIE`.
    
3. Сравнить введённый логин с сохранённым логином.
    
4. Сравнить введённый пароль с сохранённым паролем.
    
5. Если оба значения совпадают — создать сессию авторизованного пользователя.
    
6. Если данные не совпадают — показать сообщение об ошибке.
    

Для сессии используйте:

```
session_start();
```

При успешном входе сохраните в `$_SESSION` признак авторизации и логин пользователя. Например, можно использовать ключи `authorized` и `login`.

После успешной авторизации покажите ссылку «Перейти в личный кабинет».

Если пользователь ввёл неверные данные, он должен увидеть сообщение:

**«Неверный логин или пароль».**

## 4. Страница личного кабинета — `profile.php`

Эта страница должна показывать анкету пользователя.

### Проверка авторизации

Перед выводом личного кабинета необходимо:

1. Запустить сессию.
    
2. Проверить, что пользователь авторизован.
    
3. Если авторизации нет, не показывать личные данные и предложить перейти на страницу входа.
    

### Отображение анкеты

Если пользователь вошёл, выведите его данные в аккуратном виде:

- Имя.
    
- Возраст.
    
- Пол.
    
- Предпочтения в еде.
    
- Стиль одежды.
    
- Любимая музыка.
    
- Хобби.
    

Получайте информацию из cookies, а не из значений, введённых непосредственно в форму авторизации.

Например, личный кабинет может выглядеть так:

**Моя анкета**

Имя: Иван

Возраст: 20 лет

Пол: Мужской

Предпочтения в еде: Вегетарианское питание

Стиль одежды: Повседневный

Любимая музыка: Рок

Хобби: Фотография

Это пример заполненной анкеты, а не данные, которые нужно прописывать вручную.

### Кнопка выхода

Добавьте кнопку «Выйти».

При её нажатии необходимо завершить сессию пользователя с помощью `session_destroy()` и вернуть страницу в состояние, при котором личный кабинет недоступен без повторной авторизации.

Cookies при выходе удалять не нужно: пользователь должен иметь возможность снова войти с теми же данными.

## 5. Требования к оформлению

Оформите сайт как единый небольшой проект.

Обязательные требования:

- У каждой страницы есть заголовок.
    
- У каждого поля формы есть подпись.
    
- Кнопки и ссылки хорошо различимы.
    
- Поля и кнопки имеют одинаковое оформление на всех страницах.
    
- Страницы аккуратно выровнены и не занимают всю ширину экрана.
    
- Сообщения об ошибках и успешных действиях видны пользователю.
    
- Данные анкеты выводятся в удобном для чтения виде.
    

Для оформления используйте отдельный файл `style.css`.

## 6. Проверка работы

Перед завершением проекта проверьте следующие сценарии:

- Можно зарегистрировать пользователя и сохранить его данные.
    
- После регистрации можно перейти на страницу входа.
    
- При правильном логине и пароле создаётся сессия.
    
- При неправильных данных появляется сообщение об ошибке.
    
- Авторизованный пользователь видит свою анкету.
    
- Неавторизованный пользователь не может просматривать личный кабинет.
    
- После выхода доступ к личному кабинету закрывается.
    
- После выхода можно войти снова с теми же данными.
    
- Пустые обязательные поля и некорректный возраст обрабатываются корректно.
    

## 7. Дополнительные задания

Если основные требования выполнены раньше, добавьте одну или несколько функций:

1. **Редактирование анкеты.** Добавьте форму, позволяющую изменить предпочтения пользователя и сохранить новые значения в cookies.
    
2. **Проверка логина.** Если логин уже сохранён, покажите сообщение, что пользователь с такими данными уже зарегистрирован.
    
3. **Более удобная анкета.** Оформите личный кабинет отдельными блоками: «Личные данные», «Еда», «Стиль и увлечения».
    
4. **Подтверждение выхода.** Перед завершением сессии попросите пользователя подтвердить действие.
    

## Важное примечание

В этой работе cookies используются как **временная учебная замена базе данных**. Это позволяет потренироваться с хранением и получением данных, не изучая пока SQL.

Однако такой способ не подходит для настоящей регистрации: cookies хранятся на стороне браузера, могут быть изменены пользователем, а пароль в них хранить небезопасно. В реальном проекте данные пользователей сохраняют на сервере, обычно в базе данных, а пароли хранят в виде безопасных хешей.

В рамках этой учебной работы сохранение пароля в cookie допускается только как демонстрационная схема на локальном учебном проекте.
