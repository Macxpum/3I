## Задание 6. Стоимость досавки

Создать программу определения стоимости доставки.

Есть:

```php
$orderSum = 3500;
```

Правила:

```text
если сумма >= 5000 → доставка бесплатная

если сумма >= 2000 → доставка 300 рублей

если сумма < 2000 → доставка 500 рублей
```

Программа должна вывести:

```text
Стоимость заказа: 3500
Стоимость доставки: 300
Итого: 3800
```

Здесь студент должен самостоятельно:

1. создать условие;
2. определить размер доставки;
3. рассчитать итог;
4. вывести результат.

## Задание 7. Доступ

Есть:

```php
$login = "admin";
$password = "12345";
$isBlocked = false;
```

Правила:

- если пользователь заблокирован — вывести `Пользователь заблокирован`;
- если логин и пароль неправильные — вывести `Неверные данные`;
- если всё правильно — вывести `Добро пожаловать`.

Здесь важно правильно расставить приоритет условий:

```php
if ($isBlocked === true) {
    ...
} elseif (...) {
    ...
} else {
    ...
}
```
