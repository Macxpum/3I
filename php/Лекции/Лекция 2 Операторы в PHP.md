# 2. Что такое оператор?

**Оператор — это специальный символ или конструкция, которая сообщает PHP, какое действие необходимо выполнить.**

Например:

```php
$result = 10 + 5;
```

Здесь:

```text
10 + 5
│  │  │
│  │  └── операнд
│  └───── оператор
└──────── операнд
```

**Операнды** — это значения, над которыми выполняется операция.

Например:

```php
$a + $b
```

- `$a` — операнд;
- `$b` — операнд;
- `+` — оператор.

# 3. Арифметические операторы

Начнём с самых простых.

| Оператор | Назначение           | Пример   |
| -------- | -------------------- | -------- |
| `+`      | сложение             | `10 + 5` |
| `-`      | вычитание            | `10 - 5` |
| `*`      | умножение            | `10 * 5` |
| `/`      | деление              | `10 / 5` |
| `%`      | остаток от деления   | `10 % 3` |
| `**`     | возведение в степень | `2 ** 3` |

---

## Сложение

```php
$a = 10;
$b = 5;

$result = $a + $b;

echo $result;
```

Результат:

```text
15
```

---

## Вычитание

```php
$result = $a - $b;
```

Результат:

```text
5
```

---

## Умножение

```php
$result = $a * $b;
```

Результат:

```text
50
```

---

## Деление

```php
$result = $a / $b;
```

Результат:

```text
2
```

Важно помнить, что `/` — это именно **деление**, а не целочисленное деление.

Например:

```php
$result = 10 / 3;

var_dump($result);
```

Результат:

```text
float(3.3333333333333...)
```

# 4. Остаток от деления `%`

Очень важный оператор:

```php
%
```

Он возвращает **остаток от деления**.

Например:

```php
$result = 10 % 3;
```

Получаем:

```text
1
```

Потому что:

```text
10 / 3 = 3 целых + 1 остаток
```

Ещё примеры:

```php
10 % 2 → 0
10 % 3 → 1
10 % 4 → 2
15 % 5 → 0
17 % 5 → 2
```

## Где это используется?

Например, чтобы определить, является ли число чётным:

```php
$number = 10;

$number % 2
```

Если результат `0`, число чётное.

Позже это будет использоваться вместе с `if`:

```php
if ($number % 2 === 0) {
    echo "Чётное число";
}
```

# 5. Возведение в степень

Оператор:

```php
**
```

Например:

```php
$result = 2 ** 3;

echo $result;
```

Получим:

```text
8
```

Потому что:

```text
2 × 2 × 2 = 8
```

# 6. Оператор присваивания `=`

С ним мы уже встречались:

```php
$age = 20;
```

Очень важно помнить, что `=` означает **не «равно» в математическом смысле**.

Он означает:

> взять значение справа и записать его в переменную слева.

Например:

```php
$age = 20;
```

Можно прочитать:

> Переменной `$age` присвоить значение `20`.

---

# 7. Присваивание результата выражения

Справа может находиться целое выражение:

```php
$a = 10;
$b = 20;

$result = $a + $b;
```

Сначала PHP вычислит:

```text
10 + 20 = 30
```

и затем:

```text
$result = 30
```

---

# 8. Составные операторы присваивания

Предположим:

```php
$number = 10;
```

Нужно увеличить его на 5.

Можно написать:

```php
$number = $number + 5;
```

После выполнения:

```text
15
```

Но PHP позволяет записать короче:

```php
$number += 5;
```

Это эквивалентно:

```php
$number = $number + 5;
```

---

## Основные составные операторы

| Оператор | Пример     | Эквивалент     |
| -------- | ---------- | -------------- |
| `+=`     | `$a += 5`  | `$a = $a + 5`  |
| `-=`     | `$a -= 5`  | `$a = $a - 5`  |
| `*=`     | `$a *= 5`  | `$a = $a * 5`  |
| `/=`     | `$a /= 5`  | `$a = $a / 5`  |
| `%=`     | `$a %= 5`  | `$a = $a % 5`  |
| `**=`    | `$a **= 2` | `$a = $a ** 2` |


Теперь:

```text
1200
```

Такой пример уже ближе к реальной информационной системе.

# 10. Операторы сравнения

Теперь начинается действительно важная часть.

Операторы сравнения позволяют узнать, **как два значения соотносятся друг с другом**.

Результатом сравнения является:

```php
true
```

или:

```php
false
```

То есть `bool`.

---

## Основные операторы

| Оператор | Значение         |
| -------- | ---------------- |
| `==`     | равно            |
| `!=`     | не равно         |
| `===`    | идентично        |
| `!==`    | не идентично     |
| `>`      | больше           |
| `<`      | меньше           |
| `>=`     | больше или равно |
| `<=`     | меньше или равно |

---

# 11. Сравнение чисел

```php
$a = 10;
$b = 20;

var_dump($a > $b);
```

Результат:

```text
bool(false)
```

Потому что `10` не больше `20`.

А:

```php
var_dump($a < $b);
```

даст:

```text
bool(true)
```

---

# 12. Результат сравнения — `bool`

Это важная связь с предыдущей лекцией.

Например:

```php
$age = 20;

$result = $age >= 18;
```

Теперь:

```php
var_dump($result);
```

Получим:

```text
bool(true)
```

То есть оператор сравнения **создал логическое значение**.

```text
20 >= 18
   ↓
 true
```

Это станет основой следующей лекции про `if`.

---

# 13. `==` — нестрогое сравнение

Например:

```php
var_dump(10 == 10);
```

Получим:

```text
true
```

Но:

```php
var_dump(10 == "10");
```

тоже:

```text
true
```

Почему?

Потому что `==` сравнивает значения с возможным приведением типов.

```text
10       → int
"10"     → string

       ↓

значения считаются равными
```

---

# 14. `===` — строгое сравнение

Теперь:

```php
var_dump(10 === "10");
```

Результат:

```text
false
```

Потому что:

```text
10       → int
"10"     → string
```

Типы разные.

Для `===` должны совпадать **и значение, и тип**.

```php
10 === 10
```

→ `true`

```php
10 === "10"
```

→ `false`

```php
"hello" === "hello"
```

→ `true`

```php
true === 1
```

→ `false`

---

# 15. Почему лучше использовать `===`?

PHP умеет автоматически преобразовывать типы. Иногда это удобно, но иногда может приводить к неожиданным результатам.

Поэтому в большинстве ситуаций лучше писать:

```php
if ($age === 18)
```

а не:

```php
if ($age == 18)
```

Особенно это важно при работе:

- с пользовательским вводом;
- с данными из HTTP-запросов;
- с базами данных;
- с API.

**Практическое правило:**

> Если нет конкретной причины использовать `==`, обычно используем `===`.

---

# 16. Логические операторы

Теперь мы умеем сравнивать значения.

Но часто одного условия недостаточно.

Например:

> Пользователь совершеннолетний **и** имеет доступ.

Нам нужно объединить два условия.

Для этого существуют логические операторы.

| Оператор | Название |
| -------- | -------- |
| &&       | И        |
| \|\|     | ИЛИ      |
| !        | НЕ       |


---

# 17. `&&` — логическое И

```php
$age = 20;
$hasAccess = true;

$result = $age >= 18 && $hasAccess === true;
```

Чтобы результат был `true`, **оба условия должны быть истинными**.

```text
Условие 1    Условие 2    Результат

true         true         true
true         false        false
false        true         false
false        false        false
```

---

# 18. Пример

```php
$age = 20;
$isStudent = true;

$result = $age >= 18 && $isStudent === true;
```

Получаем:

```text
true
```

Потому что:

```text
20 >= 18       → true
$isStudent     → true

true && true   → true
```

---

# 19. `||` — логическое ИЛИ

Оператор:

```php
||
```

возвращает `true`, если **хотя бы одно условие истинно**.

```text
true  || true  → true
true  || false → true
false || true  → true
false || false → false
```

Например:

```php
$isAdmin = false;
$isTeacher = true;

$result = $isAdmin || $isTeacher;
```

Результат:

```text
true
```

Потому что пользователь является преподавателем.

---

# 20. `!` — логическое НЕ

Оператор `!` меняет значение на противоположное.

```php
$value = true;

var_dump(!$value);
```

Получим:

```text
bool(false)
```

И:

```php
$value = false;

var_dump(!$value);
```

Получим:

```text
bool(true)
```

Можно прочитать:

```text
!true  → false
!false → true
```

---

# 21. Комбинирование операторов

Можно создавать достаточно сложные выражения:

```php
$age = 20;
$isStudent = true;
$hasDebt = false;

$result = $age >= 18
       && $isStudent === true
       && $hasDebt === false;
```

Здесь одновременно проверяется:

1. возраст не меньше 18;
2. человек является студентом;
3. у него нет задолженности.

Это уже очень близко к реальной бизнес-логике информационных систем.

---

# 22. Инкремент `++`

Очень часто необходимо увеличить число на единицу.

Вместо:

```php
$count = $count + 1;
```

можно написать:

```php
$count++;
```

Например:

```php
$count = 0;

$count++;
$count++;
$count++;

echo $count;
```

Получим:

```text
3
```

---

# 23. Декремент `--`

Аналогично можно уменьшить значение на единицу:

```php
$count--;
```

Например:

```php
$count = 3;

$count--;

echo $count;
```

Получим:

```text
2
```

Эти операторы особенно часто будут встречаться при изучении циклов.

---

# 24. Префиксная и постфиксная формы

Существуют:

```php
++$a;
$a++;
```

и:

```php
--$a;
$a--;
```

Разница становится заметна, когда оператор используется **внутри выражения**.

Например:

```php
$a = 10;

$b = $a++;
```

После выполнения:

```text
$a = 11
$b = 10
```

Сначала значение `$a` использовалось, потом увеличилось.

А:

```php
$a = 10;

$b = ++$a;
```

даст:

```text
$a = 11
$b = 11
```

Сначала увеличили `$a`, затем получили его значение.

Для первого знакомства достаточно сформулировать:

> `a++` — сначала используем значение, потом увеличиваем.
> `++a` — сначала увеличиваем, потом используем.

# 25. Приоритет операторов

Что произойдёт здесь?

```php
$result = 10 + 5 * 2;
```

Не:

```text
30
```

а:

```text
20
```

Потому что сначала выполняется умножение:

```text
5 * 2 = 10

10 + 10 = 20
```

Как и в математике.

---

## Скобки

Если нужно изменить порядок:

```php
$result = (10 + 5) * 2;
```

Получим:

```text
30
```

Хорошая практика:

> Если выражение сложное и порядок вычислений может быть неочевиден — используйте скобки.

Например:

```php
$total = ($price * $quantity) + $delivery;
```

гораздо легче читать, чем пытаться держать приоритеты операторов в голове.

# 26. Тернарный оператор

Теперь небольшой, но полезный оператор:

```php
? :
```

Он позволяет компактно записать простое условие.

Например:

```php
$age = 20;

$status = $age >= 18 ? "Совершеннолетний" : "Несовершеннолетний";
```

Логика:

```text
        $age >= 18
             │
       ┌─────┴─────┐
      true        false
       │             │
       ▼             ▼
"Совершеннолетний" "Несовершеннолетний"
```

То есть:

```php
условие ? значение_если_true : значение_если_false
```

---

# 27. Когда использовать тернарный оператор?

Хорошо:

```php
$status = $age >= 18 ? "18+" : "до 18";
```

Плохо:

```php
$result = $a > 10
    ? ($b > 20 ? "..." : "...")
    : ($c > 30 ? "..." : "...");
```

Если условие становится слишком сложным, лучше использовать обычный `if`.

---

# 28. Оператор `??`

Это оператор **null coalescing** — оператор объединения с `null`.

Название пока можно не заставлять студентов запоминать.

Главная идея:

> Если первое значение существует и не является `null` — использовать его. Иначе использовать второе.

Например:

```php
$name = null;

$result = $name ?? "Гость";
```

Результат:

```text
Гость
```

Если:

```php
$name = "Иван";

$result = $name ?? "Гость";
```

получим:

```text
Иван
```

---

# 29. Практический пример с `??`

Это особенно полезно при работе с данными пользователя.

Например:

```php
$name = $_GET['name'] ?? "Гость";
```

Если параметр `name` передан:

```text
?name=Иван
```

получим:

```text
Иван
```

Если параметра нет:

```text
Гость
```

Здесь мы уже слегка заглядываем вперёд — к работе с HTTP и массивами.
