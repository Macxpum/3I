# 2. Что такое переменная?

Начнём с простого определения.

**Переменная — это именованное место для хранения некоторого значения, которое программа может использовать и изменять во время работы.**

Например:

```php
$name = "Иван";
$age = 20;
```

Здесь мы создали две переменные:

```text
$name → "Иван"
$age  → 20
```

Можно представить переменную как **подписанную коробку**.

```text
┌─────────────┐
│    name     │
│   "Иван"    │
└─────────────┘

┌─────────────┐
│     age     │
│     20      │
└─────────────┘
```

Имя переменной позволяет нам обратиться к сохранённому значению.

```php
echo $name;
```

Результат:

```text
Иван
```

---

# 3. Как создать переменную в PHP?

В PHP переменная обозначается символом `$`.

Общий вид:

```php
$имя = значение;
```

Например:

```php
$name = "Иван";
$age = 20;
$height = 1.82;
$isStudent = true;
```

Обратите внимание: **отдельно объявлять тип переменной не требуется.**

Например, нам не нужно писать:

```php
string $name;
int $age;
```

чтобы просто создать переменные.

Достаточно:

```php
$name = "Иван";
$age = 20;
```

---

# 4. Изменение значения переменной

Одно из главных свойств переменной — её значение можно изменить.

```php
$age = 20;

echo $age;

$age = 21;

echo $age;
```

В результате:

```text
20
21
```

После выполнения:

```php
$age = 21;
```

старое значение `20` больше не является текущим значением переменной `$age`.

Можно даже присвоить переменной значение другого типа:

```php
$value = 10;

$value = "Hello";

$value = true;
```

Это связано с одной из важных особенностей PHP — **динамической типизацией**.

---

# 5. Правила именования переменных

У переменных в PHP есть определённые правила.

Корректные примеры:

```php
$name
$age
$userName
$user_name
$student2
```

Имя переменной:

- начинается с `$`;
- после `$` должно начинаться с буквы или `_`;
- затем могут использоваться буквы, цифры и `_`;
- регистр имеет значение.

Например:

```php
$name
$Name
$NAME
```

Это **три разные переменные**.

```php
$name = "Иван";
$Name = "Пётр";

echo $name;
echo $Name;
```

Получим:

```text
Иван
Пётр
```

---

## Что нельзя?

Например:

```php
$2name
```

Так нельзя, потому что имя начинается с цифры.

Также нельзя использовать пробел:

```php
$user name
```

Вместо этого:

```php
$userName
```

или:

```php
$user_name
```

---

# 6. Как правильно называть переменные?

Технически PHP позволяет довольно многое, но в реальном программировании важно придерживаться соглашений.

Плохо:

```php
$a = "Иван";
$b = 20;
$c = true;
```

Мы не понимаем, что означает `$a`, `$b` и `$c`.

Лучше:

```php
$name = "Иван";
$age = 20;
$isStudent = true;
```

Ещё лучше — давать переменной имя, которое **описывает её содержимое**.

Например:

```php
$studentName
$studentAge
$courseName
$price
$quantity
```

---

# 7. Типы данных

Теперь переходим к главной части лекции.

Переменная содержит **значение**, а значение имеет **тип**.

Например:

```php
$name = "Иван";
```

`"Иван"` — это строка (`string`).

```php
$age = 20;
```

`20` — целое число (`int`).

```php
$price = 99.99;
```

`99.99` — число с плавающей точкой (`float`).

```php
$isAdmin = true;
```

`true` — логическое значение (`bool`).

---

# 8. Основные типы данных PHP

Для начала достаточно познакомиться с такими типами:

| Тип      | Название            | Пример        |
| -------- | ------------------- | ------------- |
| `int`    | целое число         | `42`          |
| `float`  | дробное число       | `3.14`        |
| `string` | строка              | `"Hello"`     |
| `bool`   | логическое значение | `true`        |
| `null`   | отсутствие значения | `null`        |
| `array`  | массив              | `[1, 2, 3]`   |
| `object` | объект              | объект класса |

---

# 9. Integer — целые числа

Тип `int` используется для целых чисел.

```php
$age = 20;
$count = 100;
$temperature = -10;
```

Значения:

```text
20
100
-10
```

не содержат дробной части.

Можно использовать арифметические операции:

```php
$a = 10;
$b = 5;

echo $a + $b;
echo $a - $b;
echo $a * $b;
echo $a / $b;
```

Обратите внимание: результат деления не обязательно будет `int`.

Например:

```php
$result = 10 / 3;
```

Получим:

```text
3.3333333333...
```

То есть результатом будет `float`.

---

# 10. Float — дробные числа

`float` используется для чисел с дробной частью:

```php
$price = 199.99;
$temperature = 36.6;
$pi = 3.14159;
```

Например:

```php
$width = 10.5;
$height = 20.2;

$area = $width * $height;

echo $area;
```

---

## Важный момент: деньги

Здесь можно сделать небольшое отступление.

Новичкам часто хочется написать:

```php
$price = 19.99;
```

и выполнять финансовые расчёты через `float`.

Но числа с плавающей точкой могут иметь особенности представления.

Например, компьютер не всегда может точно представить десятичную дробь в двоичной системе.

Поэтому в серьёзных финансовых системах деньги часто хранят:

```php
$price = 1999;
```

где `1999` означает **19,99** в минимальных денежных единицах.

Это хороший пример того, почему программисту недостаточно знать только синтаксис — нужно понимать, **как данные представлены внутри компьютера**.

---

# 11. String — строки

`string` используется для хранения текста.

```php
$name = "Иван";
$city = "Москва";
$message = "Hello, world!";
```

Строку можно заключить в одинарные:

```php
$name = 'Иван';
```

или двойные кавычки:

```php
$name = "Иван";
```

---

# 12. Одинарные и двойные кавычки

Здесь есть важное отличие.

Например:

```php
$name = "Иван";

echo "Привет, $name";
```

Получим:

```text
Привет, Иван
```

PHP подставил значение переменной в строку.

А:

```php
echo 'Привет, $name';
```

выведет:

```text
Привет, $name
```

То есть переменная внутри одинарных кавычек не интерполируется.

---

# 13. Объединение строк

Для объединения строк в PHP используется оператор `.`

```php
$name = "Иван";
$age = 20;

$message = "Имя: " . $name . ", возраст: " . $age;

echo $message;
```

Получим:

```text
Имя: Иван, возраст: 20
```

Можно написать проще:

```php
echo "Имя: $name, возраст: $age";
```

---

# 14. Boolean — логический тип

`bool` может иметь только два значения:

```php
true
false
```

То есть:

```text
истина
ложь
```

Например:

```php
$isStudent = true;
$isAdmin = false;
```

Очень часто `bool` используется для хранения состояния.

Например:

```php
$isAuthorized = true;
```

Можно прочитать это как:

> Пользователь авторизован — да.

Или:

```php
$isAuthorized = false;
```

> Пользователь авторизован — нет.

Позже именно `bool` будет активно использоваться в условиях:

```php
if ($isAuthorized) {
    echo "Добро пожаловать!";
}
```

---

# 15. Null

`null` означает, что переменная **не содержит значения**.

```php
$middleName = null;
```

Это не то же самое, что:

```php
$middleName = "";
```

Пустая строка — это всё ещё строка.

```php
""
```

А `null` означает:

> Значение отсутствует.

Например:

```php
$userPhoto = null;
```

Можно понимать это как:

> У пользователя пока нет фотографии.

---

# 16. Array — массив

Массив позволяет хранить **несколько значений в одной переменной**.

Например:

```php
$numbers = [10, 20, 30, 40];
```

Вместо:

```php
$number1 = 10;
$number2 = 20;
$number3 = 30;
$number4 = 40;
```

мы можем использовать один массив:

```php
$numbers = [10, 20, 30, 40];
```

Обратиться к элементу можно по индексу:

```php
echo $numbers[0];
```

Результат:

```text
10
```

```php
echo $numbers[2];
```

Результат:

```text
30
```

И здесь возникает важное понятие:

> **Индексация массива начинается с нуля.**

То есть:

```text
Индекс:    0    1    2    3
           ↓    ↓    ↓    ↓
Значение: 10   20   30   40
```

---

# 17. Object — объекты

Тип `object` связан с объектно-ориентированным программированием.

Например, позже мы сможем создать класс:

```php
class Student
{
    public string $name;
}
```

А затем объект:

```php
$student = new Student();
```

Переменная `$student` будет содержать **объект**.

Пока достаточно понимать идею:

> Объект — это структура, которая объединяет данные и поведение.

К объектам мы вернёмся в большом блоке по ООП.

# 18. Динамическая типизация

Это одна из самых важных особенностей PHP.

В некоторых языках программист заранее указывает тип переменной.

Например, условно:

```text
int age = 20;
```

В PHP можно написать:

```php
$age = 20;
```

PHP сам определит, что `20` — это `int`.

Можно сделать:

```php
$age = 20;

$age = "двадцать";

$age = true;
```

Тип переменной изменился:

```text
20         → int
"двадцать" → string
true       → bool
```

Это называется **динамической типизацией**.

---

# 19. Почему динамическая типизация удобна?

Она позволяет писать код быстрее и с меньшим количеством служебного синтаксиса.

Например:

```php
$name = "Иван";
$age = 20;
```

не требует дополнительных объявлений.

Но у этого есть и обратная сторона.

Например:

```php
$price = 100;

$price = "сто";
```

Программа технически может принять такое изменение, хотя с точки зрения логики программы это может быть ошибкой.

Поэтому в современном PHP активно используется **типизация**, особенно в больших проектах.

Например:

```php
function calculatePrice(float $price): float
{
    return $price * 1.2;
}
```

К этому мы вернёмся при изучении функций.

---

# 20. Как узнать тип переменной?

Для этого очень удобно использовать:

```php
var_dump()
```

Например:

```php
$name = "Иван";
$age = 20;
$price = 99.99;
$isStudent = true;

var_dump($name);
var_dump($age);
var_dump($price);
var_dump($isStudent);
```

Результат будет примерно таким:

```text
string(8) "Иван"
int(20)
float(99.99)
bool(true)
```

`var_dump()` особенно полезен при отладке.

---

# 21. `gettype()`

Есть и функция:

```php
gettype()
```

Например:

```php
$value = 100;

echo gettype($value);
```

Результат:

```text
integer
```

Но для отладки обычно гораздо информативнее:

```php
var_dump($value);
```

# 22. Проверка конкретного типа

PHP предоставляет функции:

```php
is_int()
is_float()
is_string()
is_bool()
is_array()
is_object()
is_null()
```

Например:

```php
$age = 20;

if (is_int($age)) {
    echo "Это целое число";
}
```

Это особенно пригодится при обработке данных, полученных от пользователя.

# 23. Приведение типов

PHP может преобразовывать значения из одного типа в другой.

Например:

```php
$value = "100";

$number = (int) $value;
```

Теперь:

```php
var_dump($number);
```

получим:

```text
int(100)
```

Можно привести к другим типам:

```php
(int)
(float)
(string)
(bool)
```

Например:

```php
$number = 100;

$text = (string) $number;

var_dump($text);
```

Получим:

```text
string(3) "100"
```

---

# 24. Неявное преобразование типов

PHP может самостоятельно преобразовывать типы в определённых ситуациях.

Например:

```php
$number = "10";

$result = $number + 5;

echo $result;
```

Получим:

```text
15
```

PHP понял, что строку `"10"` можно интерпретировать как число.

Это удобно, но одновременно является источником некоторых неожиданных ситуаций.

Поэтому в дальнейшем важно понимать разницу между:

```text
значением
типом значения
преобразованием типа
```

# 25. `==` и `===`

### `==`

Сравнивает значения, при необходимости выполняя преобразование типов.

```php
10 == "10"
```

Результат:

```text
true
```

Потому что PHP может привести `"10"` к числу `10`.

---

### `===`

Сравнивает **и значение, и тип**.

```php
10 === "10"
```

Результат:

```text
false
```

Потому что:

```text
10   → int
"10" → string
```

Хотя значения визуально похожи, типы разные.

Можно представить:

```text
10 == "10"
│     │
└─────┴── значения считаются равными


10 === "10"
│      │
│      └── string
└───────── int

Типы разные → false
```

### Практическое правило

В современном PHP в большинстве случаев предпочтительно использовать **строгие сравнения**:

```php
===
!==
```

а не:

```php
==
!=
```

# 26. Небольшой практический пример

Представим регистрацию студента.

```php
$name = "Алексей";
$age = 19;
$averageGrade = 4.5;
$isStudent = true;
$phone = null;
```

Здесь мы имеем:

| Переменная      | Значение    | Тип      |
| --------------- | ----------- | -------- |
| `$name`         | `"Алексей"` | `string` |
| `$age`          | `19`        | `int`    |
| `$averageGrade` | `4.5`       | `float`  |
| `$isStudent`    | `true`      | `bool`   |
| `$phone`        | `null`      | `null`   |

А затем можем вывести информацию:

```php
echo "Имя: $name<br>";
echo "Возраст: $age<br>";
echo "Средний балл: $averageGrade<br>";
```

Это уже начинает напоминать реальную информационную систему.
