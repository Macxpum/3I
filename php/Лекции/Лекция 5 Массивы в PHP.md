
## Цель занятия

* понимать, зачем нужны массивы;
* создавать обычные и ассоциативные массивы;
* получать и изменять элементы;
* добавлять и удалять элементы;

* использовать основные функции для работы с массивами;

# 1. Что такое массив?

**Массив — это переменная, которая может хранить несколько значений.**

Например:

```php
$names = ["Иван", "Пётр", "Анна", "Мария"];
```

Вместо четырёх переменных у нас одна:

```php
$names
```

Внутри неё находятся четыре значения.

У каждого значения есть свой **индекс**.

```text
Индекс      Значение

  0    →    Иван
  1    →    Пётр
  2    →    Анна
  3    →    Мария
```

Обратите внимание:

> **Нумерация начинается с 0.**

---

# 3. Создание массива

Самый распространённый вариант:

```php
$names = ["Иван", "Пётр", "Анна"];
```

Старый вариант:

```php
$names = array("Иван", "Пётр", "Анна");
```

В современном PHP обычно используется первый вариант.

---

# 4. Получение элемента массива

Получить первый элемент:

```php
echo $names[0];
```

Второй:

```php
echo $names[1];
```

Третий:

```php
echo $names[2];
```

Например:

```php
$names = ["Иван", "Пётр", "Анна"];

echo $names[1];
```

Получим:

```text
Пётр
```

---

# 5. Изменение элемента

Массив работает примерно так же, как обычная переменная.

```php
$names = ["Иван", "Пётр", "Анна"];

$names[1] = "Алексей";
```

Теперь:

```text
0 → Иван
1 → Алексей
2 → Анна
```

---

# 6. Добавление элемента

Если нужно добавить элемент в конец:

```php
$names[] = "Мария";
```

Например:

```php
$names = ["Иван", "Пётр"];

$names[] = "Анна";
$names[] = "Мария";
```

Получим:

```text
Иван
Пётр
Анна
Мария
```

---

# 7. А теперь вспомним `foreach`

В предыдущей лекции мы уже использовали `foreach`.

Теперь становится понятно, зачем он особенно удобен.

```php
$names = ["Иван", "Пётр", "Анна", "Мария"];

foreach ($names as $name) {
    echo $name . "<br>";
}
```

`foreach` последовательно берёт каждый элемент массива.

Можно представить:

```text
$names
   ↓
Иван
   ↓
Пётр
   ↓
Анна
   ↓
Мария
```

---

# 8. `foreach` с индексом

Иногда нам нужен не только элемент, но и его индекс.

Для этого:

```php
foreach ($names as $index => $name) {
    echo $index . " — " . $name . "<br>";
}
```

Получим:

```text
0 — Иван
1 — Пётр
2 — Анна
3 — Мария
```

Здесь:

```php
$index
```

— индекс.

А:

```php
$name
```

— значение.

# 9. Новая функция — `count()`

До этого мы могли перебрать массив через `foreach`.

Но иногда нам нужно просто узнать:

> Сколько элементов находится в массиве?

Для этого используется:

```php
count()
```

Например:

```php
$names = ["Иван", "Пётр", "Анна"];

echo count($names);
```

Результат:

```text
3
```

---

## `count()` вместе с `for`

Мы можем объединить то, что уже знаем:

```php
$names = ["Иван", "Пётр", "Анна"];

for ($i = 0; $i < count($names); $i++) {
    echo $names[$i] . "<br>";
}
```

Здесь одновременно используются:

* массив;
* `count()`;
* `for`;
* индекс массива.

# 10. Новая функция — `in_array()`

Иногда нам нужно проверить:

> Есть ли определённое значение в массиве?

Например:

```php
$names = ["Иван", "Пётр", "Анна"];
```

Проверяем наличие Анны:

```php
if (in_array("Анна", $names)) {
    echo "Анна найдена";
}
```

`in_array()` возвращает:

```text
true
```

если значение найдено,

или:

```text
false
```

если его нет.

---

## Пример

```php
$names = ["Иван", "Пётр", "Анна"];

if (in_array("Мария", $names)) {
    echo "Мария найдена";
} else {
    echo "Мария не найдена";
}
```

Результат:

```text
Мария не найдена
```

---

# 11. Новая функция — `unset()`

Иногда элемент массива необходимо удалить.

Для этого используется:

```php
unset()
```

Например:

```php
$names = ["Иван", "Пётр", "Анна"];

unset($names[1]);
```

Мы удалили:

```text
Пётр
```

---

# 12. Важный момент после `unset()`

После удаления элемента индексы не обязательно перестраиваются.

Было:

```text
0 → Иван
1 → Пётр
2 → Анна
```

После:

```php
unset($names[1]);
```

может остаться:

```text
0 → Иван
2 → Анна
```

То есть индекса `1` больше нет.

На этом этапе достаточно понимать сам принцип.

---

# 13. Новая функция — `sort()`

PHP позволяет сортировать массивы.

Например:

```php
$numbers = [10, 5, 30, 2, 15];

sort($numbers);
```

После сортировки:

```text
2
5
10
15
30
```

`sort()` сортирует значения **по возрастанию**.

---

# 14. `rsort()`

Если нужна сортировка по убыванию:

```php
$numbers = [10, 5, 30, 2, 15];

rsort($numbers);
```

Получим:

```text
30
15
10
5
2
```

---

# 15. Новая функция — `array_pop()`

Иногда необходимо удалить последний элемент.

Для этого:

```php
array_pop()
```

Например:

```php
$names = ["Иван", "Пётр", "Анна"];

array_pop($names);
```

Теперь:

```text
Иван
Пётр
```

`Анна` была последним элементом и удалена.

---

# 16. Новая функция — `array_shift()`

А если нужно удалить **первый** элемент:

```php
array_shift()
```

Например:

```php
$names = ["Иван", "Пётр", "Анна"];

array_shift($names);
```

Получим:

```text
Пётр
Анна
```

---

# 17. Новая функция — `array_unshift()`

Обратная операция — добавить элемент в начало:

```php
$names = ["Пётр", "Анна"];

array_unshift($names, "Иван");
```

Получим:

```text
Иван
Пётр
Анна
```

---

# 18. Кратко о новых функциях

| Функция           | Что делает                   |
| ----------------- | ---------------------------- |
| `count()`         | считает количество элементов |
| `in_array()`      | проверяет наличие значения   |
| `unset()`         | удаляет элемент              |
| `sort()`          | сортирует по возрастанию     |
| `rsort()`         | сортирует по убыванию        |
| `array_pop()`     | удаляет последний элемент    |
| `array_shift()`   | удаляет первый элемент       |
| `array_unshift()` | добавляет элемент в начало   |

# 19. Ассоциативные массивы

До этого мы использовали индексы:

```php
$names[0]
$names[1]
$names[2]
```

Но иногда индекс `0`, `1`, `2` не очень информативен.

Например, если мы храним информацию о пользователе:

```text
Имя
Возраст
Email
Город
```

Было бы удобнее обращаться к данным по названию.

Для этого существуют **ассоциативные массивы**.

```php
$user = [
    "name" => "Иван",
    "age" => 20,
    "email" => "ivan@mail.ru",
    "city" => "Москва"
];
```

Теперь:

```php
echo $user["name"];
```

выведет:

```text
Иван
```

---

# 20. Ключ и значение

В записи:

```php
"name" => "Иван"
```

`name` — **ключ**.

`Иван` — **значение**.

Можно представить:

```text
Ключ       Значение

name   →   Иван
age    →   20
email  →   ivan@mail.ru
city   →   Москва
```

---

# 21. Изменение и добавление

Изменить значение:

```php
$user["age"] = 21;
```

Добавить новое:

```php
$user["phone"] = "89991234567";
```

---

# 22. Перебор ассоциативного массива

Используем уже знакомый `foreach`:

```php
foreach ($user as $key => $value) {
    echo $key . ": " . $value . "<br>";
}
```

Получим:

```text
name: Иван
age: 21
email: ivan@mail.ru
city: Москва
phone: 89991234567
```

То есть `foreach` работает и с обычными, и с ассоциативными массивами.

# 23. Многомерные массивы

Теперь самое интересное.

Мы можем хранить **массив внутри массива**.

Например, несколько пользователей:

```php
$users = [
    [
        "name" => "Иван",
        "age" => 20
    ],
    [
        "name" => "Анна",
        "age" => 17
    ],
    [
        "name" => "Пётр",
        "age" => 25
    ]
];
```

Получается:

```text
$users
 │
 ├── пользователь 1
 │      name → Иван
 │      age  → 20
 │
 ├── пользователь 2
 │      name → Анна
 │      age  → 17
 │
 └── пользователь 3
        name → Пётр
        age  → 25
```

---

# 24. Получение данных

Например, имя первого пользователя:

```php
echo $users[0]["name"];
```

Возраст второго:

```php
echo $users[1]["age"];
```

Имя третьего:

```php
echo $users[2]["name"];
```

---

# 25. Перебор многомерного массива

И здесь снова пригодится `foreach`:

```php
foreach ($users as $user) {
    echo $user["name"] . "<br>";
}
```

Получим:

```text
Иван
Анна
Пётр
```

---

# 26. Массивы + `if`

Теперь соединяем новые знания со старыми.

Например, нам нужно вывести только совершеннолетних пользователей:

```php
foreach ($users as $user) {

    if ($user["age"] >= 18) {
        echo $user["name"] . "<br>";
    }

}
```

Результат:

```text
Иван
Пётр
```

Здесь мы используем сразу:

```text
массив
   ↓
foreach
   ↓
if
   ↓
оператор сравнения
```

---

# 27. Массивы + `foreach` + `continue`

Например, нужно пропустить несовершеннолетних:

```php
foreach ($users as $user) {

    if ($user["age"] < 18) {
        continue;
    }

    echo $user["name"] . "<br>";
}
```

Это хороший пример того, как знания предыдущих занятий начинают объединяться.

---

# 28. Массивы + `foreach` + `break`

А если нам нужно найти первого пользователя старше 18 лет:

```php
foreach ($users as $user) {

    if ($user["age"] >= 18) {
        echo $user["name"];
        break;
    }

}
```

После нахождения пользователя цикл прекращается.
