  

## Цель задания

  

Создать PHP-скрипт, реализующий простую систему авторизации пользователя с проверкой:

* существования логина;
* правильности пароля;
* данных пользователя;
* надёжности введённого пароля.

  

---

  

## 1. Создание массива пользователей


В начале программы создайте массив `$users`, содержащий **3 пользователей**.

Для каждого пользователя необходимо указать следующие данные:

* `user_name` — имя пользователя;
* `user_age` — возраст;
* `user_login` — логин;
* `user_password` — пароль.
### Пример


```php

$users = [

[

"user_name" => "Алексей",

"user_age" => 21,

"user_login" => "alex",

"user_password" => "Alex@123"

],

[

"user_name" => "Мария",

"user_age" => 19,

"user_login" => "maria",

"user_password" => "Maria#456"

],

[

"user_name" => "Иван",

"user_age" => 25,

"user_login" => "ivan",

"user_password" => "Ivan_789"

]

];

```


---


## 2. Данные для авторизации
  
После создания массива пользователей создайте две переменные:

  

```php

$user_login = "";

$user_password = "";

```

  

В эти переменные необходимо  записывать логин и пароль, которые будут использоваться для проверки. Попадать данные будут через `http` запрос типа `POST`.

---

# 3. Логика работы программы

Программа должна последовательно выполнять несколько проверок.
## 3.1. Проверка логина

Необходимо проверить, существует ли введённый `$user_login` среди пользователей массива `$users`.

Если пользователь с таким логином **не найден**, вывести сообщение:

```text
Пользователь с таким логином не существует.
```

---

## 3.2. Проверка пароля

Если пользователь с указанным логином существует, необходимо сравнить введённый `$user_password` с паролем этого пользователя.

Если пароль **неверный**, вывести:

```text
Некорректный пароль.
```

---
## 3.3. Успешная авторизация

Если логин и пароль совпадают с данными пользователя, необходимо вывести информацию о пользователе:

```text
Имя пользователя: [имя]
Возраст: [возраст]
```

Например:

```text
Имя пользователя: Алексей
Возраст: 21
```

---

# 4. Проверка надёжности пароля

При проверке введённого пароля необходимо дополнительно определить, является ли он слабым.

Пароль считается **слабым**, если выполняется хотя бы одно из следующих условий:

1. Длина пароля меньше **8 символов**.
2. Отсутствует хотя бы **один специальный символ** из списка: `@ & % # [ ] ( ) _ !`
3. Отсутствует хотя бы **одна цифра**.

Если пароль не соответствует хотя бы одному из требований, необходимо вывести сообщение:

```text
Внимание! Пароль является слабым.
```

> **Важно:** проверка надёжности пароля должна выполняться с использованием функций для работы со строками и логических операторов.

# 7. Результат работы

  

В результате должен получиться PHP-скрипт, который:

  

1. Хранит данные трёх пользователей в массиве.

2. Принимает логин и пароль через переменные.

3. Ищет пользователя по логину.

4. Проверяет правильность пароля.

5. При успешной авторизации выводит имя и возраст пользователя.

6. Проверяет надёжность пароля.

7. Выводит предупреждение, если пароль является слабым.

8. Корректно обрабатывает все перечисленные варианты тестирования.
