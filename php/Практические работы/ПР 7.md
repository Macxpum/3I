
## Задание 1. Первая GET-форма

Создайте форму:

```text
Имя:
[____________]

[ Отправить ]
```

Используйте:

```html
method="GET"
```

После отправки вывести:

```text
Привет, Иван!
```

Имя необходимо получить из:

```php
$_GET
```

---

## Задание 2. Два GET-параметра

Создайте форму с полями:

```text
Имя

```

После отправки вывести:

```text

Город: Москва
```

Проверьте адресную строку браузера и найдите оба параметра.

## Задание 6. Проверка возраста

Создайте POST-форму:

```text
Возраст:
[____]

[ Проверить ]
```

Получите возраст.

Если поле пустое:

```text
Введите возраст
```

Если введено не число:

```text
Некорректный возраст
```

Если возраст меньше 18:

```text
Несовершеннолетний
```

Иначе:

```text
Совершеннолетний
```

Использовать:

```php
is_numeric()
```

и:

```php
if / elseif / else
```

## Задание 7. Проверка имени функцией

Создайте функцию:

```php
validateName($name)
```

Она должна вернуть `false`, если:

- имя пустое;
- после `trim()` ничего не осталось;
- длина имени меньше двух символов.

В остальных случаях вернуть:

```php
true
```

Используйте функцию при обработке POST-формы.

## Задание 9. Анкета

Создайте POST-форму:

```text
Имя
Возраст
Город
```

После отправки:

1. получить все данные;
2. убрать лишние пробелы;
3. проверить имя;
4. проверить возраст;
5. проверить город;
6. создать массив `$user`.

Например:

```php
$user = [
    "name" => $name,
    "age" => $age,
    "city" => $city
];
```

Вывести данные пользователя.

## Задание 10. Функции проверки

Для предыдущей задачи создайте:

```php
validateName($name)
validateAge($age)
validateCity($city)
```

Каждая функция должна возвращать:

```text
true
```

или:

```text
false
```

Основная часть программы должна только:

1. получить данные;
2. вызвать функции;
3. вывести результат.

## Задание 11. Мини-калькулятор

Создайте POST-форму:

```text
Первое число
Второе число
Операция
```

Например:

```text
10
5
+
```

Создайте функцию:

```php
calculate($a, $b, $operation)
```

Поддерживаемые операции:

```text
+
-
*
/
```

Используйте:

```php
switch
```

Проверьте:

- оба значения должны быть числами;
- нельзя делить на `0`.

Результат:

```text
10 + 5 = 15
```

Итоговое задание — мини-регистрация

Создайте форму:

```text
Имя:
[________________]

Возраст:
[________________]

Email:
[________________]

Город:
[________________]

[ Зарегистрироваться ]
```

Используйте:

```html
method="POST"
```

Создайте функции:

```php
validateName($name)
validateAge($age)
validateEmail($email)
validateCity($city)
```

Для `validateEmail()` пока достаточно проверить:

```text
поле не пустое
```

Подробная проверка email будет изучаться позже.

После успешной проверки создать:

```php
$user = [
    "name" => $name,
    "age" => $age,
    "email" => $email,
    "city" => $city
];
```

Вывести:

```text
Регистрация успешна

Имя: Иван
Возраст: 20
Email: ivan@mail.ru
Город: Москва
```

Если какое-либо значение некорректно, вывести соответствующую ошибку.

Например:

```text
Введите имя
```

или:

```text
Некорректный возраст
```

или:

```text
Введите email
```
